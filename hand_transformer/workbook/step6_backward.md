# ステップ6 逆伝播（6.1–6.9）

**目標**：損失 $L$ から入力側へ勾配を流し、180個すべてのパラメータの勾配を求めます。分岐点では勾配が**足し算で合流**し、残差接続は勾配を**素通り**させます。その様子を数字で確かめます。

- **目安時間**：8.0 時間（導出 2.5h ＋ 数値 5.5h。内訳は下の表）
- **対応チェックポイント**：6.1–6.9

| ブロック | チェックポイント | 内容 | 目安 |
|---|---|---|---:|
| 導出 | — | [derivations.md](derivations.md) の問1〜8（数字は使わない） | 2.5h |
| 6a | 6.1 | 出力層 | 0.75h |
| 6b | 6.2 | FFN | 1.25h |
| 6c | 6.3 | LN2 の逆伝播と残差の合流 | 0.75h |
| 6d | 6.4–6.6 | 出力射影・Attention の softmax・Q/K/V | 1.5h |
| 6e | 6.7–6.9 | 射影行列・LN1 と残差の合流・埋め込み | 1.25h |

> **数字に入る前に、[derivations.md](derivations.md) を最後まで解いてください。**
> このシートの式は、すべてそこで自分で導く式です。導出が済んでいれば、ここでの作業は「代入して積和する」だけになります。
> 導出を飛ばすと、6.3（LayerNorm）と 6.5（softmax）で手が止まりがちです。

## 手順

始める前に、下の「計算する前に予想しよう」の3問に、自分の予想を書いておいてください。

### 地図：勾配の流れと3つの分岐点

6a〜6c（出力側）：

```
dlogits -> dX2 --+-------------------------------------> (+) -> dX1
                 |                                        ^
                 +-> dF -> dR -> dZ -> dU2 -> LN2-bwd ----+
```

6d〜6e（入力側）：

```
dX1 --+--------------------------------------------------------------> (+) -> dX0 -> dP, dE
      |                                                                 ^
      +-> dAttn -> dOcat -> dA -> dS -> dQ,dK,dV -> dU1 -> LN1-bwd -----+
```

順伝播で1つの値を2か所以上で使った場所（**分岐点**）では、逆伝播で各経路の勾配を**足します**（derivations.md 問2）。

| 分岐点 | 順伝播での行き先 | 逆伝播での合流 | どこで |
|---|---|---|---|
| X1 | 残差で X2 へ ／ LN2 → FFN | dX1 = dX2 + LN2経由 | 6.3 |
| U1 | Q・K・V の3か所 | dU1 = dQ Wqᵀ + dK Wkᵀ + dV Wvᵀ | 6.7 |
| X0 | 残差で X1 へ ／ LN1 → Attention | dX0 = dX1 + LN1経由 | 6.8 |

同じ理由で、**3位置で共有している重みの勾配は、位置ごとの外積の3つの和**になります：$dW = X^\top dY = \sum_t x_t^\top\, dy_t$。
キー $k_j$・値 $v_j$ も複数のクエリに使われるので、dK・dV は「そのキーを見たクエリ」についての和です。

### 6a 出力層（6.1）— 0.75h

1. **dlogits = (p − y)/3**〔3×5〕：5.2 の p から正解のマス（t0 の 猫、t1 の が、t2 の 鳴く）だけ 1 を引き、全体を 3 で割ります。÷3 は損失が3位置の**平均**だからです。負になるのは正解の3マスだけです。
2. **dWout = X2ᵀ dlogits**〔4×5〕：$dW_{out}[k,j] = \sum_t X_2[t,k]\, d\mathrm{logits}[t,j]$。3位置の外積の和です。60回の積がすべて小数×小数なので、6a の時間の大半はここです。
3. **dX2 = dlogits Woutᵀ**〔3×4〕：Wout は20個中14個が0なので、1行あたり6回の積（×0.5 か ×1）で済みます。dlogits の t 行を $g = (g_0, \dots, g_4)$（列の順は `<s>`, 猫, が, 鳴く, 。）とすると

   $$dX_2[t] = \left(-0.5\,g_1,\; -0.5\,g_2,\; 0.5\,g_0,\; -g_0 - 0.5\,g_2 + 0.5\,g_4\right)$$

   Wout の「鳴く」列は全部0なので $g_3$ は dX2 に効きません。ただし dWout の「鳴く」列は0ではないので、2. では省略しないこと。

### 6b FFN（6.2）— 1.25h

1. **dF = dX2**〔3×4〕：$X_2 = X_1 + F$ の F 側です。足し算の逆伝播は「そのままコピー」。
2. **dW2 = Rᵀ dF**〔8×4〕：h 行 $= \sum_t R[t,h]\, dF[t]$。R は24マス中10マスしか非零でないので、積は40回です。**h3 行は厳密に0**（R の h3 列が全部0）。h0・h2（t2 だけが発火）と h1・h6（t1 だけ）は「数×ベクトル」1回で終わります。
3. **dR = dF W2ᵀ**〔3×8〕：**Z > 0 の10マスだけ**求めれば十分です（40回。うち8回は W2 が0で、残りは ×0.5 か ×1）。残り14マスは次の ReLU で0倍されて消えるからです。記入欄の残りは空けて構いません（24マス全部埋めると行和チェックサムが使えます）。
4. **dZ = dR ⊙ [Z > 0]**〔3×8〕：4.3 の Z が正のマスだけ dR を写し、他は0。
5. **dW1 = U2ᵀ dZ**〔4×8〕：h 列 $= \sum_t U_2[t]^\top\, dZ[t,h]$。積40回（小数×小数）。**h3 列は厳密に0**。
6. **dU2 = dZ W1ᵀ**〔3×4〕：非零の積は25回（×0.5 か ×1）。

### 6c LN2 の逆伝播と残差の合流（6.3）— 0.75h

各行 t について、y = U2[t]、σ = σ[t]（4.2）として（derivations.md 問8）：

1. $m_1$ = dU2[t] の4成分の平均
2. $m_2$ = dU2[t] ⊙ U2[t] の4成分の平均（積4回）
3. **LN2経由[t] = (dU2[t] − m₁ − U2[t]·m₂) / σ**：1/σ を1回求めてから掛けます。
4. **dX1 = dX2 + LN2経由**（分岐点 X1）：dX2 は 6.1 の値を**何も掛けずに**そのまま足します。

### 6d 出力射影・Attention（6.4–6.6）— 1.5h

**6.4**

1. **dAttn = dX1**：$X_1 = X_0 + \mathrm{Attn}$ の Attn 側。コピーです。
2. **dWo = Ocatᵀ dAttn**〔4×4〕：Ocat の t0 行のヘッド0部分は (0, 0) です（V の t0 行のヘッド0部分が (0, 0) だから）。積は40回。
3. **dOcat = dAttn Woᵀ**〔3×4〕：積36回（×0.5 か ×1）。列 d0, d1 が dO0、列 d2, d3 が dO1 です。

**6.5**（ヘッド h = 0, 1 それぞれ。A_h は 3.3、V_h は 3.1 の V の該当2列）

1. **dA_h = dO_h V_hᵀ**〔3×3〕：下三角だけ求めます（0* のマスは0）。**t0 行は不要**です（3. で dS の t0 行は dA に関係なく0になる）。ヘッド0 は V0 の t0 行が (0, 0) なので、**k0 列も全部0**です。
2. 行ごとのスカラー $r_i = \sum_j A_h[i,j]\, dA_h[i,j]$（その行の、A で重み付けした dA の平均）
3. **dS_h[i,j] = A_h[i,j] · (dA_h[i,j] − r_i)**。t0 行は A = [1, 0, 0] なので $1\cdot(dA_{00} - dA_{00}) = 0$。

**6.6**

1. **dQ_h = dS_h K_h / √2**〔3×2〕：t0 行は0（dS の t0 行が0）。$dS_h K_h$ を正確に求めてから、最後に 0.70711 を1回掛けます。
2. **dK_h = dS_hᵀ Q_h / √2**〔3×2〕：$dK_h[j] = \frac{1}{\sqrt2}\sum_{i \ge j} dS_h[i,j]\, Q_h[i]$。キー j を**見たすべてのクエリ**からの和です（転置に注意）。順伝播で省いた **Q の t0 行は、ここでも不要**です（掛かる dS の t0 行が0）。
3. **dV_h = A_hᵀ dO_h**〔3×2〕：$dV_h[j] = \sum_{i \ge j} A_h[i,j]\, dO_h[i]$。t2 行は $A_h[2,2]\, dO_h[2]$ の1項だけです。
4. ヘッド0 を列 d0, d1、ヘッド1 を列 d2, d3 に並べ、dQ・dK・dV（各3×4）にまとめます（6.7 で使う）。

### 6e 射影行列・LN1・埋め込み（6.7–6.9）— 1.25h

**6.7**

1. **dWq = U1ᵀ dQ、dWk = U1ᵀ dK、dWv = U1ᵀ dV**〔各4×4〕：U1 は ±1 だけなので**掛け算はありません**。$dW[k,:] = \sum_t U_1[t,k]\, dY[t,:]$ は、U1 の k 列の符号に従って dY の3行を足し引きするだけです。dWq は dQ の t0 行が0なので、t1 と t2 の2行だけです。
2. **dU1 = dQ Wqᵀ + dK Wkᵀ + dV Wvᵀ**〔3×4〕（分岐点 U1）：3項を別々に求めてから足します。非零の積は 17 + 21 + 33 = 71回（×0.5 か ×1）。

**6.8**

1. **LN1経由**：6.3 と同じ式で、y = U1、σ = (0.5, 2, 1)（2.2）。$y_i = \pm1$ なので $m_2$ は符号付きの足し算だけで求まります。
2. **dX0 = dX1 + LN1経由**（分岐点 X0）

**6.9**

1. **dP = dX0**：$X_0 = E[\mathrm{ids}] + P$ の P 側。コピーです。
2. **dE**：トークン ids[t] の行に dX0[t] を足します（`<s>` ← t0、猫 ← t1、が ← t2）。入力に無い 鳴く・。 の行は0です。

## 検算

**列和ベクトル 1ᵀW**（dX = dY Wᵀ の行和チェックサム用。$\sum_k dX[t,k] = dY[t] \cdot (\mathbf 1^\top W)$。[ステップ1](step1_setup.md) の 1-4 で求めた列和と同じで、コードでも確認済み）

| W | 1ᵀW（各列の和） | 使う場所 |
|---|---|---|
| Wout | (−0.5, −0.5, −1, 0, 0.5) | dX2 の行和 = dlogits[t]·(この値) |
| W2 | (0, 2, 1.5, 0.5) | dR の行和 = dF[t]·(この値)（24マス全部求めた場合） |
| W1 | (0, −1, 2, −1, 0.5, 0, 1, 1) | dU2 の行和 = dZ[t]·(この値) |
| Wo | (−0.5, 2.5, −2.5, −2) | dOcat の行和 = dAttn[t]·(この値) |
| Wq / Wk / Wv | (−2.5, 1, 1.5, −0.5) / (0.5, 1, −0.5, −3) / (1, −1, 0, 1) | dU1 の行和 = dQ[t]·(Wq の値) + dK[t]·(Wk の値) + dV[t]·(Wv の値) |

**重みの勾配 dW = Xᵀ dY の行和**：$\sum_j dW[k,j] = \sum_t X[t,k] \cdot (\text{dY の } t \text{ 行の和})$。先に dY の3つの行和を求めておけば、dW の1行を積3回で検算できます。

**この段階で成り立つ不変量**（derivations.md 末尾のチェックリストも参照）

| どこ | 成り立つべきこと |
|---|---|
| 6.1 | dlogits の各行の和 = 0、dWout の各行の和 = 0 |
| 6.2 | dW2 の h3 行・dW1 の h3 列 = 0。dW1 の**各列の和 = 0**（U2 の各行の和が0だから） |
| 6.3 | LN2経由：各行の和 = 0、U2 の同じ行との内積 = 0 |
| 6.5 | dS の各行の和 = 0、t0 行は全部0 |
| 6.6 | dQ の t0 行 = 0。dK はヘッドごとに各列の和 = 0。dV はヘッドごとに各列の和 = dO の各列の和 |
| 6.7 | dWq・dWk・dWv の**各列の和 = 0**（U1 の各行の和が0）。dWk の d0 行 = 0。dWq は d1 行 = −(d0 行)、d3 行 = −(d2 行)（t1, t2 の2行だけが寄与し、U1 のその2行は d1 = −d0、d3 = −d2 だから） |
| 6.8 | LN1経由：各行の和 = 0、U1 との内積 = 0、下の「ペアの規則」 |
| 6.9 | dE の使われた行 = dP の行、鳴く・。 の行 = 0 |

**LN1 のペアの規則**（U1 = ±1 のときだけ使える検算・近道。コードで一致を確認済み）：U1 の各行には +1 と −1 が2個ずつあります。同じ符号の2成分をペア (i, i') にすると

$$\text{LN1経由}[t,i] = \frac{dU_1[t,i] - dU_1[t,i']}{2\sigma_t},\qquad \text{LN1経由}[t,i'] = -\text{LN1経由}[t,i]$$

ペアは t0：(d0, d1) と (d2, d3)、t1：(d0, d2) と (d1, d3)、t2：(d0, d3) と (d1, d2)。
理由：結果は「行和0」と「U1 と直交」を満たすので、+1 の2成分の和も −1 の2成分の和も0になります。ペア内の差は、共通の $m_1$, $m_2$ の項が消えて $(dy_i - dy_{i'})/\sigma$ になります。

## 見どころ

数値は `python3 mini_gpt.py --step 6` の出力（4桁に丸めたもの）と、同じ実装でより多くの桁を表示したものです。

**1. 勾配の高速道路（残差）**：t0 行で、出力層の勾配 dX2 が埋め込みまでどう届くかを追います。

| t0 行 | d0 | d1 | d2 | d3 |
|---|---:|---:|---:|---:|
| dX2（6.1） | 0.1281 | −0.0214 | 0.0526 | −0.0991 |
| ＋ LN2経由（6.3） | −0.0232 | 0.0139 | −0.0313 | 0.0405 |
| ＝ dX1 | 0.1049 | −0.0074 | 0.0213 | −0.0586 |
| ＋ LN1経由（6.8） | −0.0528 | 0.0528 | 0.1044 | −0.1044 |
| ＝ dX0 ＝ dP | 0.0521 | 0.0454 | 0.1257 | −0.1630 |

dX0 = dX2 + LN2経由 + LN1経由。出力側の勾配が、**どの重みにも掛けられずに**埋め込みまで届いています。層を深くしても学習できるのは、この経路のおかげです。
（4桁に丸めた値どうしを足すと最後の桁が1ずれることがあります。例：−0.0214 + 0.0139 = −0.0075 ですが、正確な値は −0.0074）

**2. `<s>` のクエリは学習されない**：両ヘッドとも dS の t0 行は厳密に0です。ヘッド1 では dA1 (t0, k0) = −0.1157 と0ではないのに、dS1 (t0, k0) = 1 × (−0.1157 − (−0.1157)) = 0 になります。要素1つの softmax は Q に関係なく常に1だからです。順伝播で Q の t0 行を省けたことと、逆伝播で dQ の t0 行が0になることは、同じ事実の表と裏です。

**3. 飽和したキーは勾配を通さない（dWq の d1 列）**：dS の各行の和は0なので、$dq_i = \frac{1}{\sqrt2}\sum_j dS_{ij}\,(k_j - c)$（c は任意のベクトル）と書けます。つまり、クエリの勾配は**キーどうしの差**にしか反応しません。

- ヘッド0 のキーの d1 成分は k0, k1, k2 = −1, −1, +1。t1 行が見るのは k0, k1 だけで、その d1 成分は同じなので、dQ0 (t1, d1) は**厳密に0**（「0」）です。
- t2 行で d1 成分が他と違うのは k2 だけです。ところが A0 (t2, k2) = 0.0004 と飽和しているので、dS0 (t2, k2) = −9.4×10⁻⁷ しかなく、dQ0 (t2, d1) = √2 × dS0 (t2, k2) = −1.33×10⁻⁶ です。
- その結果、dWq の d1 列は (−1.33, +1.33, +1.33, −1.33)×10⁻⁶。answers.md では「0.0000」（「0」ではない）と表示され、更新後の Wq' の d1 列も 4桁では (0, 1, 1, −1) のままです。同じ理由で、dK0 の t2 行 ≈ (1.0, 2.0)×10⁻⁶、dV0 の t2 行 ≈ (−1.24, −0.85)×10⁻⁵ です。7.2 で、Wq の ‖g‖² は全体の 1.0% しかありません。

**4. 死んだユニット h3**：Z の h3 列は (−1.8856, −0.6761, −3.1631) で全部負です。dR の h3 列は (−0.0465, 0.0514, 0.0276) と0ではありませんが、ReLU の門で止められて dZ は0になります。その結果、dW1 の h3 列と dW2 の h3 行は**厳密に0**です（W2 の h3 行は [0, 0, 1, 1] と0ではないのに）。W1 の h3 列は更新されず、更新後も Z' の h3 列は (−0.6138, −0.7650, −1.4857) と負のままです（ステップ7）。

**5. dWk の d0 行は厳密に0**：U1 の d0 列は3位置とも +1 なので、dWk の d0 行 = dK の3行の和 = 0（dK の列和が0だから）です。Wk の d0 行を変えると、全キーに同じベクトルが足されるだけで、softmax は変わりません。dWq・dWk・dWv・dW1 の列和が0になるのも同じ理由です（LN の出力は各行の和が0）。

**6. 重みの勾配は「3位置の外積の和」**：dW2 の h1 行は t1 でしか発火しないので、R (t1, h1) × dF[t1] = 2.1155 × (−0.0135, 0.1221, 0.0800, −0.0286) = (−0.0287, 0.2583, 0.1691, −0.0604) の1項だけです。dWout (d3, が) = 0.3978 は、ほぼ t1 の1項です（予想3）。

**7. LN1 は 1/σ 倍に効く**：σ = 0.5 の `<s>` 行は勾配が2倍に、σ = 2 の 猫 行は半分になります。LN1経由の t0 行 (−0.0528, 0.0528, 0.1044, −0.1044) は、ペアの規則どおり ±a, ±b の形です。

**8. E と P は同じだけ動く**：dE の使われた3行は dP と完全に一致します（各トークンが1回ずつ別の位置に出るため）。ステップ7で X0 は −2·lr·dX0 だけ動きます。

## よくあるミス

- **÷3 を忘れる**：以降の勾配がすべて3倍になります。dlogits の行和は ÷3 の有無に関係なく0なので、**行和の検算ではこのミスを見つけられません**。
- **転置の取り違え**：dW = Xᵀ dY は W と同じ形、dX = dY Wᵀ は X と同じ形です。形が合わなければ転置ミスです。
- **分岐での足し忘れ**：dX1 に dX2 を足し忘れる、dU1 の3項のどれかを落とす、dX0 に dX1 を足し忘れる。
- **1/√2 を付け忘れる**：順伝播で掛けた 1/√2 は、dQ と dK にも掛かります。
- **dK で dS を転置しない**：dK の j 行は dS の **j 列**（キー j を見たクエリたち）から作ります。
- **softmax の逆で r を列方向に取る**：$r_i$ は**行** i の和 $\sum_j A[i,j]\, dA[i,j]$ です。
- **dV = A dO としてしまう**：正しくは Aᵀ dO。dV の t2 行は $A[2,2]\,dO[2]$ の1項だけになるはずです。
- **LN の逆で σ を取り違える**：6.3 は LN2 の σ（4.2）、6.8 は LN1 の σ（2.2）。σ² で割らない。y には LN の**出力**（U2, U1）を使います（入力の X1, X0 ではない）。
- **ReLU のマスクを dR の符号で決める**：マスクは順伝播の Z > 0（4.3）です。
- **小さい勾配を小数第4位で丸める**：0.0041 は有効数字2桁しかありません。有効数字4桁で記録します。
