# 手計算のコスト：この params.json で実際に何回計算するか

`mini_gpt.py` を import する集計スクリプト `opcount.py` で、ワークシートの手順どおりに**人が行う演算を1つずつ再生して数えました**。
回数はすべて実際に数えた値で、推定ではありません。時間だけは §2 の時間モデルによる推定です。

## 0. 要点

- 2.1〜7.4 の全体で、暗算か電卓が必要な掛け算は **1484 回**（うち小数×小数 788 回）です。純粋な計算時間は **8.06 時間**です。
- 密に数えると積は 2377 回あります。そのうち構造的に不要なものが 332 回（14%）、片方が 0 の積が 561 回（24%）で、**38% は計算しなくて済みます**。
- 一番重いのは **7.3 再順伝播（175 分、全計算時間の 36%）**です。積の数は1回目の順伝播と同じ 484 回ですが、小数×小数が 8 回から 400 回に増え、時間は 2.24 倍になります。
- 「順伝播は ~500 回、逆伝播はその ~2 倍」という見立ては正しいです。密に数えて 540 回 / 1116 回（2.07 倍）、工夫したあとの非自明な積でも 282 回 / 625 回（2.22 倍）です。
- **ステップ7は検算と照合を含めると 4.70 時間かかります。** 元の案の 3 時間（README §6）では足りないので、1回目の順伝播で浮いた時間を回してステップ7を 4.75 時間にしました（§4）。それでも余裕はほぼ無いので、ステップ6を終えた時点で遅れていたら [step7_update.md](step7_update.md) の省略案を選んでください。

## 1. 数え方

- **掛け算の分類**（記録した4桁の値で判定）：**0**＝片方が 0、**±1**＝片方が ±1、**n×n**＝両方が 0.5 刻み、**n×d**＝片方だけ 0.5 刻み、**d×d**＝両方が小数（二乗 d² を含む）。
- 内積は電卓のメモリ（M+）に積み上げるので、内積の中の足し算は数えません。「加減」は単独の足し算・引き算（残差、LN の平均と中心化、softmax の最大値引き、7.1 の更新）です。
- 特殊演算：exp、ln、√、÷（σ や Σe などデータの値で割る）、÷c（÷4、÷3、σ = 0.5 や 2 など 0.5 刻みの数で割る）、/√2（0.70711 倍）。自明な exp(0) = 1（14 回）と √0.25 のような √（3 回）は数に含めていません。
- **構造スキップ**（値を見るまでもなく飛ばせる積。表の「構造スキップ」列）：
  - Q の0行目と S[0,0]。位置0は自分しか見ないので、A の0行目は常に [1, 0, 0] です。
  - マスク位置に関わる積：S、O = AV、dA、dS、および dQ・dK・dV への寄与。
  - dA と dS の0行目（dS[0,0] = 0）。そのため dQ の0行目、dK への位置0の寄与、dWq と dU1 の dQ 項も不要です。
  - 死んだユニット h3（Z の h3 列は3位置とも負）。F の W2 行3、dW2 行3、dR 列3、dW1 列3、dU2 の h3 項が不要です。
  - ReLU が不活性な位置の dR（dZ = 0 になるので不要）。7.2 の ‖dE‖² は ‖dP‖² と同じです（使われた行が一致するため）。
- **数え漏れの確認**：「再生した積 + 構造スキップ = 密な積の数」が、順伝播 484 + 56 = 540、逆伝播 916 + 200 = 1116、再順伝播 484 + 56 = 540 でぴったり一致します。
- 空欄表（blank.md）では Q の0行目、S[0,0]、dA[0,0] を「—」（計算不要）にしてあります。不活性な位置の dR も**計算は不要**です。「—」と書いて先へ進んでください。

## 2. 時間モデル

| 操作 | 秒 | 根拠 |
|---|---:|---|
| 0 との積 | 1 | 0 を見て飛ばすだけ |
| ±1 × 0.5 刻み / ±1 × 小数 | 2 / 4 | 前者は暗算。後者は符号を付けて打ち込み M+ か M− |
| n×n | 3 | 1.5 × (−0.5) などの暗算 |
| n×d | 7 | 0.7428 ÷ 2 M+ など、打ち込みは1回 |
| d×d | 16 | 4桁の数を2回打ち込んで M+。2つの表から数を拾う時間を含む |
| d²（二乗） | 10 | x² キーを使うので打ち込みは1回 |
| exp・ln・√ | 15 | 引数を打ち込み、関数キーを押し、表示を読む |
| ÷（データの値で割る） | 15 | d×d と同じくらいの手間 |
| ÷c（0.5 刻みの数で割る） | 7（暗算なら 3） | n×d と同じくらいの手間 |
| ×1/√2 | 10 | 0.70711 を変数メモリに入れておき、呼び出して掛ける |
| 単独の加減 | 5（暗算なら 2、片方が 0 なら 0） | |
| 1つ記録する | 8（短い数は 3、転記は 4） | 表示を読み、4桁に丸めて書き、MC を押す |
| 照合 | 2 | answers.md と1つずつ見比べる |

**感度**：d×d を 1回 12 秒 / 20 秒とすると、合計時間は 7.39 h / 8.74 h、7b は 2.55 h / 3.39 h になります。

- **1回目の順伝播（ステップ2〜5）**：予算 4.75 h に対し、①+②+③ は 1.68 h です。初めて見る計算なので、残りは式の意味を確かめ、結果を予想する時間に使います。U1 が ±1 になるよう設計してあるので、3.1 の 128 回の積はすべて「±1」か「0」で、5.0 分で終わります（同じ 3.1 を 7.3 でやると 33.1 分）。

- **ステップ7**：予算 4.75 h に対し 4.70 h です。重いのは 7.1 の更新 180 個（26.4 分）、7.2 の二乗 148 回（26.4 分）、7.3 の d×d 400 回です。
- **配分**：上の予算は README §6 の見直し後の配分です（3 = 1.75 h、7a = 1.0 h、7b = 3.75 h）。それでも 7b が苦しいときは、7.3 では行和チェックサムを省いて answers.md との照合だけにすると、約 0.6 h 浮きます。

## 5. 密な数え方（工夫なし）との比較

| 区間 | 密な積の数 | 構造スキップ | 0 との積 | 非自明な積 | うち d×d | 計算時間 |
|---|---:|---:|---:|---:|---:|---:|
| 順伝播 2.1–5.3 | 540 | 56 | 202 | 282 | 8 | 1.33 h |
| 逆伝播 6.1–6.9 | 1116 | 200 | 291 | 625 | 232 | 2.77 h |
| 更新 7.1–7.2 | 181（g² 180 回 + 1 回。lr = 1 なので lr·g の 180 回は数えない） | 20 | 12 | 149 | 148 | 0.88 h |
| 再順伝播 7.3–7.4 | 540 | 56 | 56 | 428 | 400 | 2.97 h |
| **合計** | | 332 | 561 | **1484** | 788 | **8.06 h** |

- 密な 540 回の内訳：LN の二乗 12 + 12、Q・K・V 144、スコア 36、AV 36、Wo 48、W1 96、W2 96、Wout 60。
- 逆伝播の 1116 回には、LN 逆伝播と softmax 逆伝播の要素ごとの積も含めています（ReLU の 0/1 マスクは含めません）。更新は lr = 1 なので、7.1 は引き算だけです（密なら lr·g の 180 回）。
- 1回目の順伝播で d×d が 8 回しかないのは、0.5 刻みの重みと ±1 の U1 のおかげです。再順伝播では更新後の重みが4桁の小数になり、U1′ も ±1 ではなくなるので、484 回中 400 回が d×d になります（4桁に丸めずに判定すると 412 回）。

## 6. 20 時間の内訳：計算以外の時間は何に使うか

| 内容 | 時間 |
|---|---:|
| ① 計算（§3 の合計） | 8.06 h |
| ② 検算（チェックサムと不変量） | 1.51 h |
| ③ 照合（answers.md との突き合わせ、1116 値） | 0.62 h |
| 導出（derivations.md、数値は使わない） | 2.5 h |
| 予備・振り返り | 1.5 h |
| **残り：理解と誤り探し（各ステップの予算に含まれている分）** | **5.81 h** |

残りの 5.81 h は、次のことに使う時間です。

- **理解**：各チェックポイントの前に、式と形を確かめて結果を予想します（例：3.3 の位置0の行は [1, 0, 0]、6.6 の dQ の0行目は 0、6.9 の「鳴く」「。」の行は 0）。ステップ1の計算グラフ作りもここに入ります（ステップ1 の 1.0 h のうち計算は 0.12 h）。
- **段取り**：ページをめくり、どの数を使うか探し、表を書き写す時間です。時間モデルには「表から数を拾う」ところまでしか入っていません。
- **誤り探し**：許容差を超えたら最大 10 分探し、見つからなければ解答の値で上書きして先へ進みます。29 チェックポイントのすべてで起きた場合が最悪で 4.83 h です。ただしステップ7には余裕がほとんどないので、7.x で大きくずれたら早めに上書きしてください。
- **読み取り**：Attention がどこを見ているか、ロジットの分解（`--decompose`）、そして 7.2 の予言 ΔL = −1.4701 と 7.4 の実際の ΔL = −1.2893 の比較です。

## 7. 再現方法

`python3 tools/opcount.py` で全集計を表示します（`--exact` は4桁に丸めず厳密な値で分類、`--md FILE` はこのページの表を書き出し）。
