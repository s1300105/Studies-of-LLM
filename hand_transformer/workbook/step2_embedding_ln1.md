# ステップ2 埋め込み + LayerNorm1

**目標**：入力 `<s> 猫 が` を 3×4 の行列 X0 にし、LayerNorm で U1 にします。U1 が **全成分 ±1** になる理由を自分の言葉で説明できるようにします。

- **目安時間**：0.5 時間
- **対応チェックポイント**：2.1 埋め込み + 位置埋め込み、2.2 LayerNorm1 の統計量、2.3 LayerNorm1 の出力

## 使う値

- [params.md](params.md) の **トークン埋め込み E**（5×4、行 = トークン）と **位置埋め込み P**（3×4、行 = 位置）
- 入力 ids = [0, 1, 2]（`<s>`, `猫`, `が`）
- 前のステップ：[ステップ1](step1_setup.md) で決めた精度ルール（この段階ではまだ小数は出ません）

## 手順

### 2-1 埋め込みを引いて位置を足す（2.1、5分）

$$X_0 = E[\text{ids}] + P \qquad (3\times4) = (3\times4) + (3\times4)$$

- $E[\text{ids}]$ は **計算ではなく表引き** です。位置 $t$ の行に、トークン $\text{ids}[t]$ の E の行を写します。今回は ids がたまたま 0, 1, 2 なので E の上3行ですが、一般には「上から3行」ではありません
- P は **位置** ごとの行（トークンごとではない）。成分ごとに12回足し算をします

### 2-2 行ごとの平均・分散（2.2、10分）

$$\mu_t = \tfrac14\textstyle\sum_i X_0[t,i],\qquad \sigma_t^2 = \tfrac14\textstyle\sum_i (X_0[t,i]-\mu_t)^2,\qquad \sigma_t = \sqrt{\sigma_t^2}$$

- 分散は **母分散（÷4）**。ε は 0 なので足しません
- 各行は「2種類の値が2回ずつ」なので、σ は平方根を開くまでもなく求まります（下の予想1）

### 2-3 正規化（2.3、10分）

$$U_1[t,i] = \frac{X_0[t,i]-\mu_t}{\sigma_t}\qquad (3\times4)$$

- ★ U1 と σ1 は逆伝播（6.7, 6.8）で再利用します。地図に印をつけておきましょう
- U1 の符号パターンを、ステップ3で使うので行ごとに `(+, −, …)` の形でメモしておきます

## 計算する前に予想しよう

1. X0 の各行は「2種類の値 $a, b$ が2回ずつ」並んでいます。σ を計算する前に、U1 の値を予想できますか？
2. U1 の各行に +1 と −1 はそれぞれいくつありますか？（LN 出力の性質から決まります）
3. E の5行のうち、使われない行はどれですか？ その行の勾配は逆伝播でどうなるでしょう？

<details><summary>答え</summary>

1. $\mu = (a+b)/2$ なので、各成分の偏差は $\pm(a-b)/2$ のどちらか。$\sigma^2 = ((a-b)/2)^2$、$\sigma = |a-b|/2$ となり、**どの成分も ±1** になります。値の大きさ（$a, b$）は消え、どちらの値が大きいかという **パターンだけ** が残ります
2. 2個ずつ。LN 出力は各行で平均0なので、±1 だけで平均0にするには +1 と −1 が同数でなければなりません
3. `鳴く` と `。` の行。入力に現れないので、6.9 で勾配が0になり、7.1 で更新されません（出力側の Wout の列としては学習されます）
</details>

## 検算

- **行和**：$\mathrm{rowsum}(X_0) = \mathrm{rowsum}(E[\text{ids}]) + \mathrm{rowsum}(P)$。μ は行和 ÷ 4 なので、行和が合えば μ も合います
- **U1 の各行**：平均 = 0、二乗平均 = 1（±1 なら自動的に1）、+1 と −1 が2個ずつ
- **σ の検算**：$\sigma_t = |a-b|/2$ と、定義どおりの $\sqrt{\sigma_t^2}$ が一致すること

<details><summary>検算用の値（mini_gpt.py より）</summary>

rowsum(E[ids]) = (−1, 0, −1)、rowsum(P) = (−1, 0, 1) → rowsum(X0) = (−2, 0, 0) → μ1 = (−0.5, 0, 0)
</details>

## 見どころ

<details><summary>計算を終えてから開く</summary>

- **大きさは消え、向きだけが残る**：σ1 = (0.5, 2, 1)。t1（猫）の X0 は ±2 で t2 の2倍の大きさですが、U1 ではどちらも ±1 です。Attention 側は U1 しか見ないので「大きさ」を知りません。大きさは残差 $X_1 = X_0 + \mathrm{Attn}$ を通って X0 のまま運ばれます
- **3つの位置の符号パターンは互いに直交**：t0 = (+, +, −, −)、t1 = (+, −, +, −)、t2 = (+, −, −, +)。どの2行の内積も0です（`mini_gpt.py` で $U_1U_1^\top = 4I$ を確認）
- **ステップ3が足し算だけになる理由**：U1 が ±1 なので、$Q = U_1W_q$ の各行は「Wq の4行を符号どおりに足し引きしたもの」です。README が「144回の積和が足し算・引き算だけになる」と書いているのはこのことです
- **2回目の順伝播（7.3）ではこうはいきません**：更新後は X0' の t0 行が (−0.1042, −0.0907, −1.2515, −0.6741) となり「2種類×2回」の形が崩れ、U1' の t0 行は (0.8903, 0.9184, −1.5078, −0.3009)、σ1' = (0.4784, 2.0017, 0.9998) です。t1, t2 行も (1.0270, −0.9983, 0.9727, −1.0013) のように ±1 に **近いだけ** になります。ステップ7で時間がかかる理由の1つです
</details>

## よくあるミス

- **標本分散（÷3）** を使ってしまう。このワークブックは母分散（÷4）です
- t0 行で **μ を引き忘れる**（t0 だけ μ = −0.5 で、0 ではありません）
- σ ではなく **σ² で割る**
- P を **トークン** で引いてしまう（P の行は位置 t0, t1, t2）
- 実装の癖で ε を足す（ここでは ε = 0）
