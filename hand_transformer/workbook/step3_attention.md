# ステップ3 マスク付き Attention

**目標**：2つのヘッドそれぞれで「各位置が過去のどの位置をどれだけ見るか」（A_h）を計算し、その重みで値ベクトルを混ぜて（O_h）、Wo で残差ストリームに戻します（Attn）。

- **目安時間**：1.75 時間（3.1 20分 / 3.2 20分 / 3.3 20分 / 3.4 20分 / 3.5 15分 / 検算と余裕 10分）
- **対応チェックポイント**：3.1 Q, K, V、3.2 スコア、3.3 Attention重み、3.4 ヘッド出力と連結、3.5 出力射影

## 使う値

- [params.md](params.md) の **Wq, Wk, Wv, Wo**（Wo は行 d0, d1 = ヘッド0、d2, d3 = ヘッド1）
- [ステップ2](step2_embedding_ln1.md) の **2.3 U1**（全成分 ±1）と、その符号パターン
- [ステップ1](step1_setup.md) で求めた行和 Wq·1, Wk·1, Wv·1, Wo·1

## 手順

### 3-1 Q, K, V（3.1）

$$Q = U_1W_q,\quad K = U_1W_k,\quad V = U_1W_v\qquad(3\times4)(4\times4) = 3\times4$$

- U1 が ±1 なので、$Q[t] = \sum_k U_1[t,k]\,W_q[k,:]$ は **Wq の4行を符号どおりに足し引きするだけ** です。U1[t] の符号を Wq の各行の左に書き、縦に足します。掛け算は1回もありません
- **Q の t0 行は計算しません**（記入欄には「—」）。因果マスクで t0 が見られるのは k0 だけなので、1要素の softmax は Q[t0] が何であっても1になるからです。逆伝播でも $dQ$ の t0 行は0です（[derivations.md 問5](derivations.md#問5-スケーリングと因果マスク)）
- K と V は3行とも必要です（k0 と v0 は全クエリから使われます）

### 3-2 スコア（3.2）

$$S_h[t,j] = \frac{Q_h[t]\cdot K_h[j]}{\sqrt2}\ (j\le t),\qquad S_h[t,j] = -\infty\ (j>t)$$

- ヘッド $h$ は列 $2h, 2h+1$ だけを使う（ヘッド0 = d0, d1、ヘッド1 = d2, d3）。$Q_h[t]\cdot K_h[j]$ は **2項の内積**
- まず **素点 $r = Q_h[t]\cdot K_h[j]$ を厳密に** 出します（0.5刻み × 0.5刻みなので 0.25 刻み）。そのあと 0.70711 を1回だけ掛けて S にします
- 計算するのは各ヘッド5成分（t1: k0, k1 / t2: k0, k1, k2）。マスク（−∞）は記入済み。**S の (t0, k0) も不要** です（Q[t0] を使わないため。「—」と書く）

### 3-3 Attention 重み（3.3）

$$A_h[t,j] = \frac{\exp(S_h[t,j]-m_t)}{\sum_{j'\le t}\exp(S_h[t,j']-m_t)},\qquad m_t = \max_{j\le t} S_h[t,j]$$

- **行ごと**（クエリ位置ごと）の softmax。$\exp(-\infty) = 0$ なのでマスク位置は 0*（記入済み）
- **t0 行は計算不要で [1, 0, 0]**
- コツ：$S - m = (r - r_{\max})\times0.70711$ なので、**素点のまま差を取ってから** 0.70711 を掛け、exp します。差は 0.25 刻みの厳密値なので誤差が入りません
- ★ A0, A1 は逆伝播（6.5, 6.6）で再利用します

### 3-4 ヘッド出力と連結（3.4）

$$O_h[t] = \sum_{j\le t} A_h[t,j]\,V_h[j]\quad(3\times2),\qquad O_{\text{cat}} = [\,O_0 \mid O_1\,]\quad(3\times4)$$

- $O_h[t]$ は値ベクトル $V_h[j]$ の **加重平均**。重みは A の **t 行**、混ぜるのは V の **j 行**
- **t0 行は $O_h[t_0] = V_h[t_0]$ を写すだけ**（A の t0 行が [1, 0, 0] だから）
- 連結は O0 を列 d0, d1 に、O1 を列 d2, d3 に並べるだけです。★ Ocat は 6.4 で再利用します

### 3-5 出力射影（3.5）

$$\mathrm{Attn} = O_{\text{cat}}\,W_o\qquad(3\times4)(4\times4) = 3\times4$$

- Ocat の列 d0, d1（ヘッド0）は Wo の行 d0, d1 に、列 d2, d3（ヘッド1）は行 d2, d3 に掛かります
- Wo の0成分と Ocat の0成分を飛ばすと、積は48回中29回で済みます（t0 行は Ocat の2成分だけが0でない）

## 計算する前に予想しよう

1. （3.1 の前に）A0, A1 の t0 行と、O0, O1 の t0 行は何になりますか？
2. （3.1 の後、3.2 の前に）ヘッド0（列 d0, d1）の K の k0 行と k2 行を見比べてください。t2 のクエリが k0 と k2 につけるスコアにはどんな関係がありますか？ A0[t2, k2] はどのくらいになりそうですか？
3. （3.5 の前に）Wo の列 d2 から列 d3 を引くと (−1, 0.5, 0, 0) です。Attn[:, d2] − Attn[:, d3] を O0 で表し、V0 の形を使って A0 で表してください

<details><summary>答え</summary>

1. A の t0 行は両ヘッドとも [1, 0, 0]、$O_h[t_0] = V_h[t_0]$。Q[t0] は結果に影響しません
2. ヘッド0では k2 = −k0 です（(1.5, 1) と (−1.5, −1)）。したがって $S_0[t_2,k_2] = -S_0[t_2,k_0]$。k0 へのスコアが大きな正なら、k2 はほぼ0の重みになります（実際は 0.0004）
3. ヘッド1の行（d2, d3）は列 d2 と d3 で同じ値なので差に効かず、$\mathrm{Attn}[t,d_2]-\mathrm{Attn}[t,d_3] = -O_0[t,d_0] + 0.5\,O_0[t,d_1]$。V0 の行は k0 = (0, 0)、k1 = (1, 2)、k2 = (0, 1) なので、これは **$0.5\,A_0[t,k_2]$** になります。t0, t1 では厳密に0、t2 では 0.5 × 0.0004 だけずれます
</details>

## 検算

- **Q, K, V の行和**：$\mathrm{rowsum}(Q[t]) = U_1[t]\cdot(W_q\mathbf 1)$。U1 が ±1 なので、行和ベクトルの符号付き和です。Wq·1 = (−1, 0, 1.5, −1)、Wk·1 = (−1, −1.5, −1.5, 2)、Wv·1 = (0.5, −0.5, 0.5, 0.5)
- **素点の行和**：$\sum_{j\le t} r_{tj} = Q_h[t]\cdot\big(\sum_{j\le t}K_h[j]\big)$（見えているキーの和との内積、2回の積で済みます）
- **A**：各行の和 = 1、マスク位置 = 0、t0 行 = [1, 0, 0]
- **O**：$\mathrm{rowsum}(O_h[t]) = A_h[t]\cdot\mathrm{rowsum}(V_h)$。また $O_h[t]$ の各成分は、見えている $V_h[j]$（$j\le t$）のその列の最小値と最大値の間に入ります（加重平均だから）
- **Attn**：$\mathrm{rowsum}(\mathrm{Attn}[t]) = O_{\text{cat}}[t]\cdot(W_o\mathbf 1)$、Wo·1 = (0.5, −2, −1, 0)

## よくあるミス

- **ヘッドの列を取り違える**：ヘッド1 は列 d2, d3。S1 に d0, d1 を使ってしまう
- **転置の向き**：$S[t,j]$ は Q の **t 行** と K の **j 行** の内積。K の列を使わない
- **1/√2 を忘れる・2回掛ける・0.707 に丸める**（このワークブックでは 0.70711）
- **softmax を列方向に取る**、またはマスク位置（−∞）を分母に入れる
- **AV の添字**：$O[t] = \sum_j A[t,j]\,V[j]$。$A[t,j]\,V[t]$ にしてしまう
- **符号付き和の符号ミス**：U1[t] の符号を Wq の行の横に必ず書いてから足す
- Wo の **行** ではなく列でヘッドを分けてしまう

## 遅れたときのショートカット

- **優先順位は 3.2 → 3.3（スコアと softmax）** です。ここが Attention の核心なので、両ヘッドとも自分で計算してください
- 遅れている場合：3.1 の Q, K, V は機械的な符号付き和なので [answers.md 3.1](answers.md#31-q-k-v) から写して構いません。さらに遅れたら、3.4 と 3.5 は **t1 行だけ** 計算して残りを写します
- 写した場合も、★の値（Q, K, V, A0, A1, Ocat）は清書用シートに必ず書き込んでください（ステップ6で使います）
