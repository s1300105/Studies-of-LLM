# ステップ4 残差接続 + LayerNorm2 + FFN

**目標**：Attention の出力を残差ストリームに足し（X1）、正規化し（U2）、位置ごとの FFN（4 → 8 → 4、ReLU）を通して、もう一度足します（X2）。初めての「本物の平方根」と、一度も発火しないユニットに出会います。

- **目安時間**：1.75 時間（4.1 5分 / 4.2 30分 / 4.3 40分 / 4.4 20分 / 4.5 5分 / 検算 5分）
- **対応チェックポイント**：4.1 残差接続1、4.2 LayerNorm2、4.3 FFN 1層目 + ReLU、4.4 FFN 2層目、4.5 残差接続2

## 使う値

- [params.md](params.md) の **W1**（4×8、FFN 1層目）と **W2**（8×4、FFN 2層目）
- [ステップ2](step2_embedding_ln1.md) の **2.1 X0**、[ステップ3](step3_attention.md) の **3.5 Attn** と、Attn の行和
- [ステップ1](step1_setup.md) で求めた行和 W1·1, W2·1

## 手順

### 4-1 残差接続1（4.1）

$$X_1 = X_0 + \mathrm{Attn}\qquad(3\times4)$$

- 足すのは **X0**（LN の前の値）です。U1 ではありません（Pre-LN：LN はサブ層の入り口だけで使い、残差ストリームには触れない）
- t0 行は X0, Attn ともに厳密値なので、X1[t0] も厳密値になります

### 4-2 LayerNorm2（4.2）

$$\mu_t = \tfrac14\textstyle\sum_i X_1[t,i],\quad \sigma_t^2 = \tfrac14\textstyle\sum_i (X_1[t,i]-\mu_t)^2,\quad U_2[t,i] = (X_1[t,i]-\mu_t)\cdot\frac{1}{\sigma_t}$$

- **μ は検算から無料で手に入ります**：$\mathrm{rowsum}(X_1) = \mathrm{rowsum}(X_0) + \mathrm{rowsum}(\mathrm{Attn})$ を4で割るだけ
- ここで **初めて本物の平方根** を開きます（3回）。$1/\sigma_t$ を一度だけ計算して記録し、4回の割り算を4回の掛け算に置き換えます
- ★ U2 と σ2 は逆伝播（6.2, 6.3）で再利用します

<details><summary>ヒント：t0 行を厳密に扱う</summary>

X1[t0] は 0.5 刻みで μ = 0 です。σ² も分数で書けるので、$1/\sigma$ は $\sqrt2$ を含む定数になります。U2[t0] を「定数 × 整数ベクトル」の形で持っておくと、4.3 の Z[t0] も「定数 × 整数ベクトル」として厳密に計算でき、最後に1回だけ小数に直せます（ステップ3の「素点を厳密に → 最後に 0.70711」と同じ考え方）。
</details>

### 4-3 FFN 1層目と ReLU（4.3）

$$Z = U_2W_1\quad(3\times4)(4\times8) = 3\times8,\qquad R = \mathrm{ReLU}(Z) = \max(0, Z)$$

- W1 の32成分のうち10個は0なので、積は 96回中 **66回** で済みます。W1 の0を先に鉛筆で消しておきましょう
- ReLU は「負なら0、正ならそのまま」。★ **Z の符号パターン** と R を逆伝播（6.2）で使うので、正の成分に丸をつけておきます

### 4-4 FFN 2層目（4.4）

$$F[t] = \sum_{h:\,R[t,h]>0} R[t,h]\;W_2[h,:]\qquad(3\times8)(8\times4) = 3\times4$$

- **R が0のユニットは丸ごと飛ばせます**（W2 のその行は掛ける必要がない）。W2 の0成分も飛ばすと、積は 96回中 **32回** です
- 各位置で「発火したユニットの W2 の行を、R の値で重みづけして足す」と考えると速く進みます

### 4-5 残差接続2（4.5）

$$X_2 = X_1 + F\qquad(3\times4)$$

- ★ X2 は 6.1 の $dW_{\text{out}} = X_2^\top d\text{logits}$ で再利用します

## 計算する前に予想しよう

1. （4.2 の前に）X1 の t0 行の μ は、σ を計算する前に分かりますか？ X1[t0] は小数になりますか？
2. （4.3 の後に）Z の列のうち、**全位置で負**（ReLU で全部0）になる列を探してください。そのユニットの W1 の列と W2 の行には、逆伝播でどんな勾配が来るでしょう？
3. （4.4 の前に）W2 の列 d1 は (0, 1, 0, 0, 1, 1, −1, 0) です。R の発火パターンを見て、F の d1 列の符号を予想してください

<details><summary>答え</summary>

1. 分かります。Attn[t0] = (−0.5, −1.5, 2, 2) は厳密値で、X1[t0] = (−0.5, −1.5, 1, 1)、行和0なので μ = 0 です。σ² = 1.125 も厳密値です
2. h3 です（Z[:, h3] = (−1.8856, −0.6761, −3.1631)）。ReLU の微分が全位置で0なので、6.2 で **W1 の列 h3 と W2 の行 h3 の勾配はちょうど0** になり、7.1 の更新でも変わりません
3. 3位置とも正です（1.8856, 1.7811, 2.3145）。列 d1 で負なのは h6 だけで、h6 が発火するのは t1 だけ（R = 0.3344）。その t1 でも h1 の R = 2.1155 が上回ります。t0 は h4 + h5、t2 も h4 + h5 の和だけで決まります
</details>

## 検算

- **X1 の行和**：$\mathrm{rowsum}(X_1) = \mathrm{rowsum}(X_0) + \mathrm{rowsum}(\mathrm{Attn})$。rowsum(X0) = (−2, 0, 0)
- **U2 の各行**：平均 = 0、二乗平均 = 1（$\sum_i U_2[t,i]^2 = 4$）
- **Z の行和**：$\mathrm{rowsum}(Z[t]) = U_2[t]\cdot(W_1\mathbf 1)$、W1·1 = (1, 3, −2.5, 1)
- **F の行和**：$\mathrm{rowsum}(F[t]) = R[t]\cdot(W_2\mathbf 1)$、W2·1 = (1.5, 1.5, 3, 2, 1, 0, −4, −1)
- **X2 の行和**：$\mathrm{rowsum}(X_2) = \mathrm{rowsum}(X_1) + \mathrm{rowsum}(F)$
- **R**：すべて ≥ 0。R[t, h] は Z[t, h] か 0 のどちらか

## 見どころ

<details><summary>計算を終えてから開く</summary>

- **初めての本物の平方根**：σ2² = (1.125, 3.6498, 1.4914)、σ2 = (1.0607, 1.9104, 1.2212)。ステップ2の σ1 = (0.5, 2, 1) とは違い、t0 行も $\sqrt{1.125} = 3/(2\sqrt2)$ という無理数です
- **t0 行は √2 の倍数で書ける**：U2[t0] = (√2/3)·(−1, −3, 2, 2) = (−0.4714, −1.4142, 0.9428, 0.9428)、Z[t0] = (√2/6)·(−5, −2, −8, −8, 5, 3, −9, −2)、F[t0] = (√2/6)·(−1, 8, 2, −4)。ヒントの方法で計算すると誤差0で通過できます
- **死んだユニット h3**：W1 の列 h3 = (−1, 1, 0, −1) で、Z[:, h3] = (−1.8856, −0.6761, −3.1631) と全位置で負。勾配が来ないので更新されず、7.3 の再順伝播でも Z'[:, h3] = (−0.6138, −0.7650, −1.4857) と死んだままです
- **ReLU の発火パターン**：t0 は h4, h5（2個）、t1 は h1, h6, h7（3個）、t2 は h0, h2, h4, h5, h7（5個）で、24個中10個だけが発火します。7.3 の再順伝播でも **同じパターン** になります
- **FFN は d1 を押し上げる**：F[:, d1] = (1.8856, 1.7811, 2.3145) と全位置で大きな正の値です
- **残差の素通り**：X1 は X0 の大きさを保っています。例えば t1 の X1 = (1.5822, −1.9733, 1.2768, −2.7232) は、X0[t1] = (2, −2, 2, −2) の形がほぼ残っています
</details>

## よくあるミス

- **残差に U1 を足す**（正しくは X1 = X0 + Attn、X2 = X1 + F）
- **標本分散（÷3）**、**μ の引き忘れ**（t1 は μ = −0.4594、t2 は μ = 0.0666 で0ではありません）、**σ² で割る**
- ReLU の前の Z を記録せずに R だけ書く（逆伝播で Z の符号が要ります）。負の Z を R にそのまま写す
- F の計算で、R = 0 のユニットの W2 の行まで足してしまう（結果は同じでも時間を失います）。逆に、発火したユニットを1つ見落とす
- W1 の **列** h が Z の列 h に対応する（W1 の行ではない）

## 遅れたときのショートカット

- 4.1 と 4.5 は足し算だけなので必ず自分でやります
- 遅れている場合は [answers.md 4.2](answers.md#42-layernorm2) から U2 を写し、**4.3 の Z と ReLU パターンは自分で** 計算します（h3 が死ぬ様子はここでしか見られません）
- さらに遅れたら、4.4 の F は **t0 行だけ**（厳密値で速い）計算して、残りを [answers.md 4.4](answers.md#44-ffn-2層目) から写します
- 写した場合も、★の値（U2, σ2, Z の符号, R, X2）は清書用シートに必ず書き込んでください
