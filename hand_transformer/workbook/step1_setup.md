### 1-1 計算グラフを描く（20分）

A3 用紙1枚に、次の式だけを見てグラフを描きます（行ベクトル規約、ヘッド $h$ は列 $2h, 2h+1$）。

$X_0 = E[\text{ids}] + P$, $U_1 = \mathrm{LN}(X_0)$, $Q, K, V = U_1W_q,\ U_1W_k,\ U_1W_v$, $S_h = Q_hK_h^\top/\sqrt2$（マスク付き）, $A_h = \mathrm{softmax}(S_h)$, $O_h = A_hV_h$, $\mathrm{Attn} = [O_0|O_1]W_o$, $X_1 = X_0 + \mathrm{Attn}$, $U_2 = \mathrm{LN}(X_1)$, $Z = U_2W_1$, $R = \mathrm{ReLU}(Z)$, $X_2 = X_1 + RW_2$, $\text{logits} = X_2W_{\text{out}}$, $p = \mathrm{softmax}$, $L = \frac13\sum_t -\log p[t, y_t]$

- 各ノードに **名前・形・チェックポイント番号** を書く（例：`U1 3×4 (2.3)`）。パラメータは四角で囲む
- 1つの値が2か所以上で使われる所（**分岐点**）に ● をつける
- 逆伝播でもう一度使う値に ★ をつける（1-2 で答え合わせ）

### 1-2 分岐点と ★ を確認する（10分）

分岐点では、逆伝播で **各経路から来た勾配を足し合わせます**（[derivations.md 問2](derivations.md#問2-分岐と残差接続)）。

| 分岐点 | 行き先 | 逆伝播で合流する所 |
|---|---|---|
| X0 | LN1 と 残差 | 6.8 $dX_0 = dX_1 + (\text{LN1経由})$ |
| U1 | Wq, Wk, Wv の3本 | 6.7 $dU_1 = dQ\,W_q^\top + dK\,W_k^\top + dV\,W_v^\top$ |
| X1 | LN2 と 残差 | 6.3 $dX_1 = dX_2 + (\text{LN2経由})$ |

目に見えない分岐もあります：**重みは3位置で共有**されるので $dW$ は3位置分の和、K・V の各行は複数のクエリに使われるので $dK, dV$ はクエリ方向の和になります。

### 1-3 精度と検算のルールを決める（10分）

ワークブック全体で次のルールを守ります。ルールを紙の1枚目に書き写してください。

1. **記録は有効数字4桁**。ただし内積は電卓のメモリ（`M+`）に積み上げ、**途中で丸めない**
2. $1/\sqrt2 = 0.70711$。スコアは $QK^\top$ を（0.25刻みの）**厳密値で出してから最後に1回だけ** 0.70711 を掛ける
3. softmax は **行の最大値を引いてから** exp。損失は $\text{nll} = \mathrm{logsumexp} - \text{logit}_{\text{正解}}$
4. **許容誤差** $|\text{手} - \text{解答}| \le 0.002 + 0.002\cdot|\text{解答}|$
5. 外れたら **最大10分** 探す。見つからなければ [answers.md](answers.md) の値で **上書き** し、誤差ログに書いて先へ進む（誤差を下流へ伝播させない）
6. 行列積を1つ終えるたびに **行和チェックサム**（1-4）を取る

### 1-4 行和 W·1 と列和 1ᵀW を前計算する（15分）

$Y = XW$ の各行の和は、$X$ の行と「$W$ の行和ベクトル」の内積です。逆伝播 $dX = dY\,W^\top$ では $W$ の **列和** を使います（[derivations.md](derivations.md#行列積のチェックサムどの行列積にも使える)）。

$$\textstyle\sum_j (XW)_{tj} = x_t\cdot(W\mathbf 1),\qquad \sum_k (dY\,W^\top)_{tk} = dy_t\cdot(\mathbf 1^\top W)^\top$$

パラメータカード（1-5）の **各行の右に行和、各列の下に列和** を書き込みます。0.5刻みなので暗算でできます。

## 計算する前に予想しよう

1. 180個のパラメータのうち、データを見ただけで「勾配がちょうど0」と分かるのはどれでしょう？
2. 位置 t0（`<s>`）の Attention 重みは計算する必要がありますか？ そこから、計算しなくてよい行列の行が分かりますか？
3. 行和チェックサムでは **見つけられない** ミスはどんなミスでしょう？

<details><summary>答え</summary>

1. 入力に現れない `鳴く`・`。` の埋め込み E の行（8個）。順伝播をしてみると、FFN に一度も発火しないユニットが見つかり（ステップ4）、その W1 の列と W2 の行（計8個）も0になります。`mini_gpt.py` で数えると、ちょうど0の勾配は E 8個 + W1 4個 + W2 4個 = **16個** です。
2. 不要です。因果マスクで t0 が見られるのは自分（k0）だけなので、1要素の softmax は必ず1、A の t0 行は両ヘッドとも [1, 0, 0] です。したがって **Q の t0 行はどこにも使われません**（逆伝播でも $dQ$ の t0 行は0）。
3. 同じ行の中で **値を隣の列に書き間違えた** ミス（和は変わらない）と、同じ行で誤差が打ち消し合うミス。行和は「その行のどこかが違う」ことしか教えてくれません。列の取り違えは、LN 出力の「平均0・二乗平均1」や softmax の「行和1」など各ステップの不変量で補います。
</details>

## 検算

- 行和の合計と列和の合計は、どちらも行列の **全成分の総和** に一致します。2通りで出して一致すれば、どちらの和も正しいと思ってよいでしょう
- 成分がすべて 0.5 の倍数なので、行和・列和も 0.5 の倍数になります（そうでなければ写し間違い）
- グラフの各ノードで、行列積の内側の次元がそろっているか（例：Ocat 3×4 と Wo 4×4）

## 見どころ

<details><summary>計算を終えてから開く</summary>

- **Wout は20成分のうち14個が0**。特に `鳴く` の列はすべて0（列和も0）なので、最初の順伝播では logit[鳴く] が全位置で0になります（ステップ5で意味を考えます）

- W2 の h6 行はすべて −1（行和 −4）、h5 行は行和0。行和0の行は、ReLU 後の値が何であっても F の行和に寄与しません
- 0 と ±1 が多いのは、掛け算を減らすための設計です（[../README.md](../README.md) の「初期値」の行）
</details>

## よくあるミス

- **行和と列和の取り違え**：W·1 は「各行を横に足した」縦ベクトル（長さ = 行数）。1ᵀW は「各列を縦に足した」横ベクトル（長さ = 列数）
- **ヘッドの列**：ヘッド0 = Q, K, V の列 d0, d1 と **Wo の行** d0, d1。ヘッド1 = 列 d2, d3 と Wo の行 d2, d3
- **逆伝播の途中で重みを更新してしまう**：6.x はすべて **更新前** の重みを使います。更新は 7.1 で一度に
- ★をつけ忘れ、逆伝播のときに値を探し回る（または計算し直す）
