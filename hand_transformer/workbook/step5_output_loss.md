# ステップ5 出力層・softmax・損失

> 標準・完全コース：このステップの前に [Part 0](../part0/README.md#2-順番と時間) の D5 softmax + 交差エントロピー（40分） をやっておきます。

**目標**：X2 から各位置の「次のトークン」の確率を出し、損失 L を求めます。最初の予測がどれだけ外れているかを数字で確かめ、ステップ6（逆伝播）の出発点を作ります。

- **目安時間**：0.75 時間（5.1 10分 / 5.2 20分 / 5.3 10分 / 検算と振り返り 5分）
- **対応チェックポイント**：5.1 ロジット、5.2 softmax、5.3 損失

## 使う値

- [params.md](params.md) の **Wout**（4×5、列 = トークン `<s>`, `猫`, `が`, `鳴く`, `。`）
- [ステップ4](step4_residual_ln_ffn.md) の **4.5 X2**
- 正解 y = (`猫`, `が`, `鳴く`)：位置 t の正解は **次の** トークン
- [ステップ1](step1_setup.md) で求めた行和 Wout·1 = (−0.5, −0.5, 0.5, −1)

## 手順

### 5-1 ロジット（5.1）

$$\text{logits} = X_2W_{\text{out}}\qquad(3\times4)(4\times5) = 3\times5$$

- Wout は20成分のうち14個が0です。掛け算は1行6回（3行で18回）、しかもすべて ×0.5 か ×1 です
- **`鳴く` の列は計算不要**：Wout の `鳴く` 列がすべて0なので、logit[t, 鳴く] = 0（全位置）

<details><summary>ヒント：Wout を読んで式にする</summary>

X2[t] = (x0, x1, x2, x3) とすると、Wout の0でない成分だけを拾って

logit[`<s>`] = 0.5·x2 − x3、logit[`猫`] = −0.5·x0、logit[`が`] = −0.5·x1 − 0.5·x3、logit[`鳴く`] = 0、logit[`。`] = 0.5·x3
</details>

### 5-2 softmax（5.2）

$$m_t = \max_j \text{logit}[t,j],\qquad e_{tj} = \exp(\text{logit}[t,j]-m_t),\qquad p[t,j] = e_{tj}\Big/\textstyle\sum_{j'} e_{tj'}$$

- **行ごと**（位置ごと、語彙5個の上で）の softmax。最大値の成分は $e = 1$ なので、exp は1行4回（計12回）
- $\sum_j e_{tj}$ は 5.3 でも使うので記録しておきます
- ★ p は 6.1 の $d\text{logits} = (p - y)/3$ で再利用します。**各行の argmax（予測）** にも印をつけます

### 5-3 損失（5.3）

$$\mathrm{LSE}_t = m_t + \ln\textstyle\sum_j e_{tj},\qquad \text{nll}_t = \mathrm{LSE}_t - \text{logit}[t, y_t],\qquad L = \tfrac13\textstyle\sum_t \text{nll}_t$$

- $-\ln p$ を直接取らずに **logsumexp** を使うのは、丸めた小さな確率の対数を取って誤差を増やさないためです。5.2 の和をそのまま再利用でき、ln は1行1回で済みます
- 対数は **自然対数**（電卓の `ln`。`log` は常用対数のことがあるので注意）
- L は3位置の **平均**（和ではない）

## 計算する前に予想しよう

1. Wout を見て、logit[t, 鳴く] は何になりますか？ それは `鳴く` を予測するうえで問題でしょうか？
2. 5語を一様に予測したときの損失は $\ln 5$ です。最初の L はこれより大きいでしょうか、小さいでしょうか？
3. （5.1 の後に）softmax を計算する前に、各位置の予測（argmax）が分かりますか？ 正解と比べてみてください

<details><summary>答え</summary>

1. 全位置で0です。問題ありません。softmax は全ロジットに同じ数を足しても変わらない（$\mathrm{softmax}(z + c) = \mathrm{softmax}(z)$）ので、意味があるのは **ロジットの差** だけです。`鳴く` の logit を基準点の0に固定しても、他のロジットを下げれば `鳴く` の確率はいくらでも大きくできます。しかも列が0でも勾配 $dW_{\text{out}}[:, \text{鳴く}] = X_2^\top(p[:, \text{鳴く}] - y[:, \text{鳴く}])/3$ は0になりません。勾配が出ないのは「入力に現れない埋め込み行」のほうです
2. 小さくなります（L = 1.3949 < ln 5 = 1.6094）。予測はすべて外れていますが、正解の確率は3位置とも 0.2 を上回っています（詳しくは見どころ）
3. 分かります。softmax は順序を変えないので、argmax(p) = argmax(logits)。予測は (`<s>`, `<s>`, `。`) で、正解 (`猫`, `が`, `鳴く`) に対して **全部ハズレ** です
</details>

## 検算

- **ロジットの行和**：$\mathrm{rowsum}(\text{logits}[t]) = X_2[t]\cdot(W_{\text{out}}\mathbf 1)$、Wout·1 = (−0.5, −0.5, 0.5, −1)
- **`鳴く` 列**：厳密に0
- **p**：各行の和 = 1、すべて0より大きい、argmax(p) = argmax(logits)
- **nll の2通り計算**：$\text{nll}_t = -\ln p[t, y_t]$ とも一致すること（4桁の p から計算すると末尾が少しずれます）
- **L**：3つの nll の最小値と最大値の間にあること

| 検算 | t0 | t1 | t2 |
|---|---:|---:|---:|
| rowsum(logits) | 0.8536 | 1.1580 | −1.7018 |
| $\sum_j e_{tj}$ | 3.1690 | 2.0845 | 2.5295 |
| LSE | 1.8319 | 2.1532 | 1.4015 |
</details>

## 見どころ

<details><summary>計算を終えてから開く</summary>

- **予測は全部ハズレ、でも損失は一様より小さい**：予測 (`<s>`, `<s>`, `。`)、正解の確率は p[t0, 猫] = 0.2313、p[t1, が] = 0.2674、p[t2, 鳴く] = 0.2462 で、どれも 1/5 = 0.2 を超えています。そのため nll = (1.4641, 1.3190, 1.4015)、L = 1.3949 は ln 5 = 1.6094 より小さくなります
- **t2 では nll = LSE**：正解 `鳴く` の logit が0なので、nll[t2] = LSE[t2] = 1.4015 です
- **`鳴く` 列は1ステップで動き出す**：7.1 で Wout' の `鳴く` 列は (0.3373, 0.1518, 0.0373, 0.2920) になり、7.3 では logit'[t2, 鳴く] = 2.4339、p'[t2, 鳴く] = 0.9062 です
- **ロジットは残差ストリームの成分の和に分解できる**（最終 LN が無いため。`python3 mini_gpt.py --decompose`）。例えば t1 行の `<s>` のロジット 1.4187 は、直接経路（X0·Wout）3 ＋ ヘッド0 0.7428 ＋ ヘッド1 −0.3812 ＋ FFN −1.9429 です。直接経路だけのロジットは t0 = (0.5, 0, 0.5, 0, −0.5)、t1 = (3, −1, 2, 0, −1)、t2 = (−1.5, −0.5, 0, 0, 0.5) で、この時点ではどの位置でも正解が1位ではありません
- **このタスクはバイグラムで解ける**：`<s>→猫`、`猫→が`、`が→鳴く` は **今のトークンだけ** で次が決まるので、理屈の上では Attention が無くても直接経路（E と Wout）だけで解けます。Attention が本当に必要なタスクは発展課題 [../extras/two_sentences.py](../extras/two_sentences.py) で確かめます
</details>

## よくあるミス

- softmax を **列方向**（位置方向）に取る。正しくは行ごと（語彙方向）
- 正解の列を間違える：位置 t の正解は **次の** トークン（t0 なら `猫`）。入力トークンの列や argmax の列ではありません
- `ln` の代わりに常用対数 `log` を使う
- L を3で割り忘れる（平均であって和ではない）
- 4桁に丸めた p から $-\ln p$ を取り、小さな確率で誤差を大きくする（logsumexp を使えば避けられます）

## 遅れたときのショートカット

ここは短く、しかも **L と p がステップ6すべての出発点** なので、省略しないことを強くすすめます。
どうしても遅れている場合は、[answers.md 5.1](answers.md#51-ロジット) からロジットを写し、**5.2 と 5.3 は少なくとも1行（t2 がおすすめ：nll = LSE）を自分で** 計算して、残りを写します。p は6.1で使うので3行とも清書用シートに書き込んでください。
