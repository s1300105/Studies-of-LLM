# C 順伝播を読む（5.4–5.5）

**目標**：B で出した数字を「読み」ます。① **文脈の差 C** で、モデルが猫文と犬文の t2 を区別しているかを1つの数で測る。② t2 の Attention 出力を消す **アブレーション** で、A3 の証明を数字で確かめる。③ ヘッドごとの違いを **パターン項**（どこを見るかの違い）と **値項**（何を運ぶかの違い）に分ける。④ **パッチング**（あるヘッドの出力を、もう一方の文のものに差し替える）で、そのヘッドが答えをどれだけ動かすかを測り、直接効果と比べる。どれも D〜F と、実際の解釈可能性研究で使う道具です。

- **目安時間**：2 時間（C0 予想 10分 / C1 15分 / C2 20分 / C3 35分 / C4 30分 / 検算と照合 10分）
- **対応チェックポイント**：5.4 文脈の使い分けとアブレーション、5.5 ヘッドの寄与の分解（パターン項・値項・直接効果・パッチングの総効果）

## 手順

### C0 予想を書く（10分）

下の「計算する前に予想しよう」の6問に、**計算を始める前に** 予想を書きます。書いた予想は答えを見ても消さないでください。予想と結果のずれが、このセクションで一番の学びになります。

### C1 文脈の差 C（5.4 前半）— 15分

文 s の t2 での「鳴く − 吠える」の logit 差を $\mathrm{gap}_s$ と書きます。

$$\mathrm{gap}_s = \ell_{\text{鳴く}}(s, t_2) - \ell_{\text{吠える}}(s, t_2),\qquad C = \mathrm{gap}_{\text{猫文}} - \mathrm{gap}_{\text{犬文}}$$

- logits = X2 Wout なので、$\mathrm{gap}_s = X_2[s,t_2]\cdot r$。ここで $r = W_{out}[:,\text{鳴く}] - W_{out}[:,\text{吠える}]$（4成分の **読み出しベクトル**）です。params.md から r を書き出し、X2 の t2 行との内積でも gap を求めて、5.1 の logits から引いた値と一致することを確かめます
- **C の意味**：C > 0 なら、猫文では犬文より「鳴く」寄りに推しています。t2 の入力は2文で同じなので、C ≠ 0 になれるのは Attention が t1 から違う情報を運んだときだけです（A3）。C は「正解の確率が高いか」ではなく **2文を区別しているか** を測ります
- ミラー規則（logits の列の入れ替え）から $\mathrm{gap}_{\text{犬文}} = -\mathrm{gap}_{\text{猫文}}$、したがって $C = 2\,\mathrm{gap}_{\text{猫文}}$ です。犬文の gap は計算せずに出せます

### C2 アブレーション（5.4 後半）— 20分

$$X_1[t_2] := X_0[t_2]\qquad(\text{つまり } \mathrm{Attn}[t_2] := 0)$$

として、LN2 → FFN → X2 → logits を2文の t2 で計算し直します。

- X0[t2] は2文で同じなので、計算は1回だけです（2行とも同じ値を書く。これが A3 の証明そのものです）
- 手順は B5〜B6 と同じです。B の t2 行の値と比べて、何が変わりましたか？（予想2）
- **読み方**：アブレーションは「この部品を消したら何が変わるか」を見る道具です。ここで何も変わらないなら、Attention の出力は t2 では（合計として）何もしていないことになります。ところが C3 で見るとおり、個々のヘッドは仕事をしています。**合計を消す実験では、打ち消し合う部品は見えません**

### C3 パターン項と値項（5.5 前半）— 35分

ヘッド h の、2文の t2 での出力の差 $\Delta O_h = O_h[\text{猫文},t_2] - O_h[\text{犬文},t_2]$（2成分）を分解します。$a_{\text{猫}}$ は猫文 t2 の Attention 重みの行（k0, k1, k2 の3つ）、$V_{\text{猫}}$ は猫文の $V_h$（3行×2列）です（犬も同様）。

$$\Delta O_h = a_{\text{猫}}V_{\text{猫}} - a_{\text{犬}}V_{\text{犬}} = \underbrace{(a_{\text{猫}} - a_{\text{犬}})\,V_{\text{猫}}}_{\text{パターン項}} + \underbrace{a_{\text{犬}}\,(V_{\text{猫}} - V_{\text{犬}})}_{\text{値項}}$$

（右辺を展開すると左辺に戻ることを、最初に1行で確かめてください。）

- **gap への射影**：ヘッド h の出力は Wo のヘッド h の行（$W_{o,h}$、2行×4列）で残差ストリームに入り、r で gap に読まれます。$w_h = W_{o,h}\,r$（2成分）を先に求めておくと、各項は2成分の内積1回です

  $$\text{パターン項}_h = (a_{\text{猫}} - a_{\text{犬}})\,V_{\text{猫}}\,w_h,\qquad \text{値項}_h = a_{\text{犬}}\,(V_{\text{猫}} - V_{\text{犬}})\,w_h,\qquad \text{直接効果}_h = \Delta O_h\cdot w_h$$

- **パターン項は計算しません**：A6 より $a_{\text{猫}} = a_{\text{犬}}$ なので厳密に0です。3.3 の t2 行で2文が等しいことを確かめて、0 と書きます
- **値項は1項だけ**：$V_{\text{猫}} - V_{\text{犬}}$ は t0 と t2 の行が0です（A1、A2）。残るのは $a_{\text{犬}}[k_1]\,(V_{\text{猫}}[t_1] - V_{\text{犬}}[t_1])\cdot w_h$ だけです
- **直接効果**は 3.4 の O の t2 行から直接計算し、パターン項 ＋ 値項 と一致することを確かめます（恒等式なので、ずれたら計算ミス）
- 2つのヘッドの直接効果の和を C と比べます。この重みでは **ちょうど一致します**（理由は「検算」で）

### C4 パッチング（5.5 後半）— 30分

**ヘッド h のパッチング**：猫文 t2 の計算で、ヘッド h の出力 $O_h[\text{猫文},t_2]$ だけを犬文 t2 のもの $O_h[\text{犬文},t_2]$ に差し替え、もう一方のヘッドはそのままにして、**その行の残り**（Ocat → Wo → 残差 → LN2 → FFN → X2 → logits）を計算し直します。

$$\text{総効果}_h = \mathrm{gap}_{\text{猫文}} - \mathrm{gap}_{\text{猫文}}^{\,\text{パッチ後}}$$

- 直接効果は「Wo → 残差 → Wout」の **直接の道だけ** を通した効果です。総効果は LN2 → FFN を通る道も含めた、実際の変化です。差があれば、それが FFN 経由の **間接効果** です
- まずヘッド0 を手で計算します。差し替えた後の X1 の t2 行は、d0, d1 が ±1 ではなくなるので、**LN2 の σ も計算し直し** です（下の記入欄の「途中経過」の表を使います）
- ヘッド1 は、ヘッド0 の結果にミラーを当てて求めます（d0 と d1 の役割が入れ替わるだけ）。余裕があれば手で計算して確かめます
- **読み方**：総効果と直接効果を比べます。等しいなら、このモデルでは FFN が gap を動かせないということです。なぜでしょう？ W2 の列を見て理由を探します（予想5）

## 検算

- **ミラー**：$\mathrm{gap}_{\text{犬文}} = -\mathrm{gap}_{\text{猫文}}$、$C = 2\,\mathrm{gap}_{\text{猫文}}$。ヘッド1 の各項は、ヘッド0 の各項と大きさが同じで符号が逆（この初期値では）
- **恒等式**：パターン項 ＋ 値項 ＝ 直接効果（ヘッドごと）
- **C ＝ 直接効果の和**：$\mathrm{gap}(t_2) = X_2[t_2]\cdot r = (X_0[t_2] + \mathrm{Attn}[t_2] + F[t_2])\cdot r$ です。r は d0 と d1 で符号が逆で d2, d3 は0、一方 X0[t2]（が の t2）と F（W2 の d0 列 = d1 列）はいつも d0 = d1 なので、$X_0[t_2]\cdot r = F[t_2]\cdot r = 0$。残るのは $\mathrm{Attn}[t_2]\cdot r = \sum_h O_h[t_2]\,w_h$ だけで、2文で引くと $C = \sum_h \text{直接効果}_h$ になります。ミラー対称性が保たれるので、更新後もこの等式は成り立ちます
- **総効果 ＝ 直接効果**：同じ理由で、FFN 経由の道は gap に何も足しません
- **アブレーション**：2行が完全に等しい（A3）
- **パッチング**：差し替えた X1 の行も各成分の和は0（μ = 0）。LN2 の出力は和0・二乗和4

## よくあるミス

- **gap の向き**：「鳴く − 吠える」、C は「猫文 − 犬文」。逆にすると符号が全部反転します
- **分解の式の取り違え**：パターン項の $(a_{\text{猫}} - a_{\text{犬}})$ に掛けるのは $V_{\text{猫}}$、値項の $(V_{\text{猫}} - V_{\text{犬}})$ に掛けるのは $a_{\text{犬}}$ です。$(a_{\text{猫}} - a_{\text{犬}})V_{\text{犬}} + a_{\text{猫}}(V_{\text{猫}} - V_{\text{犬}})$ という分け方もありえて、一般には2つの項の値が変わります（この初期値ではパターン項が0なので同じ）。このワークブックとコードは上の式に統一しています
- **アブレーションで X1[t2] を0にする**：0 にするのは Attn[t2] だけで、残差の X0[t2] は残します
- **パッチングで X1 の行を丸ごと差し替える**：差し替えるのは **ヘッド h の O だけ**（2成分）。もう一方のヘッドの O と、残差の X0 はそのままです
- **パッチ後に LN2 を計算し直さない**：σ が変わります。gap は結果的に変わりませんが、それは計算して初めて言えることです
- **総効果の向き**：総効果 = 元の gap − パッチ後の gap。「パッチ後 − 元」にすると符号が逆になります
- **「C = 0 だから Attention は何もしていない」と結論する**：各ヘッドは ±4.0279 を運んでいます。合計だけを見ると、仕組みを見落とします

## 遅れたときのショートカット

- **必ず自分で**：C1（C と gap の読み出し）、C3 のヘッド0 の値項と直接効果、C4 のヘッド0 のパッチング。この3つが F（回路）と E（更新後の比較）で使われます
- 遅れている場合：C2 は「A3 より2行は等しく、Attn[t2] = 0 なので B の t2 行と同じ」と書いて、[answers.md 5.4](answers.md#54-文脈の使い分けとアブレーション) で確かめるだけにします（5分）。ヘッド1 はすべてミラーで符号を反転して書きます
- C4 の時短：「F·r = 0 だから パッチ後の gap = 元の gap − 直接効果」と先に言えるなら、LN2 の再計算は σ だけにして FFN を飛ばしても構いません。ただし、ほかの logit が動くことを一度は確かめてください
