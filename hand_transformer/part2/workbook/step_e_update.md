## 手順

始める前に、下の「計算する前に予想しよう」の3問に、自分の予想を書いておいてください。

### 7.1 更新（lr = 1 なので引き算だけ）

1. **θ' = θ − lr·dθ = θ − dθ** を188個に行います。勾配の **逆** 向きに動かすので、符号に注意してください。
2. **ミラーで半分にする**：更新後のパラメータもミラーで変わりません（[A5](step_a_map.md#a5-ミラー対称性とsgd-がそれを保つ理由13分) (c)）。D の準備 (b) の表と同じ組が等しいので、**独立な125個だけを計算し、63個は写します**。
3. **計算しなくてよいもの**：勾配が厳密に0の **60個** は変わりません。E の 鳴く・吠える 行（8個）、Wq と Wk の d1, d3 列（各8個）、Wo の d2, d3 列（8個）、W1 の h2〜h6 列（20個）、W2 の d2 列（8個）です。
4. **符号反転だけのもの**：θ = 0 で勾配が0でない **82個** は θ' = −dθ です（引き算は要りません）。本当に引き算が要るのは **46個**（独立なものは32個）だけです。
5. **X0' の近道（検算用）**：Part 1 の「X0' = X0 − 2·dX0」は Part 2 では **t1 で成り立ちません**。E と P が受け取る勾配が違うからです（P の t1 行は2文の和、E の 猫 行は猫文だけ）。

   $$X_0'[t_0] = X_0[t_0] - 2\,dP[t_0],\qquad X_0'[t_2] = X_0[t_2] - 2\,dP[t_2],\qquad X_0'[\text{猫}t_1] = X_0[\text{猫}t_1] - dE[\text{猫}] - dP[t_1]$$

   この式で X0' の3行を求め、E'[ids] + P' と一致するかで検算します。

### 7.2 1次予測（再順伝播の前に！）

Part 1 と同じく、$L(\theta - \eta g) \approx L(\theta) - \eta\,\lVert g\rVert^2$ です（[derivations.md 問9](../../workbook/derivations.md)）。

1. パラメータ群ごとに勾配の二乗和を求めます（x² → M+）。0 のマスは飛ばし、ミラーの組（準備 (b)）は **1回だけ二乗して M+ を2回** 押します。二乗するのは独立で0でない **82個** だけです。
2. **Part 1 の近道は使えません**：Part 1 では ‖dE‖² = ‖dP‖² でしたが、Part 2 では dP の t1 行が2文の和なので等しくありません。

### 7.3 再順伝播（核：t2 に必要な分だけ）

**なぜ t2 だけでよいか**：因果マスクにより、t2 の出力に必要なのは **同じ文の t0, t1, t2 のキーと値** と、**t2 自身のクエリ** だけです。Attention の後（Wo、残差、LN2、FFN、Wout、softmax）は行ごとの計算です。さらに、t0 と t2 の行は Attention に入るまで2文で同じ（A1, A2）、犬文 t1 は猫文 t1 のミラーです。

| 量 | 計算する行（核） | 理由 |
|---|---|---|
| X0', LN1', U1' | t0、猫文 t1、t2 の **3行** | K', V' に3つの位置すべてが要る。犬文 t1 はミラー |
| Q' | **t2 だけ** | 使うのは t2 のクエリだけ（t0 は「—」、t1 は核では不要） |
| K' | t0、t1、t2 の3行 | 犬文 t1 は猫文 t1 と同じ（Q・K の空間はそのまま） |
| V' | t0、猫文 t1、t2 の3行 | 犬文 t1 はヘッド内の入れ替え |
| S'、A'（各ヘッド、猫文ブロック） | **t2 の行だけ** | 犬文ブロックは猫文ブロックと同じ（A6） |
| Ocat'、Attn'、X1'、LN2'、U2'、Z'、F'、X2'、logits'、p'、−log p' | **猫文 t2 だけ** | 犬文 t2 はミラー（logits' と p' は 猫↔犬・鳴く↔吠える を入れ替える） |

**1回目の工夫のうち、まだ使えるもの**（コードで確認）

- Wq' と Wk' の d1, d3 列は0のまま（勾配が0だった）。Q', K' は各ヘッド1列だけで、**スコアは各ヘッド積1回**：$S'_h[t_2,j] = Q'[t_2,d_{2h}]\,K'[j,d_{2h}]/\sqrt2$
- Wo' の d2, d3 列は0のまま → Attn' の d2, d3 列は0
- Z' の符号パターンは1回目と同じ（|Z'| の最小値は 0.6678）。t2 で発火するのは h3 と h7 だけなので、F'[t2] は W2' の h3 行と h7 行だけから作れます。W2' の d2 列は0のまま
- A' の t0 行は [1, 0, 0] のまま（Q' の t0 行は不要）

**もう使えないもの**：U1' は ±1 ではなく、LN1' の μ' も0ではありません（σ' も1ではない）。K' と V' の t0 行・t2 行は、もう0ではありません。重みもすべて4桁の小数です。

手順（記入欄の 7.3 のうち、上の表の行だけを埋めます）：

1. **X0'**：E'[ids] + P' を3行。7.1 の近道の値と照合します。
2. **LN1'**：3行それぞれ μ'、σ'²、σ' を求め、U1' = (X0' − μ')/σ'。
3. **Q'[t2]**（2列）、**K'**（3行 × 2列）、**V'**（3行 × 4列）。
4. **S'、A'**：各ヘッドで t2 行の3つのスコア（積1回ずつ）→ softmax。
5. **O'[猫文 t2]**：各ヘッド $O'_h[t_2] = \sum_j A'_h[t_2,j]\,V'_h[j]$（3項 × 2列）。並べて Ocat'。
6. **Attn'[猫文 t2] = Ocat' Wo'**（d0, d1 列だけ）、**X1' = X0' + Attn'**、**LN2'**、**Z' = U2' W1'**、**R'**、**F' = R' W2'**、**X2' = X1' + F'**。
7. **logits' = X2' Wout'**（6列）、**p'**、**−log p'[正解]**（Part 1 と同じく logsumexp − 正解の logit' の形で）。
8. **犬文 t2**：logits' と p' をミラーで写します（猫↔犬、鳴く↔吠える）。−log p' は同じ値です。

### 7.3 全行（任意・全部コース）

- **t0 を最後まで**（約32分）：X0'[t0]、U1'[t0]、V'[t0] は核ですでに求めています。A' の t0 行が [1, 0, 0] なので O'[t0] = V'[t0]、そこから Attn'[t0] → … → p'[t0] は1本道です。t0 の **p'(猫) = p'(犬)** を自分の手で見られます（予想3）

- 犬文の行はすべてミラーで写します。[answers.md の 7.3](answers.md#73-再順伝播) で行ごとに照合しながら進めてください

### 7.4 比較

1. **L'**：6行の −log p' の平均です。核では t2 の −log p' だけを自分で求めたので、t0 と t1 の値は [answers.md の 7.3](answers.md#73-再順伝播) の「−log p'[正解]」から取ります（全行をやった人は自分の値で）。**実際の ΔL = L' − L** を 7.2 の予測と並べ、比（実際 ／ 予測）を出します。
2. **正解トークンの確率** の表を埋め、t2 の argmax が2文でそれぞれ正しい動詞になったかを確かめます。
3. **t2 の (鳴く − 吠える)'**：猫文 t2 の logit' の差を求めます。犬文 t2 はミラーで符号が反転するので、**C' = 2 ×（猫文 t2 の差）** です。
4. **ヘッドごとの寄与'**（5.5 と同じ4列。定義は [C 順伝播を読む](step_c_read.md) と同じ）：
   - **パターン項**：A' の猫文ブロックと犬文ブロックが等しいので **厳密に0**
   - **値項 ＝ 直接効果**：$r' = W_{out}'[:,\text{鳴く}] - W_{out}'[:,\text{吠える}]$ とすると $(O'_h[\text{猫}t_2] - O'_h[\text{犬}t_2])\cdot(W'_{o,h}\, r')$。r' は (a, −a, 0, 0) の形で、$W'_{o,h} r'$ は (w, −w) の形になる（ミラー）ので、ヘッドの2列を a, b として **$2w\,(O'_h[\text{猫}t_2,a] - O'_h[\text{猫}t_2,b])$**
   - **パッチングの総効果 ＝ 直接効果**：差し替えの影響は LN2 → FFN も通りますが、FFN の出力 F' はいつも d0 = d1（W2' の d0 列 = d1 列）で、r' = (a, −a, 0, 0) との内積が0なので、(鳴く − 吠える) には何も足せません。さらに t2 の X0' は2文で同じなので、**2つのヘッドの直接効果の和が、そのまま C' になります**
5. （任意）**アブレーション'**：t2 の Attention 出力を0にして X1 = X0'[t2] とします。**LN2 はやり直さなくてよく**、U2 = U1'[t2]（同じ行の正規化だから）。Z = U1'[t2] W1' → R → F → X2 = X0'[t2] + F → logits。2文で同じになることを確かめます。
6. ヘッド0 とヘッド1 の t2 → t1 の注意 A'[t2, k1] を、3.3 の A[t2, k1] と比べます。

## 計算する前に予想しよう

**予想1　1次予測は当たるか**：7.2 の予測 ΔL を L = 1.3507 に足すと、予測 L' はいくつ？ それはありうる値ですか？（ヒント：[A](step_a_map.md) の A4 の下限）

<details><summary>答え</summary>

1.3507 − 1.1717 = 0.1790。これは損失の下限 $2\ln2/6 \approx 0.2310$ より小さいので、**ありえない値** です（Part 1 では予測 L' が負になりました）。
実際は L' = 0.5482（ΔL = −0.8025、予測の 0.685 倍）。Part 1 の 0.877 倍より外れ方が大きいです。
同じ勾配で lr だけ変えると、実際 ／ 予測の比は lr = 0.1, 0.25, 0.5, 1, 2 で 0.971, 0.925, 0.844, 0.685, 0.442 です（コードで計算）。Part 1 と違い、小さな lr でも1を下回ります。この1ステップで「2つの層の変化の積」の項がどのくらい効くかは、F の ΔM で見ます。
</details>

**予想2　注意のパターンは2文で分かれるか**：更新後、A' の猫文ブロックと犬文ブロックは違う値になるでしょうか？ 違わないなら、C' は0のままでしょうか？ t2 から t1 への注意が増えるのはどちらのヘッド？

<details><summary>答え</summary>

A' の2つのブロックは **等しいまま** です（A6：QK はミラーで動かない空間なので、猫と犬を区別できない）。それでも C' = 3.6937 > 0 です。注意の重みが同じでも、**混ぜる値 V'[t1] が文ごとに違う** からです（パターン項は0、値項だけで C' が生まれる）。
t2 → t1 の注意は、ヘッド0 が 0.5035 → 0.6757 と **増え**、ヘッド1 が 0.5035 → 0.4106 と **減り** ます。D の dA0 = −1/3、dA1 = +1/3 の向きどおりです。
</details>

**予想3　t0 はどうなるか**：更新後、t0 の p'(猫) と p'(犬) はどうなるでしょう？ t0 の −log p' はどこまで下がりえますか？

<details><summary>答え</summary>

**p'(猫) = p'(犬) = 0.3470**（2文とも、厳密に等しい）。t0 の入力は2文で同じなので、t0 の予測は2文で同じ p にしかなれず、しかもミラーで p(猫) と p(犬) は入れ替わるだけなので、等しいままです。−log p'[正解] は 1.6283 → 1.0583。どれだけ学習しても ln 2 = 0.6931（p = 1/2）より下がりません（A4）。
</details>

## よくあるミス

- **符号を逆にする**：θ + dθ にすると損失は上がります。
- **Part 1 の近道を無条件に使う**：X0' = X0 − 2·dX0 は t1 で成り立たず、‖dE‖² = ‖dP‖² も成り立ちません（7.1, 7.2）。
- **2回目の順伝播で1回目の性質を使う**：U1 = ±1、σ = 1、μ = 0、K と V の t0・t2 行が0、はどれももう成り立ちません。特に V'[t0] = (−0.1190, −0.1190, 0.1822, 0.1822) を0と思い込むと、O'[t2] がずれます。
- **核で K' と V' の t0 行を省く**：t2 のクエリは t0 のキーも見ます。省いてよいのは Q' の t0 行と t1 行だけです。
- **犬文 t2 のミラーで 鳴く↔吠える だけを入れ替える**：猫↔犬 の列も入れ替えます。
- **C' を確率の差で求める**：C は logit の差です。
- **L' を t2 だけで求める**：L' は6行の平均です。核では t0 と t1 の −log p' を answers.md から取ります。
- **アブレーションで LN2 をやり直そうとして迷う**：X1 = X0'[t2] の LN は U1'[t2] そのものです。
