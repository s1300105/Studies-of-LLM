### A0 6行とマスクを図にする（5分）

6行を猫文 t0, t1, t2、犬文 t0, t1, t2 の順に積みます。Attention のマスクは「同じ文の、自分以前の位置」だけを通します（○ = 見てよい、× = −∞）。

```
             猫文 k0 k1 k2   犬文 k0 k1 k2
  猫文 t0         ○  ×  ×         ×  ×  ×
  猫文 t1         ○  ○  ×         ×  ×  ×
  猫文 t2         ○  ○  ○         ×  ×  ×
  犬文 t0         ×  ×  ×         ○  ×  ×
  犬文 t1         ×  ×  ×         ○  ○  ×
  犬文 t2         ×  ×  ×         ○  ○  ○
```

文をまたぐ右上と左下の 3×3 は常に × なので、Attention は **文ごとの 3×3 が2枚** です（記入欄もそう書きます）。

次に、順伝播の演算を「**行ごと**（行 r の出力が、入力の行 r だけで決まる）」かどうかで分けます。

| 演算 | 行ごと？ |
|---|---|
| X0 = E[ids] + P[位置]（表引きと足し算） | ○ |
| LN1, LN2（μ と σ はその行の4成分から） | ○ |
| Q, K, V = U1 W（行 r の結果は U1 の行 r だけで決まる） | ○ |
| **S = Q Kᵀ/√2 ＋ マスク**（行 r のスコアは、ほかの行の K を使う） | **×** |
| A = softmax(S)（行ごとの softmax。ただし S がすでにほかの行を含む） | ○ |
| **O = A V**（ほかの行の V を混ぜる） | **×** |
| Attn = Ocat Wo、残差、W1、ReLU、W2、Wout、softmax、−log p | ○ |

**行どうしが情報をやりとりするのは、Attention の2か所（S の K と、O の V）だけ** です。以下の証明はすべてこの表から出てきます。

### A1 猫文 t0 ≡ 犬文 t0（順伝播の最後まで）（7分）

**主張**：猫文 t0 と犬文 t0 は、X0 から p（softmax の出力）まで、すべての中間値が等しい。

**ヒント**：入力の行は同じか？ 行ごとでない2か所で、t0 は何を見られるか？

<details><summary>証明</summary>

- 2つの行はどちらも「位置 t0 の `<s>`」なので、X0 の行は同じ E[`<s>`] + P[t0] です
- 行ごとの演算は、同じ入力の行から同じ出力の行を作ります。LN1、Q, K, V までは等しいままです
- 行ごとでない S と O について：マスクにより、t0 が見られるのは **自分の文の k0（自分自身）だけ** です。要素1つの softmax は 1 なので A の t0 行は [1, 0, 0]、O[t0] = V[t0] となり、結局「自分の行だけ」で決まります
- 以降はすべて行ごとなので、Attn, X1, U2, Z, R, F, X2, logits, p まで等しくなります ∎

**注意**：等しいのは **順伝播だけ** です。正解は猫文 t0 が「猫」、犬文 t0 が「犬」と違うので、−log p[正解] も、逆伝播の dlogits = (p − y)/6 も一般には違います（D では t0 も「写す」ではなく、ミラー規則で埋めます）。
</details>

### A2 t2 の行は Q, K, V まで同じ（5分）

**主張**：猫文 t2 と犬文 t2 は、X0, U1, Q, K, V の行が等しい。違いが入り込めるのは S（t2 の行が見るキー）と O（混ぜる値）からで、その後の違いはすべて Attn[t2] の違いから来る。

<details><summary>証明</summary>

- どちらも「位置 t2 の が」なので X0 の行が同じ。LN1 と Q, K, V は行ごとなので、ここまで等しい
- S[t2, k1] = Q[t2]·K[t1]/√2 の K[t1] は、猫文では「猫」の行、犬文では「犬」の行から作られます。同じクエリでも、見ている **キーが違う** のでスコアは一般に違い、混ぜる **値 V[t1] も違う** ので O[t2] も違います
- X1[t2] = X0[t2] + Attn[t2] の X0[t2] は2文で同じなので、X1[t2] の違い ＝ Attn[t2] の違いです。そこから先は行ごとなので、t2 の予測の違いはすべて Attn[t2] の違いだけで決まります ∎

記入欄では、3.1 の犬文 t2 の行に「＝猫文」の印があり、3.2 以降の犬文 t2 の行には印がありません。
</details>

### A3 t2 の Attention 出力を0にすると、2文の t2 の予測は同じ（8分）

**主張**：2文の t2 で Attn[t2] を 0 に置き換える（X1[t2] = X0[t2] にする）と、猫文 t2 と犬文 t2 の logits は、パラメータが何であっても完全に等しくなる。したがって Attention なしでは、損失は $4\ln2/6$ 未満にならない。

**ヒント**：A2 と A0 の表。後半は A4 と同じ議論です（A4 を先に解いてもかまいません）。

<details><summary>証明</summary>

- Attn[t2] = 0 にすると X1[t2] = X0[t2] で、これは2文で等しい（A2）
- その後の LN2、W1、ReLU、W2、残差、Wout、softmax は **すべて行ごと**（A0 の表）。等しい入力の行からは等しい出力の行しか出ないので、t2 の logits と p は2文で等しい ∎
- t2 の正解は猫文が「鳴く」、犬文が「吠える」。同じ p で2つの正解に答えるので、t2 の2行の −log p の和は $2\ln2$ 以上です（A4 と同じ議論で、p(鳴く) = p(吠える) = 1/2 のとき最小）。t0 の2行も $2\ln2$ 以上（A4）なので、6位置の平均は $4\ln2/6$ 以上になります

**読み方**：t2 にとって、「猫か犬か」を知る道は **Attention が t1 から運ぶ値しかない**。これが Part 2 の出発点です。5.4 のアブレーションは、この証明を数字で確かめる作業です。
</details>

### A4 損失の下限は $2\ln2/6$（7分）

**主張**：どんなパラメータでも $L > 2\ln2/6$。下限 $2\ln2/6$ には近づけるが、到達はしない。

**ヒント**：A1 より、t0 の2行は同じ p を出します。p(猫) = a、p(犬) = b とおくと、a + b ≤ 1。

<details><summary>証明</summary>

- t0 の2行の −log p[正解] の和は $-\ln a - \ln b = -\ln(ab)$。相加相乗平均より $ab \le \left(\frac{a+b}{2}\right)^2 \le \frac14$ なので、和は $\ge 2\ln2$。等号は a = b = 1/2 のとき
- 残りの4行（t1 の2行と t2 の2行）は、−log p[正解] を 0 に近づけることはできても（logit を大きくするほど 0 に近づく）、有限のパラメータでちょうど 0 にはなりません
- よって $L = \frac16\sum(\cdots) > \frac{2\ln2}{6} = \frac{\ln2}{3}$ ∎

**読み方**：t0 は `<s>` しか見られないので、「次は猫か犬か」は半々に賭けるしかありません。どれだけ学習しても消えない損失です。t1 の正解はどちらの文も「が」なので、t1 は文を区別する必要がありません。**区別が必要で、しかも区別できるのは t2 だけ** です。
</details>

### A5 ミラー対称性と、SGD がそれを保つ理由（13分）

**主張**：次の4つの入れ替えを同時に行う操作を **ミラー g** と呼びます。

| 何を | どう入れ替えるか |
|---|---|
| 残差ストリームの次元 | d0 ↔ d1 |
| 語彙 | 猫 ↔ 犬、鳴く ↔ 吠える（`<s>` と が はそのまま） |
| 値の空間（V と O の列） | 各ヘッドの中で d0 ↔ d1、d2 ↔ d3 |
| Q・K の空間、FFN の中間層 h0〜h7 | そのまま |

(a) 初期パラメータは g で変わらない。(b) したがって犬文のすべての中間値は、猫文の中間値に「ミラー規則」を当てたものに等しい。(c) SGD で1ステップ（何ステップでも）更新しても、(a) と (b) は成り立ち続ける。

**ヒント**：(a) は params.md を下の表と照らし合わせるだけ。(b) は演算ごとに「入れ替えてから計算しても、計算してから入れ替えても同じ」を確かめる。(c) は「データも g で入れ替わるだけ」に注目。

| パラメータ | g で変わらない条件（params.md で確かめる） |
|---|---|
| E | `<s>` と が の行は d0 = d1。犬 の行 = 猫 の行の d0, d1 を入れ替えたもの。吠える の行 = 鳴く の行の d0, d1 を入れ替えたもの |
| P | d0 列 = d1 列 |
| Wq, Wk, W1 | d0 行 = d1 行 |
| Wv | d1 行 = d0 行を各ヘッドの中で入れ替えたもの。d2, d3 行はヘッド内の入れ替えで変わらない |
| Wo | d1 行 = d0 行の d0, d1 列を入れ替えたもの。d3 行 = d2 行の d0, d1 列を入れ替えたもの |
| W2 | d0 列 = d1 列 |
| Wout | d1 行 = d0 行の 猫↔犬、鳴く↔吠える の列を入れ替えたもの。d2, d3 行は 猫 列 = 犬 列、鳴く 列 = 吠える 列 |

<details><summary>証明</summary>

**(a)** 上の表の条件を params.md で1つずつ確かめます（すべて成り立ちます。たとえば Wq, Wk, W1 の d0 行と d1 行はどれも全部 0、Wv の d0 行と d1 行は互いの符号を反転したもので、これはヘッド内の入れ替えと同じです）。

**(b)** 猫文の行 x に入れ替え（d0 ↔ d1）を施したものを x̃ と書きます。演算ごとに確かめます。

- 埋め込み：犬文 t1 の X0 は E[犬] + P[t1] = (E[猫] の d0, d1 を入れ替えたもの) + P[t1]。P は d0 列 = d1 列なので、これは猫文 t1 の X0 の入れ替えです。t0, t2 の行は d0 = d1 なので入れ替えても変わりません
- LN：μ と σ は4成分の **並べ方によらない** ので、x̃ の LN 出力は、x の LN 出力の入れ替え
- Q, K：Wq, Wk は d0 行 = d1 行なので、x̃ Wq = x Wq。**Q, K はそのまま**、したがって S と A もそのまま
- V：Wv の行の条件から、x̃ Wv は x Wv を各ヘッドの中で入れ替えたもの。O = A V も同じ入れ替えを受けます
- Attn = Ocat Wo：Wo の条件から、ヘッド内で入れ替えた Ocat に Wo を掛けると、Attn の d0, d1 が入れ替わります
- FFN：W1 は d0 行 = d1 行なので Z, R はそのまま。W2 は d0 列 = d1 列なので F = R W2 はいつも d0 = d1 で、R が同じなら F も同じ。これは「F の d0, d1 を入れ替えたもの」とも一致します
- 出力：Wout の条件から、X2 の d0, d1 を入れ替えると logits の 猫↔犬、鳴く↔吠える の列が入れ替わり、softmax の p も同じ列が入れ替わります。正解も 猫→犬、鳴く→吠える と入れ替わるので、−log p[正解] は同じ値です

猫文の入力・正解（`<s>` 猫 が → 猫 が 鳴く）にミラーを当てると、ちょうど犬文（`<s>` 犬 が → 犬 が 吠える）になります。(a) よりパラメータは変わらないので、犬文の中間値 ＝ 猫文の中間値のミラーです。

**(c)** 一般のパラメータ θ について、g(θ) で犬文を計算すると、θ で猫文を計算した結果のミラーになります（(b) と同じ確かめ方。(a) を使っていない部分です）。逆に g(θ) で猫文を計算すると、θ で犬文を計算した結果のミラーです。損失は2文の平均なので、2文の役割が入れ替わるだけで値は変わりません：

$$L(g(\theta)) = L(\theta)\quad(\text{すべての }\theta)$$

g はパラメータ188個の **並べ替え** なので、この式を微分すると「勾配も同じように並べ替わる」：$\nabla L(g(\theta)) = g(\nabla L(\theta))$。初期値 $\theta_0 = g(\theta_0)$ を代入すると $\nabla L(\theta_0) = g(\nabla L(\theta_0))$、つまり **勾配も上の表の条件を満たします**。よって

$$g(\theta_1) = g(\theta_0) - \mathrm{lr}\; g(\nabla L(\theta_0)) = \theta_0 - \mathrm{lr}\,\nabla L(\theta_0) = \theta_1$$

で、更新後も g で変わりません。同じ議論を繰り返せば、何ステップ後でも成り立ちます ∎

**読み方**：データが猫と犬を「同じ扱い」にしていて、パラメータも同じ扱いなら、勾配が猫と犬のどちらかをひいきする理由がありません。逆伝播でもミラー規則はそのまま使えます（dX は d0, d1 を入れ替える、dlogits は列を入れ替える、など）。
</details>

### A6 QK は猫と犬を区別できない → 注意のパターンは2文で同じ（5分）

**主張**：両ヘッドとも、Attention 重みの犬文ブロックは猫文ブロックと等しい。更新前も、SGD で何ステップ更新した後も。

**ヒント**：更新前は Wq, Wk のどの行が 0 かを見る。更新後は A5 の表で「Q・K の空間はそのまま」だったことを使う。

<details><summary>証明</summary>

- **更新前（直接）**：Wq, Wk の d0, d1 行は 0 なので、Q, K は U1 の d2, d3 成分（位置の成分）だけで決まります。猫文 t1 と犬文 t1 の X0 は、d0, d1 が入れ替わっているだけで d2, d3 は同じ P[t1]。LN の μ, σ は並べ方によらないので、U1 の d2, d3 成分も等しい。よって Q, K の行が2文で等しく、S と A のブロックも等しい
- **一般に（更新後も）**：A5 (c) より更新後もミラーで変わらず、ミラーは Q・K の空間を動かしません。A5 (b) と同じく、犬文の Q, K は猫文の Q, K と等しいので、S と A も等しい ∎
- 言いかえると、Wq, Wk は「d0 行 = d1 行」を保ったまま更新されるので、単語の成分を d0 + d1 の形でしか読めません。猫 (d0, d1) と犬 (d1, d0) は d0 + d1 が同じなので、区別できません

**読み方**：「どこを見るか」（QK）は2文で同じです。2文の違いは「何を運ぶか」（V と OV）からしか生まれません。C で計算する分解の **パターン項は厳密に0** になります。ただしこれは **初期値が対称で、SGD がその対称性を保つから** で、Attention という仕組みの限界ではありません。
</details>

## よくあるミス

- **「t0 は順伝播が同じだから、逆伝播も写せる」**：正解が違う（猫／犬）ので、dlogits から違います。逆伝播の t0 は「写す」ではなく「ミラー」です
- **「t2 は Attention まで同じ」を「S まで同じ」と読む**：同じなのは Q, K, V まで。S の t2 行は、見ているキー（K[t1]）が文ごとに違うので、一般には違います（この重みで等しくなるのは A6 の別の理由から）
- **ミラーで Q, K の列まで入れ替える**：Q・K の空間は入れ替えません。入れ替えるのは値の空間（V, O）で、しかもヘッドの **中で**（d0↔d1 と d2↔d3）です
- **下限の議論で「t1 も区別できないから損失が残る」とする**：t1 の正解はどちらの文も「が」なので、区別の必要がありません
- **「注意のパターンが2文で同じ ⇒ Attention は文脈を使っていない」**：違います。同じ重みで **違う値** を混ぜれば、出力は違います。C で、パターンが同じまま値の違いだけで C が生まれることを確かめます
- **「QK が猫と犬を区別できないのは Attention の限界」**：対称な初期値から SGD で出発したからです（A5 (c)）
