## 問1 アブレーションの恒等式（5.4、A3）

t2 の Attention 出力を 0 にすると、猫文 t2 と犬文 t2 の logits は完全に一致しました（更新前 (0, 0, 0, −1.5, 0.5, 0.5)、更新後 (−0.1917, −0.3335, −0.3335, −2.2732, 1.9414, 1.9414)）。

1. これが **どんな重みでも** 成り立つことを証明してください。
2. そこから「C ≠ 0 なら、その全量が t2 の Attention 出力を通って来ている」と言える理由を説明してください。
3. t1 の Attention 出力は 0 にしなくてよいのはなぜですか？

<details><summary>答えの骨子</summary>

1. 行をまたぐ演算は Attention だけで、LN2・FFN・残差・Wout はすべて行ごとの演算です。t2 の Attention 出力を 0 にすると X1[t2] = X0[t2] = E[が] + P[t2] となり、これは2文で同じです。その後は同じ行に同じ演算をするだけなので、logits も一致します。重みの値はどこにも使っていません（正規乱数の重み `rng = m2.np.random.default_rng(0); q = {k: rng.standard_normal(v.shape) for k, v in p.items()}` で `m2.ablate_t2(q, m2.forward(q))` を見ても、2行の差は厳密に 0。そのモデル自身の C は 0.9212）。
2. アブレーション後の C は常に 0 なので、C = C(そのまま) − C(アブレーション後) が「t2 の Attention 出力の効果」そのものです。
3. t1 の情報が t2 の行に入る道は、t2 の Attention 出力しかありません（t2 より後の演算は行ごと）。t2 の出力を切れば、t1 からのすべての経路が切れます。
</details>

## 問2 損失の下限 2·ln2/6（A4）

1. L ≥ 2·ln2/6 = 0.2310 を証明してください（t0 に注目）。この値にちょうど到達することはありますか？
2. t0 で p(猫) = p(犬) が厳密に成り立つのはなぜですか？
3. t2 に文脈が届かないモデル（Attention なし、または t2 の残差が2文で同じまま）の下限はいくつですか？

<details><summary>答えの骨子</summary>

1. 2文の t0 は入力（`<s>` と P[t0]）が同じで、自分自身しか見ないので、まったく同じ分布 q を出します。正解は 猫 と 犬 なので、2行の nll の和は $-\ln q(\text{猫}) - \ln q(\text{犬}) \ge -2\ln\frac{q(\text{猫}) + q(\text{犬})}{2} \ge 2\ln 2$（相加相乗平均と $q(\text{猫}) + q(\text{犬}) \le 1$）。残り4行は ≥ 0 なので L ≥ 2·ln2/6 です。等号には残り4行の nll = 0 が必要で、有限の logit では起きません（下限であって最小値ではない）。`python3 part2/mini_gpt2.py --train 3000 --lr 0.1` の最後の行は L = 0.2312 です（`--lr 0.1` を付けないと lr = 1 で回り、途中で対称性が崩れます。問5）。
2. ミラー対称性のためです。t0 の行 U1[&lt;s&gt;] = (1, 1, −1, −1) は d0↔d1 で変わらず、重みはミラーの不動点なので、t0 で logit[猫] = logit[犬]、したがって p(猫) = p(犬) になります（更新前 0.1963 ずつ、更新後 0.3470 ずつ）。タスクが強制するのは「2文の t0 で q が同じ」ことまでで、q(猫) = q(犬) は対称な初期値から来ています（それが最適でもある）。
3. t2 の2行も同じ分布になるので、t2 の2行でも ≥ 2·ln2。L ≥ 4·ln2/6 = 0.4621 です（問9）。
</details>

## 問3 C の分解で X0 の項が 0 になる理由

C を残差の成分（X0 の直接経路・ヘッド0・ヘッド1・FFN）ごとに分けると、X0 の項は常に 0 です。

1. なぜですか？
2. FFN の項はどうでしょう？ 更新前と更新後の値を予想してから確かめてください。

```python
for k, v in m2.m.logit_decomposition(p1, c1).items():
    print(k, (v[2, 4] - v[2, 5]) - (v[5, 4] - v[5, 5]))
```

<details><summary>答えの骨子</summary>

1. X0[猫文 t2] = X0[犬文 t2] = E[が] + P[t2] なので、(鳴く − 吠える) への寄与が2文で同じになり、C の中で消えます。重みによらず成り立ちます。

## 問4 注意の向きが2文で同じになる理由（A6）

1. 更新前、両ヘッドの注意が猫文と犬文で同じになるのはなぜですか？
2. 更新後の $W_{q,0}'W_{k,0}'^\top$（8.2）は d0, d1 の行・列も 0 ではありません。それでもヘッド0 の t2 → (k0, k1, k2) は (0.1689, 0.6757, 0.1554) で、2文で厳密に同じです（ヘッド1 も (0.3023, 0.4106, 0.2872) で同じ）。なぜでしょう？
3. その結果、5.5 のパターン項はどうなりますか？

<details><summary>答えの骨子</summary>

1. Wq と Wk の d0, d1 行が 0 なので、Q と K は U1 の d2, d3（位置）だけで決まります。
2. 8.2 の行列を見ると、d0 行 = d1 行、d0 列 = d1 列になっています（ミラー対称性）。この形の行列はキーの d0 + d1 しか読みません。U1′[猫] − U1′[犬] = (1.7807, −1.7807, 0, 0) なので、猫 と 犬 の d0 + d1 は同じです。よって t2 → 猫(t1) と t2 → 犬(t1) のスコアは等しくなります（8.2 ではどちらも 1.3308）。より一般に、重みがミラーの不動点である限り「注意の重みはスカラーなので、猫文を犬文に移すミラーで値が変わらない」と言えます。
3. パターン項 = (a猫文 − a犬文)·V… は、更新前も更新後も 0 です。C はすべて値項から来ます。これはミラー対称な出発点（A6）の性質で、Attention 一般の性質ではありません。対称性がなければ注意の向きそのものが2文を見分け、パターン項は 0 でなくなります（問11）。
</details>

## 問5 ミラー対称性は SGD で保たれるか（A5 の先）

1. 「重みがミラー g の不動点なら、1ステップ後も不動点」を、A5 を見ずに示してください。
2. params.json が不動点になるには、d0↔d1・猫↔犬・鳴く↔吠える の入れ替えに加えて、何を入れ替える必要がありますか？（ヒント：Wv の d0 行は (1, −1, 1, −1)）
3. 不動点であることは、安定であることを意味しますか？

<details><summary>答えの骨子</summary>

1. ミラー g は重みの並べ替え（直交変換）で、猫文の計算を犬文の計算に、犬文を猫文に移します。損失は2文の平均なので、すべての θ で L(g(θ)) = L(θ)。微分すると ∇L(g(θ)) = g(∇L(θ))。θ = g(θ) なら ∇L(θ) = g(∇L(θ)) で、θ − lr·∇L(θ) も g で変わりません。帰納的にすべてのステップで保たれます。数値では、1ステップ後のずれは 2.2e−16（丸め誤差）でした。
2. 各ヘッドの中の **値の2次元**（Wv の列 0↔1・2↔3 と Wo の行 0↔1・2↔3）も入れ替えます。これがないと Wv の d0 行 (1, −1, 1, −1) は d0↔d1 で (−1, 1, −1, 1) に移ってしまい、ずれは 2.0 です。入れ替えればずれは 0 になります。QK の2次元と FFN のユニットは入れ替え不要です（A5 の表）。
3. 意味しません。数学的には SGD は対称性を保ちますが（1）、計算機では毎ステップ、丸め誤差（10⁻¹⁷ 程度）のずれが入ります。ずれはミラーで符号が反転する方向（t0 の 猫 と 犬 の差、Wout の 猫 列 − 犬 列 など）にも乗り、この方向の損失の曲率を λ とすると、1ステップで約 (1 − lr·λ) 倍になります。λ > 2/lr なら |1 − lr·λ| > 1 なので、ずれは符号を交互に変えながら育ちます。lr = 1 ではこの曲率が初めから 2 を超えていて（10 ステップ目で約 7）、t0 の p(猫) − p(犬) は 10 ステップ前後から1ステップごとに約 −6〜−7 倍になります。|p(猫) − p(犬)| は 5.6e−17（1ステップ）→ 8.1e−11（10）→ 1.8e−2（20）→ 0.35（30）と育ち、`python3 part2/mini_gpt2.py --train 30` の L は 0.2362（ステップ20）から増え始め（21 で 0.2388）、24 で 2.3155、25 で 2.5236 まで跳ねます。lr を下げると 2/lr が大きくなるので崩れは遅れますが、学習が進むとこの曲率も大きくなるので、ずれが 10⁻⁹ を超えるのは lr = 0.3 で約70ステップ、lr = 0.2 で約400ステップです（L が跳ねるのはそれぞれ約100、約500ステップ）。lr = 0.1 なら `--train 3000 --lr 0.1` の 3000 ステップ後もずれは 1.3e−15 以下で、L は単調に減ります（0.2312）。長く回すときは `--lr 0.1` を使ってください。A5 (c) の「何ステップ後でも」は厳密な算術での話です。手計算の1ステップでは対称性は確実なので、「犬文の数はすべて猫文の数の入れ替え」は、そのまま自分の計算の検算に使えます。
</details>

## 問7 直接効果 = 総効果になる理由

5.5 では、直接効果（Wo → Wout だけを通る分）とパッチングの総効果が一致しました（更新前 4.0279、更新後 5.3784 / −1.6847）。

1. 総効果と直接効果の差は、どの経路を通る分ですか？
2. ここでその差が厳密に 0 になる理由を説明してください。
3. 差が 0 にならない例を作ってください。

<details><summary>答えの骨子</summary>

1. パッチングで X1[t2] が変わると、LN2 → FFN → F → Wout を通って logits も変わります。差は「FFN 経由の間接効果」で、r·ΔF です。
2. ミラー対称性で、FFN のユニットは入れ替え不要（各ユニットが自分自身のミラー）です。したがって W1 の d0 行 = d1 行（更新後も差 0）、W2 の d0 列 = d1 列（差 6.9e−18）となり、**どの行でも F[d0] = F[d1]** です。一方 r はミラーで符号が反転するので (x, −x, 0, 0) の形です（更新後 r′ = (0.8627, −0.8627, 0, 0)）。よって r·F = x·(F[d0] − F[d1]) = 0 で、パッチングで FFN の出力がどう変わっても (鳴く − 吠える) は動きません（差は 2.2e−16 以下）。
3. ミラーで互いに入れ替わるユニットの組を作ります：params.json の h2 と h6 の W1 の列と W2 の行を、W1[:, h2] = (1, −1, 0, 0)、W2[h2] = (1, −1, 0, 0)、W1[:, h6] = (−1, 1, 0, 0)、W2[h6] = (−1, 1, 0, 0) に置き換えます。2つ合わせると F = (U2[d0] − U2[d1])·(1, −1, 0, 0) となり、t2 の残差の名詞の情報を r の方向に増幅します。更新前のヘッド0 は直接効果 4.0279 に対して総効果 8.6574 です。
</details>

## 問8 $W_{q,h}W_{k,h}^\top$ の rank

1. rank は最大いくつですか？
2. 8.1 と 8.2 ではいくつですか？
3. 学習を続けると rank は上がりますか？ OV（$W_{v,h}W_{o,h}$）はどうでしょう？

## 問9 7.5：Wout だけの更新は、文脈を学ばずに損失を下げる

7.5 では、Wout だけを更新すると L が 1.3507 → 1.0180 と、1つの群の更新としては最も下がりました。しかし C は 0 のままでした。

1. なぜ C が 0 のままなのかを、更新前の t2 の残差から説明してください。
2. では、L はどこで下がったのでしょう？
3. Wout だけを何ステップ更新しても越えられない L の下限はいくつですか？

<details><summary>答えの骨子</summary>

1. 更新前は t2 の Attention 出力が厳密に 0 です。t2 では両ヘッドの注意も値も同じで、Wo の行 2, 3 が行 0, 1 の符号反転なので、2つのヘッドの出力が残差の中で打ち消し合います（5.5 の ±4.0279）。したがって ΔX2[t2] = 0 です。同じ残差にどんな Wout を掛けても同じ logits になるので、C = r·ΔX2[t2] = 0 です。
2. 行ごとの nll は t0 1.6283 → 1.2919、t1 1.0488 → 0.6677、t2 1.3750 → 1.0943。t2 では `鳴く` と `吠える` を **一緒に** 押し上げただけで、p(鳴く) = p(吠える) = 0.3348 が両文で同じです（更新前は 0.2528 ずつ）。「損失は下がったが、文脈は学んでいない」状態です。
3. X2 が動かないので、t0 の2行と t2 の2行はそれぞれ2文で同じ分布になり、L ≥ 4·ln2/6 = 0.4621 です。Wout だけで勾配降下を続けると L は 0.4725（100 ステップ）、0.4631（1000）、0.4623（5000）と近づき、C はずっと 0 のままです。文脈を学ぶには ΔX2[t2] を動かす群（7.5 では Attention の群。E, P も −0.0834 だけ）が必要です。
</details>

## 問10 もし Wout の 鳴く 列と 吠える 列が同じだったら

Wout の `鳴く` 列と `吠える` 列を同じ値（2列の平均 (0.5, 0.5, 0, 1)）にして、1ステップ更新します。7.5 と同じ「群ごとの更新」の表を予想してから確かめてください。

```python
q = {k: v.copy() for k, v in p.items()}
q["Wout"][:, 4] = q["Wout"][:, 5] = (p["Wout"][:, 4] + p["Wout"][:, 5]) / 2
cq = m2.forward(q); gq, _ = m2.backward(q, cq); print(m2.group_update_items(q, gq, 1.0)[0][1])
```

<details><summary>答えの骨子</summary>

更新前の C は、Attention が何をしていても 0 です（C = r·ΔX2[t2] で r = 0）。L = 1.2893。

1ステップ後は、**どの群を更新しても C = 0** です。L は QK 1.2893、OV 1.2723、Attention 全部 1.2723、Wout だけ 0.9935、FFN 1.1371、E, P 1.0824、全部 0.7271。Wout ですら文脈を学びません：dWout[:, 鳴く] − dWout[:, 吠える] = 0 なので r は 0 のままです。

理由：C = r·ΔX2[t2] は積で、ここでは **両方の因子が 0**（r = 0 は作り方から、ΔX2[t2] = 0 はヘッドの打ち消し合いから）。積の勾配は d(r·ΔX) = dr·ΔX + r·dΔX なので、(0, 0) では 0 になります（鞍点）。

ただし1ステップ目で ΔX2[t2] = (−0.4264, 0.4264, 0, 0) が生まれます。E, P の更新で d2 と d3 がずれ、d2 を読むヘッド0 と d3 を読むヘッド1 の t2 の注意が 0.1165 ずれて、打ち消し合いが崩れるためです。2ステップ目でようやく r が動き、C = 0.0693 になります（本来のモデルは1ステップで 3.6937、2ステップで 5.3270）。

本来のモデルでは逆に「r ≠ 0、ΔX2[t2] = 0」から始まるので、Attention の群は1ステップ目から C を作れ、Wout だけでは作れません（問9）。r と ΔX2[t2] は片方が 0 でなければ、もう片方が学べる関係です。
</details>

## 問12 7.5：QK だけ ＋ OV だけ ≠ Attention 全部

7.5 では、QK だけの更新で C = 1.8845、OV だけで 2.5282、両方で 4.4235 でした。和の 4.4127 と一致しないのはなぜですか？ 差 0.0108 を式で説明してください。

<details><summary>答えの骨子</summary>

注意の向きが2文で同じ（問4）で、FFN の項が 0（問7）なので、C は各ヘッドの「注意 × 運ぶ量」の和に書けます：

$$C = \sum_h a_h\,g_h,\qquad a_h = a_h(t2\to t1),\quad g_h = (V_h[\text{猫}] - V_h[\text{犬}])\,W_{o,h}\,r$$

QK の更新は a だけを、OV の更新は g だけを変えます。

| 更新 | a（ヘッド0, ヘッド1） | g（ヘッド0, ヘッド1） | C |
|---|---|---|---:|
| なし | 0.5035, 0.5035 | 8, −8 | 0 |
| QK だけ | 0.6303, 0.3948 | 8, −8 | 1.8845 |
| OV だけ | 0.5035, 0.5035 | 10.3635, −5.3421 | 2.5282 |
| 両方 | 0.6303, 0.3948 | 10.3635, −5.3421 | 4.4235 |

C(両方) − C(QK) − C(OV) + C(なし) = $\sum_h \Delta a_h\,\Delta g_h$ = 0.0108。積の「交差項」です。1次近似（7.2）が取りこぼすのも、この種の項です（問13）。全部の群を同時に更新すると C′ = 3.6937 で、r（0.8627 倍に縮む）や U1 も同時に動くため、さらに別の交差項が加わります。
</details>

## 問13 1次近似の比 0.685（7.2, 7.4）

7.2 の予測 ΔL = −lr‖g‖² = −1.1717 に対し、実際の ΔL は −0.8025（比 0.685）でした。

1. なぜ1次近似は減少を過大評価したのでしょう？
2. lr を 0.5、0.25、0.1 にすると、比はどうなると予想しますか？

<details><summary>答えの骨子</summary>

1. 1次近似は曲率（2次の項 $\tfrac{lr^2}{2}g^\top Hg$）と、問12 のような交差項を無視しています。下る方向で曲率が正なら、その分だけ実際の減少は小さくなります。lr = 1 は大きな一歩です。
2. 比 = 1 − (lr/2)·gᵀHg/‖g‖² + … なので、lr を小さくすると 1 に近づき、1 からのずれはほぼ lr に比例します。実際、比は 0.8438（lr 0.5）、0.9252（0.25）、0.9713（0.1）、0.9972（0.01）で、1 からのずれは 0.315 → 0.156 → 0.075 → 0.029 → 0.0028 と、lr を半分にするとほぼ半分になります。1ステップ後の C も 3.6937、2.0423、1.0699、0.4397 と、ほぼ lr に比例して小さくなります。
</details>
