## 手順

始める前に、下の「計算する前に予想しよう」の3問に、自分の予想を書いておいてください。

### 準備：3つの表を作る（30分）

**(a) 逆伝播のミラー規則**。勾配 dX は X と同じ空間の量なので、ミラー規則も順伝播と同じです。猫文の行から犬文の行を作ります。

| 勾配 | 犬文の行の作り方 |
|---|---|
| dlogits | 列の 猫↔犬、鳴く↔吠える を入れ替える |
| dX2, dF, dU2, LN2経由, dX1, dAttn, dU1, LN1経由, dX0（残差ストリーム） | d0 と d1 を入れ替える |
| dR, dZ（FFN の中間層） | そのまま |
| dOcat（dO0, dO1）, dV（値の空間） | ヘッドの中で入れ替える（d0↔d1、d2↔d3） |
| dQ, dK（Q・K の空間） | そのまま |
| dA, dS（犬文ブロック） | 猫文ブロックと同じ |

**(b) 重みの勾配の独立な成分**。重みの勾配は6行の和なので犬文の行がありません。その代わり、勾配そのものがミラーで変わりません（[A5](step_a_map.md#a5-ミラー対称性とsgd-がそれを保つ理由13分) (c) の $\nabla L(\theta_0) = g(\nabla L(\theta_0))$）。下の組は等しいので、**片方だけ計算して、もう片方は写します**。

| 勾配 | 等しい組 | 独立な成分 |
|---|---|---:|
| dWout（4×6） | d1 行 = d0 行の 猫↔犬・鳴く↔吠える の列を入れ替えたもの。d2, d3 行は 猫 列 = 犬 列、鳴く 列 = 吠える 列 | 14 / 24 |
| dW2（8×4） | d1 列 = d0 列 | 24 / 32 |
| dW1（4×8） | d1 行 = d0 行 | 24 / 32 |
| dWo（4×4） | d1 行 = d0 行の d0↔d1 を入れ替えたもの。d3 行 = d2 行の d0↔d1 を入れ替えたもの | 8 / 16 |
| dWq, dWk（4×4） | d1 行 = d0 行 | 各 12 / 16 |
| dWv（4×4） | d1 行 = d0 行をヘッドの中で入れ替えたもの。d2, d3 行はヘッド内で入れ替えても同じ（d0 列 = d1 列、d2 列 = d3 列） | 8 / 16 |
| dP（3×4） | d1 列 = d0 列 | 9 / 12 |
| dE（6×4） | 犬 行 = 猫 行の d0↔d1。`<s>` と が の行は d0 = d1。鳴く・吠える 行は 0 | 14 / 24 |

合計で 188 個のうち独立なのは 125 個です（コードで数えた値）。

**(c) 共有行は先に足す**。重みの勾配は6行の外積の和です。

$$dW = X^\top dY = \sum_{t=0}^{2}\Big(x_{\text{猫}t}^\top\, dy_{\text{猫}t} + x_{\text{犬}t}^\top\, dy_{\text{犬}t}\Big)$$

同じ位置の2行（猫文 t と犬文 t）の組ごとに、次のどれかを選びます。

| 組の状態 | 計算 | 外積の数 |
|---|---|---:|
| 順伝播の x が2文で同じ | $x_t^\top\,(dy_{\text{猫}t} + dy_{\text{犬}t})$：**dy を先に足す** | 1 |
| 勾配の dy が2文で同じ | $(x_{\text{猫}t} + x_{\text{犬}t})^\top\, dy_t$：**x を先に足す** | 1 |
| どちらも違う | 2つの外積をそのまま（犬文の値はミラーで写した表から読む） | 2 |

どの行が同じかは、A の証明とミラー規則から決まります（コードで確認済み）。

| dW | x（順伝播） | 2文で同じ x の行 | dy（勾配） | 2文で同じ dy の行 |
|---|---|---|---|---|
| dWout | X2 | t0, t2 | dlogits | なし |
| dW2 | R | t0, t1, t2 | dF | t0 |
| dW1 | U2 | t0, t2 | dZ | t0, t1, t2 |
| dWo | Ocat | t0（ただし全部0） | dAttn | t0 |
| dWq, dWk | U1 | t0, t2 | dQ, dK | t0, t1, t2 |
| dWv | U1 | t0, t2 | dV | なし |

D 全体の掛け算は、この工夫で 446 回 → 335 回（小数×小数は 90 → 82 回）に減ります。足し算が増えるので純粋な計算時間はどちらも約 2.1 時間（作成時に手順を再生して数えた値。再集計スクリプトは未収録）ですが、**相殺で厳密に0になる成分が、掛ける前に見えます**（予想1）。

**(d) 先に足してはいけないところ**。「先に足す」が使えるのは **重みの勾配 dW と、dP・dE を作るときだけ** です。各行の勾配（dlogits, dX2, …, dX0 の6行の表）は、文ごとに求めます。

- t0 の2行は、順伝播では最後まで同じでした（A1）。しかし逆伝播では、まず **dlogits が違います**（正解が 猫 と 犬）
- さらに Attention の中では、キーと値の勾配が **同じ文の、後ろのクエリから** 集まります：$dV_h[j] = \sum_{i \ge j,\ \text{同じ文}} A_h[i,j]\, dO_h[i]$。猫文 t0 の値を読むのは猫文の t0, t1, t2 のクエリだけ、犬文 t0 の値を読むのは犬文のクエリだけです。だから **dV の t0 行は2文で別の値** になります。「t0 は共通だから、4つのクエリ全部から1行だけ求めて両方に写す」は誤りです（その和は dWv の t0 の項としてだけ正しい）
- 犬文の行は、いつでも「ミラー規則で写す」で求めます。写した結果がたまたま猫文と同じになる行もあります（予想3）

### Da 出力層（6.1）— 45分

1. **dlogits = (p − y)/6**〔6×6〕：猫文の3行は、5.2 の p から正解のマス（t0 の 猫、t1 の が、t2 の 鳴く）だけ 1 を引き、全体を 6 で割ります。**÷6 は損失が6行の平均だから** です。犬文の3行はミラー（列の 猫↔犬、鳴く↔吠える を入れ替える）。正解のマスも 犬・が・吠える に移ります。
2. **dWout = X2ᵀ dlogits**〔4×6〕：独立な成分 14 個だけを求めます（表 (b)）。X2 の t0 行と t2 行は2文で同じなので、dlogits の t0 の2行、t2 の2行を **先に足して** から掛けます。

   $$dW_{out} = X_2[t_0]^\top g_{t_0} + X_2[\text{猫}t_1]^\top dl_{\text{猫}t_1} + X_2[\text{犬}t_1]^\top dl_{\text{犬}t_1} + X_2[t_2]^\top g_{t_2},\qquad g_{t} = dl_{\text{猫}t} + dl_{\text{犬}t}$$

   X2 の t0 行と t2 行は ±1 と 0.5 刻みの数だけなので、小数×小数になるのは t1 の d0, d1 成分（±1.6790）との積だけです。
3. **dX2 = dlogits Woutᵀ**〔6×4〕：Wout の非零は5個（d0 行の 鳴く、d1 行の 吠える、d3 行の が・鳴く・吠える）で、すべて ±1 です。dlogits のある行の 鳴く・吠える・が の成分を $g_{\text{鳴く}}, g_{\text{吠える}}, g_{\text{が}}$ とすると

   $$dX_2[i] = \big(g_{\text{鳴く}},\ g_{\text{吠える}},\ 0,\ g_{\text{鳴く}} + g_{\text{吠える}} - g_{\text{が}}\big)$$

   **掛け算なしの足し引きだけ** です。d2 列は厳密に0（Wout の d2 行が全部0）。犬文の行は d0↔d1 の入れ替えで写します。

### Db FFN（6.2）— 45分

1. **dF = dX2**：残差の足し算の逆伝播はコピーです。
2. **dW2 = Rᵀ dF**〔8×4〕：R は3位置とも2文で同じ（Z, R はミラーで「そのまま」）なので、**3位置すべてで dy を先に足します**：$dW_2 = \sum_t R[t]^\top\big(dF_{\text{猫}t} + dF_{\text{犬}t}\big)$。足した dF の行は d0 = d1 になるので、dW2 の d1 列 = d0 列（表 (b)）。d2 列は厳密に0です。R の非零は t0 と t2 では 1 なので、その行は「足すだけ」です。
3. **dR = dF W2ᵀ**〔6×8〕：猫文の3行の **Z > 0 のマスだけ** を求めます（Part 1 と同じ理由）。さらに、**W2 の h2〜h6 行は全部0** なので dR の h2〜h6 列は厳密に0です。h2〜h6 はどれも、どこかの位置で発火しています（Z > 0）が、出力に何も書き込まないユニットなので勾配を受け取りません。記入欄の残りのマスは「—」で構いません（全部埋めると行和チェックサムが使えます）。
4. **dZ = dR ⊙ [Z > 0]**：4.3 の Z が正のマスだけ dR を写します。犬文の行は「そのまま」（猫文と同じ値）です。
5. **dW1 = U2ᵀ dZ**〔4×8〕：dZ は3位置とも2文で同じなので **x を先に足します**：$dW_1 = \sum_t \big(U_2[\text{猫}t] + U_2[\text{犬}t]\big)^\top dZ[t]$。dZ の t1 行は0、U2 の t0 行と t2 行は2文で同じなので、結局 $dW_1 = 2\,U_2[t_0]^\top dZ[t_0] + 2\,U_2[t_2]^\top dZ[t_2]$ です。U2 のこの2行は ±1 なので、×2 と符号だけで済みます。
6. **dU2 = dZ W1ᵀ**〔6×4〕：W1 の d0, d1 行は全部0なので、dU2 の d0, d1 列は厳密に0です。

### Dc LN2 の逆伝播と残差の合流（6.3）— 15分

1. **t1 の行**：dU2 の t1 行が0なので、LN2経由も0です。dX1[t1] = dX2[t1]。
2. **t0 と t2 の行**：σ = 1 で、U2 は ±1 です。Part 1 の [ステップ6 の検算](../../workbook/step6_backward.md#検算) の **ペアの規則** がそのまま使えます。U2 の同じ符号の2成分をペア (i, i') にすると

   $$\text{LN2経由}[t,i] = \frac{dU_2[t,i] - dU_2[t,i']}{2\sigma_t},\qquad \text{LN2経由}[t,i'] = -\text{LN2経由}[t,i]$$

   ペアは t0, t2 とも (d0, d1) と (d2, d3) です。
3. **dX1 = dX2 + LN2経由**（分岐点 X1）。犬文の行は d0↔d1 の入れ替えで写します。

### Dd 出力射影・Attention（6.4–6.6）— 75分

**6.4**

1. **dAttn = dX1**（コピー）。
2. **dWo = Ocatᵀ dAttn**〔4×4〕：Ocat の t0 行は全部0なので、t0 の2行は何も足しません。t1 と t2 は x も dy も2文で違うので、外積4つ（猫文 t1、犬文 t1、猫文 t2、犬文 t2）の和です。独立な成分は 8 個だけです。**d2, d3 列がどうなるか** は予想1。
3. **dOcat = dAttn Woᵀ**〔6×4〕：Wo の非零は ±1 だけで、

   $$dO_{cat}[i] = \big(dX_1[i,d_0],\ dX_1[i,d_1],\ -dX_1[i,d_0],\ -dX_1[i,d_1]\big)$$

   です。**dO1 = −dO0**（ヘッド1 の出力の勾配は、ヘッド0 の符号を反転したもの）。掛け算はありません。

**6.5**（**猫文ブロックだけ** を計算し、犬文ブロックには同じ値を写します）

1. **dA_h = dO_h V_hᵀ**〔3×3〕：V の t0 行と t2 行は全部0なので、dA の k0 列と k2 列は厳密に0です。非零は (t1, k1) と (t2, k1) の2マスだけ。V_h の猫文 t1 行は (2, −2) なので、ヘッドの2列を $c_0, c_1$ として（ヘッド0 は d0, d1、ヘッド1 は d2, d3） $dA_h[t,k_1] = 2\big(dO_h[t,c_0] - dO_h[t,c_1]\big)$。
2. **行ごとのスカラー** $s_i = \sum_j A_h[i,j]\, dA_h[i,j] = A_h[i,k_1]\, dA_h[i,k_1]$（積1回。Part 1 の 6.5 の $r_i$ と同じものです。Part 2 では r を読み出しの向き $W_{out}[:,\text{鳴く}] - W_{out}[:,\text{吠える}]$ に使うので、s と書きます）。
3. **dS_h = A_h ⊙ (dA_h − s)**：dA が0の k0, k2 列も、dS は $-A_h[i,j]\, s_i$ で0になりません（softmax の逆は、行の中に勾配を配り直す）。t0 行は Part 1 と同じく全部0です。

**6.6**（猫文の3行。犬文は dQ, dK が「そのまま」、dV が「ヘッド内の入れ替え」）

1. **dQ_h = dS_h K_h / √2**〔6×2〕：K の t0 行と t2 行は0、K の t1 行はどちらのヘッドでも (1, 0) なので、$dQ_h[t] = dS_h[t,k_1]\,(1,\ 0)/\sqrt2$。d1, d3 列と t0 行は厳密に0です。
2. **dK_h = dS_hᵀ Q_h / √2**：$dK_h[j] = \frac{1}{\sqrt2}\sum_{i\ge j} dS_h[i,j]\, Q_h[i]$。Q の t0 行は今回も不要です（掛かる dS の t0 行が0）。Q の各ヘッドの成分は ±1 か 0 なので、符号付きの足し算のあと 0.70711 を1回掛けるだけです。
3. **dV_h = A_hᵀ dO_h**：$dV_h[j] = \sum_{i\ge j,\ \text{同じ文}} A_h[i,j]\, dO_h[i]$。t0 行は3項（t0, t1, t2 のクエリ）、t1 行は2項、t2 行は1項です。**ここで t0 の行が2文で分かれます**（準備 (d)）。
4. ヘッド0 を列 d0, d1、ヘッド1 を列 d2, d3 に並べ、dQ・dK・dV（各 6×4）にまとめます（6.7 で使う）。

### De 射影行列・LN1・埋め込み（6.7–6.9）— 60分

**6.7**

1. **dWq = U1ᵀ dQ**：dQ は6行とも2文で同じなので **x を先に足します**。dQ の t0 行は0、$U_1[\text{猫}t_1] + U_1[\text{犬}t_1] = (0, 0, 2, -2)$（**単語の成分が打ち消し合う**）、U1 の t2 行は2文で同じなので

   $$dW_q = (0,\ 0,\ 2,\ -2)^\top dQ[t_1] + 2\,U_1[t_2]^\top dQ[t_2]$$

   掛け算は ±2 だけです。
2. **dWk = U1ᵀ dK**：同じく $dW_k = 2\,U_1[t_0]^\top dK[t_0] + (0,0,2,-2)^\top dK[t_1] + 2\,U_1[t_2]^\top dK[t_2]$。
3. **dWv = U1ᵀ dV**：U1 の t0 行と t2 行は2文で同じなので、そこでは dV の2行を先に足します。t1 は外積2つです。U1 は ±1 なので掛け算はなく、符号付きの足し算だけです。**dV の t0 の2行を足してよいのはここ**（dW を作るとき）です。
4. **dU1 = dQ Wqᵀ + dK Wkᵀ + dV Wvᵀ**（猫文の3行、分岐点 U1）：Wq, Wk の d0, d1 行は0なので、dQ と dK の項は d2, d3 列にしか入りません。Wv は d0 行 = −(d1 行) で d2, d3 行が0なので、dV の項は d0, d1 列にしか入らず、$dU_1[i,d_1] = -dU_1[i,d_0]$、$dU_1[i,d_0] = dV[i]\cdot(1,-1,1,-1)$ です。3項を別々に求めてから足します。

**6.8**

1. **LN1経由**：6行とも σ = 1、U1 = ±1 なので、6.3 と同じ **ペアの規則** で求めます。ペアは t0, t2 が (d0, d1) と (d2, d3)、猫文 t1 が (d0, d2) と (d1, d3) です。
2. **dX0 = dX1 + LN1経由**（分岐点 X0）。犬文の行は d0↔d1 の入れ替え。

**6.9**

1. **dP**〔3×4〕：P は2文で共有なので、$dP[t] = dX_0[\text{猫}t] + dX_0[\text{犬}t]$（同じ位置の2行を足す）。足した行は d0 = d1 になります。
2. **dE**〔6×4〕：使われた行に dX0 を足し込みます。`<s>` ← 両文の t0（= dP[t0]）、が ← 両文の t2（= dP[t2]）、猫 ← 猫文 t1 だけ、犬 ← 犬文 t1 だけ（= 猫 行の d0↔d1）。鳴く・吠える 行は0です。

## 計算する前に予想しよう

## 検算

**組み込みの検算（ミラーを使わずに手で計算する2か所）**：ずれたら、猫文の行かミラーの写し方のどちらかに誤りがあります。

1. 犬文 t2 の dX2 を、犬文 t2 の dlogits から 6.1 の式で直接求め、猫文 t2 の dX2 の d0↔d1 を入れ替えたものと一致することを確かめる（足し引き2回）
2. ヘッド0 の犬文 t0 の dV を、**犬文の** t0, t1, t2 の dO から $\sum_i A_0[i,k_0]\, dO_0[i]$ で直接求め、猫文 t0 の dV0 を入れ替えたものと一致することを確かめる（積3回）。猫文と同じ値にならないことも確かめます（準備 (d)）

**列和ベクトル 1ᵀW**（dX = dY Wᵀ の行和チェックサム用：$\sum_k dX[t,k] = dY[t]\cdot(\mathbf 1^\top W)$。Part 2 の重みでコードで計算した値）

<details><summary>計算を終えてから開く（数値は mini_gpt2.py の出力と、同じ実装でより多くの桁を表示したもの）</summary>

**1. dA は ∓1/3、厳密に**：予想2 のとおり、dA0[t2, k1] = −1/3、dA1[t2, k1] = +1/3。その前の段階も、dX2[猫文 t2, d0] − dX2[猫文 t2, d1] = −0.1245 − 0.0421 = −1/6 と、きれいな値です。勾配は「ヘッド0 は t1 をもっと見よ、ヘッド1 はもっと見るな」と言っています。7.3 で実際に、ヘッド0 の t2 → t1 は 0.5035 → 0.6757、ヘッド1 は 0.5035 → 0.4106 と動きます。

## よくあるミス

- **÷3 にする**：Part 2 は6行の平均なので ÷6 です。行和の検算では見つけられません（dlogits の行和は ÷ の有無に関係なく0）。
- **t0 の逆伝播を「写す」**：順伝播の t0 は同じでも、dlogits から違います。犬文の行はいつも「ミラー」で写します（A の「よくあるミス」と同じ）。
- **「先に足す」を各行の勾配に使う**：dV の t0 の2行を1行にまとめてしまう、など。足してよいのは dW と dP・dE を作るときだけです（準備 (d)）。
- **dW で犬文の行を足し忘れる**：猫文の3行だけで dW を作ると、勾配がおよそ半分になります。「先に足す」を使えば、足し忘れが起きにくくなります。
- **ミラーの入れ替えを間違える**：dQ・dK の列は入れ替えない。dV と dOcat は **ヘッドの中で**（d0↔d1、d2↔d3）入れ替え、d0↔d2 ではない。dlogits は 猫↔犬 と 鳴く↔吠える の **両方** を入れ替える。
- **dP で2文を足し忘れる／dE と混同する**：dP[t1] は2文の t1 の和ですが、dE[猫] は猫文 t1 だけです。Part 1 の「dE の使われた行 = dP」は、`<s>` と が の行でしか成り立ちません。
- **dA が0の列で dS も0にする**：dA の k0, k2 列は0でも、dS は $-A\,s$ で0ではありません。
- **dV で他の文のクエリまで足す**：マスクで文をまたぐ注意は0です。dV[j] の和は同じ文のクエリだけ。
- **1/√2 を忘れる**：dQ と dK にも掛かります（Part 1 と同じ）。
