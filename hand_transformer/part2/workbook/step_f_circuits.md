## 手順

始める前に、下の「計算する前に予想しよう」の4問に、自分の予想を書いておいてください。

### F1 QK 回路：どこを見るか（8.1）

スコアは、クエリの行 $u_i$ とキーの行 $u_j$ だけで書けます。

$$S_h[i,j] = \frac{(u_i W_q^{(h)})\cdot(u_j W_k^{(h)})}{\sqrt2} = \frac{u_i\, M_h\, u_j^\top}{\sqrt2},\qquad M_h = W_q^{(h)}\,{W_k^{(h)}}^\top\quad(4\times4)$$

$M_h$ は入力に依らない「このヘッドは、どんな行がどんな行を見たがるか」の表です。

1. **M0, M1 を作る**：この重みでは、各ヘッドが2列のうち **1列目しか使っていません**（Wq と Wk の d1 列と d3 列は全部0）。そこで $M_h$ は2つの4次元ベクトルの外積になります：$M_h = w_q\, w_k^\top$、$w_q = W_q[:, d_{2h}]$、$w_k = W_k[:, d_{2h}]$。積は 0 か ±1 か 0.5 との積だけです。
2. **スコアで確かめる**：ソースは4種類（`<s>`(t0)、猫(t1)、犬(t1)、が(t2)）です。t2（が）のクエリから4つのキー行へのスコア $u_{\text{が}} M_h u_j^\top/\sqrt2$ を 8.1 の表に書き、3.2 の S の t2 行（k0, k1, k2、両方の文のブロック）と一致することを確かめます。外積の形なら $(u_i\cdot w_q)(u_j\cdot w_k)/\sqrt2$ で、**各ソースの「キーの値」$u_j\cdot w_k$ を先に4つ求めておく** と速いです。
3. **階数と、見分けられないもの**：$M_h$ は 4×2 と 2×4 の積なので、階数は最大2です（この重みでは1）。2つのキー行 u, u' が **どのクエリからも同じスコア** をもらうのは、$M_h (u - u')^\top = 0$、つまり差 u − u' が $M_h$ の右の零空間に入るときです。この重みでは $u\cdot w_k$ が等しいとき、です。
   - 4つのソースのキーの値を比べ、**ヘッド0 は「猫」と「犬」を見分けられるか、「`<s>`」と「が」を見分けられるか** を答えます
   - クエリ側（左の零空間）も同じように、$u\cdot w_q$ でどのクエリ行が同じ見方をするかを読みます
4. **M ≠ Mᵀ**：$M_0$ の (d2, d3) と (d3, d2) を比べます。「が が 猫 を見るスコア」$u_{\text{が}} M_0 u_{\text{猫}}^\top/\sqrt2$ と「猫 が が を見るスコア」$u_{\text{猫}} M_0 u_{\text{が}}^\top/\sqrt2$ を両方求めます（後者は因果マスクで実際には使われませんが、回路としては定義できます）。

### F2 QK 回路の変化（8.2）

lr = 1 の更新 $W_q' = W_q - dW_q$、$W_k' = W_k - dW_k$ を代入すると

$$M' = (W_q - dW_q)(W_k - dW_k)^\top = M \;-\; dW_q W_k^\top \;-\; W_q\,dW_k^\top \;+\; dW_q\,dW_k^\top$$

一般の lr では $\Delta M = -\mathrm{lr}\,(dW_q W_k^\top + W_q\,dW_k^\top) + \mathrm{lr}^2\, dW_q\,dW_k^\top$ です。最後の **積の項** は lr の2乗に比例する「2つの重みが同時に動いた」分で、7.2 の1次予測には入っていません。

1. **3つの項を作る**：dWq, dWk も各ヘッドの1列目以外は0なので（6.7）、3つの項はどれも外積です（$\delta_q = dW_q[:, d_{2h}]$、$\delta_k = dW_k[:, d_{2h}]$ として $-\delta_q w_k^\top$、$-w_q \delta_k^\top$、$\delta_q \delta_k^\top$）。各ヘッドで3つの 4×4 を作り、$M' = M + (\text{3つの和})$ を 8.2 の表に書きます。$w_q' w_k'^\top$（7.1 の Wq', Wk' の列）を直接計算しても同じになることを確かめます。
2. **階数は1のまま**：Wq と Wk の使っていない列（d1 と d3）は、勾配も厳密に0でした（6.7）。$dQ[:,d_1] = dS\,K[:,d_1]/\sqrt2$ で K の d1 列が0、$dK[:,d_1] = dS^\top Q[:,d_1]/\sqrt2$ で Q の d1 列が0だからです。互いに相手が0なので、**何ステップ更新しても0のまま** です（コードで20ステップ後も厳密に0）。
3. **見分けられないものは変わったか**：$w_q'$ と $w_k'$ の d0 成分と d1 成分を比べます。$(1, -1, 0, 0)$（猫と犬の差の向き）は、更新後も零空間に入っていますか？
4. **更新後のスコア**：8.2 の「t2 クエリ → 各キー行のスコア」は、**U1'**（7.3）のソース行で計算します。$u'\cdot w_q'$ と $u'\cdot w_k'$ は 7.3 の Q', K' の列そのものなので、$Q'[t_2,d_{2h}]\,K'[j,d_{2h}]/\sqrt2$ で求まり、7.3 の S' の t2 行と一致します。
5. **スコアの変化を分ける**（補助表 F2）：t2（が）→ 猫(t1) のスコアの変化を、**更新前の U1 のまま** 3つの項に分け、残りを U1 → U1' の変化の分とします：

   $$\underbrace{u_{\text{が}} M' u_{\text{猫}}^\top - u_{\text{が}} M u_{\text{猫}}^\top}_{\text{3つの項の和}} \quad\text{と}\quad \underbrace{u'_{\text{が}} M' {u'_{\text{猫}}}^\top - u_{\text{が}} M' u_{\text{猫}}^\top}_{\text{U1 の変化の分}}\qquad(\text{どちらも } /\sqrt2)$$

   外積の項は $(u_{\text{が}}\cdot a)(b\cdot u_{\text{猫}})/\sqrt2$ の形なので、U1 が ±1 の今は、符号付きの和を2つ作って積を1回するだけです。積の項が線形の項の何割かを出します。

### F3 OV 回路：何を運ぶか

ヘッド h が t2 の残差ストリームに書き込む量と、それが logits に与える量は

$$\text{書き込み}_h = \sum_j A_h[t_2,j]\; u_j\, OV_h,\qquad OV_h = W_v^{(h)}\, W_o^{(h)}\quad(4\times4),\qquad \text{logits への寄与} = \text{書き込み}_h\, W_{out}$$

です。文脈に効くのは「鳴く − 吠える」の向きだけなので、読み出しの向き $r = W_{out}[:,\text{鳴く}] - W_{out}[:,\text{吠える}]$（4次元）への射影 $OV_h\, r$ を見ます。$u\, OV_h\, r$ は「ソース行 u を1だけ見たとき、ヘッド h が (鳴く − 吠える) をいくつ押すか」です。

1. **更新前**：$OV_0$、$OV_1$、r、$OV_h r$ を求め、4つのソースについて $u\,OV_h\,r$ を出します。8.1 の OV 回路の表の「鳴く 列 − 吠える 列」と一致することを確かめます。
2. **1単位の注意で運ぶ差 β**（C の $w_h = W_{o,h}\,r$ は2成分のベクトルでしたが、ここの $\beta_h$ はソースまで含めた1つの数です）：t0 と t2 のソース行は2文で同じで、注意のパターンも2文で同じなので、C への寄与では打ち消し合います。残るのは t1 だけです：

   $$\text{ヘッド } h \text{ の C への寄与} = A_h[t_2,k_1]\cdot \beta_h,\qquad \beta_h = (u_{\text{猫}} - u_{\text{犬}})\, OV_h\, r$$

   5.5 の値項（ヘッド0 で 4.0279）になることを確かめます。
3. **更新後**：$r' = W_{out}'[:,\text{鳴く}] - W_{out}'[:,\text{吠える}]$、先に $W_o'^{(h)} r'$（2次元）を求めてから $OV_h' r' = W_v'^{(h)}\,(W_o'^{(h)} r')$ とすると積が少なくて済みます。ソースは **U1'** の行（8.2 の表と同じ）。$\beta_h'$ と $A'_h[t_2,k_1]\cdot \beta_h'$ を出し、7.4 のヘッドの寄与と比べます。8.2 の OV 回路の表（4×6）は [answers.md](answers.md#82-回路で読む更新後) から写して構いません。手で求めるのは「鳴く − 吠える」の1列だけで十分です。
4. **FFN と X0 が C に効かない理由**：ミラーで不変なので、r はいつも (a, −a, 0, 0) の形、W2 はいつも d0 列 = d1 列で F は d0 = d1、したがって $F\cdot r = 0$。t2 の X0 は2文で同じ。よって **C = Σ_h（ヘッド h の寄与）が厳密に成り立ちます**（更新前も後も）。

### F5 「注意が動いた」と「注意が役に立った」

F3 の $A_h[t_2,k_1]$ を a、$\beta_h$ を β と書くと、ヘッドの寄与は $a\,\beta$ です。更新による変化を3つに分けます。

$$\Delta(a\,\beta) = \underbrace{\Delta a\cdot \beta}_{\text{注意の項}} + \underbrace{a\cdot\Delta \beta}_{\text{値の項}} + \underbrace{\Delta a\cdot\Delta \beta}_{\text{交差}}$$

## 計算する前に予想しよう

**予想1　ヘッド0 は何を見分けるか**：Wq と Wk の0でない成分（params.md）だけを見て、ヘッド0 のキー側は4つのソース（`<s>`、猫、犬、が）のうちどれとどれを区別できるか、予想してください。

<details><summary>答え</summary>

キーの値 $u\cdot w_k$（$w_k = W_k[:, d_0] = (0, 0, 0.5, -0.5)$）は `<s>` 0、猫 1、犬 1、が 0。**猫と犬は区別できず、`<s>` と が も区別できません**。見分けるのは「t1 の位置か、そうでないか」だけで（P の t1 行だけが d2 − d3 ≠ 0）、ヘッド0 は **位置 t1 の検出器** です。ヘッド1 のキー側も同じ $w_k$ です。クエリ側は、ヘッド0 では `<s>` −1、猫・犬・が +1、ヘッド1 では `<s>`・猫・犬 −1、が +1 です。
</details>

**予想2　更新で QK 回路はどう変わるか**：更新後、$M_h'$ の階数は2になるでしょうか？ 猫と犬の差 (1, −1, 0, 0) は零空間に残るでしょうか？

<details><summary>答え</summary>

**階数は1のまま**（使っていない列は勾配も0なので、何ステップでも0。F2 の 2）。**(1, −1, 0, 0) も零空間に残ります**（ミラーで $w_q'$ と $w_k'$ の d0 成分 = d1 成分。A6）。更新後のキーの値はヘッド0 で `<s>` −0.0543、猫 1.3032、犬 1.3032、が −0.1359。猫と犬は同じままですが、`<s>` と が は少しだけ見分けられるようになりました。
</details>

**予想3　1つの群だけ更新するなら**：損失を一番下げるのはどの群？ C を一番大きくするのはどの群？ その2つは同じ？

<details><summary>答え</summary>

損失は **Wout だけ**（L = 1.0180）が一番下げますが、そのとき **C は厳密に0** です。C を一番大きくするのは **Attention 全部**（C = 4.4235）で、全部を更新したとき（3.6937）より大きくなります。2つは別の群です（F4、見どころ 5）。
</details>

**予想4　ヘッド1 は t1 を見なくなった**：ヘッド1 の t2 → t1 の注意は 0.5035 → 0.4106 と減りました。これは C を増やした？減らした？

<details><summary>答え</summary>

**増やしました**（注意の項 +0.7434）。ヘッド1 が運ぶ β は負（−8：猫 を見ると (鳴く − 吠える) を下げる）なので、見る量を減らすと C は増えます。同じ「注意が動いた」でも、役に立つ向きは運ぶ値の符号で決まります（F5）。
</details>

## よくあるミス

- **転置を間違える**：$M_h = W_q^{(h)} {W_k^{(h)}}^\top$（4×4）。$W_q^\top W_k$（2×2）や $W_q W_k$ ではありません。スコアにするときの /√2 も忘れずに。
- **4列全部で M を作る**：ヘッド h が使うのは Wq, Wk の自分の2列だけです。4列全部で作ると、2つのヘッドの回路が混ざります。
- **M を対称だと思う**：$M_0$ の (d2, d3) と (d3, d2) は違います。「が が 猫 を見る」と「猫 が が を見る」は別のスコアです。
- **ΔM を線形の2項だけにする**：それは1次近似です。lr = 1 では積の項（t2 → 猫 のスコアで +0.0615、+0.0956）が無視できません。
- **OV の掛ける順番**：行ベクトル規約なので $u\,W_v^{(h)} W_o^{(h)}$。$W_o W_v$ ではありません。
- **r を 鳴く の列だけにする**：C に効くのは (鳴く − 吠える) の差の向きです。
- **8.2 のスコアを更新前の U1 で計算する**：8.2 の表は U1'（7.3）のソース行です。U1 のままだと補助表 F2 の「更新前の U1 で M'」の行（1.2324 など）になります。
- **「注意が減った ⇒ そのヘッドは悪くなった」**：ヘッド1 は注意が減って C に貢献しました（F5）。
- **「Wout だけで一番損失が下がった ⇒ Wout が一番学んだ」**：Wout だけでは文脈を何も学びません（C = 0）。
