# Part 2 2文タスク — Attention が文脈を運ぶ瞬間を手で見る

**ゴール**：Part 1 と **まったく同じモデル**（1層・2ヘッド・d_model 4・Pre-LN・SGD lr = 1）で、2つの文を同時に1ステップ学習させます。

- **猫文**：`<s> 猫 が` → `猫 が 鳴く`
- **犬文**：`<s> 犬 が` → `犬 が 吠える`

t2 の入力はどちらの文も「が」です。「鳴く」か「吠える」かを決める情報は、t1（猫／犬）から **Attention が運んでくるしかありません**。
その「運ぶ」仕組みが1回の SGD でどう育つかを、紙と電卓で追います。

> **はじめ方（5分）**
> 1. 前提：Part 1 を最後まで終えていること（§2）。用意するものは Part 1 と同じです。[`workbook/params.md`](workbook/params.md) と [`workbook/blank.md`](workbook/blank.md) を印刷します
> 2. この README の §1〜§6 を読みます。§8 は結果の要約なので、最後に開いてください
> 3. [`workbook/step_a_map.md`](workbook/step_a_map.md)（A 地図と証明）から始めます。答え合わせは [`workbook/answers.md`](workbook/answers.md)、または `hand_transformer/` で `python3 part2/mini_gpt2.py --only 2.1`

## 1. なぜ Part 2 か：Attention が「必要」になる

Part 1 の `<s>→猫, 猫→が, が→鳴く` は、**直前の1語だけで次が決まる** タスクでした（[Part 1 README §2 の「正直な限界」](../README.md#2-モデル仕様と設計判断)）。
Attention の **計算と勾配の流れ** は学べましたが、Attention が **なぜ必要か** は見えません。

Part 2 では、t2 の入力が2文とも「が」です。Attention 以外の演算はすべて **行ごと**（自分の行しか見ない）なので、
Attention が t1 から何も運ばなければ、猫文 t2 と犬文 t2 は最後まで同じ計算になり、「鳴く」と「吠える」を分けられません（A の問 A3 で証明します）。

| | 損失の下限（6位置の平均） |
|---|---:|
| t2 の Attention 出力を0にしたモデル | $4\ln2/6 \approx 0.4621$ |
| このモデル（Attention あり） | $2\ln2/6 \approx 0.2310$ |

残りの $2\ln2/6$ は t0 の分です。t0 は `<s>` しか見られないので、次が猫か犬かは誰にも分かりません（問 A4）。

## 3. Part 1 から何が変わるか

| 項目 | Part 1 | Part 2 |
|---|---|---|
| データ | 1文・3位置 | **2文・6行**（猫文 t0, t1, t2、犬文 t0, t1, t2 の順に積む） |
| 語彙 | 5：`<s>`, 猫, が, 鳴く, 。 | **6**：`<s>`, 猫, 犬, が, 鳴く, 吠える |
| マスク | 3×3 の因果マスク | **6×6 のブロック対角の因果マスク**：見てよいのは「同じ文の、自分以前の位置」だけ。文をまたぐ部分は常に −∞ なので、実質は 3×3 が2枚。記入欄も文ごとの 3×3 で書きます |
| 位置埋め込み P | 3行 | 3行のまま **2文で共有**（どちらの文の t1 も P の t1 行を使う） |
| 損失 | 3位置の平均 | **6位置の平均**（dlogits = (p − y)/6） |
| パラメータ | 180個 | **188個**（E 24 + P 12 + Wq/Wk/Wv 48 + Wo 16 + W1 32 + W2 32 + Wout 24） |
| 重みの工夫 | U1 = LN(X0) が ±1 | E は d0, d1（**どの単語か**）、P は d2, d3（**どの位置か**）だけを使う。X0 そのものが ±1 で、σ1 = 1、**U1 = X0** |
| 新しいチェックポイント | — | 5.4 文脈の使い分けとアブレーション、5.5 ヘッドの寄与の分解、7.5 群ごとの更新（参考表）、8.1・8.2 回路 |
| 新しい道具 | — | 文脈の差 C、アブレーション、パターン項と値項、パッチング（直接効果と総効果）、QK 回路と OV 回路、重みの手設計 |

**文脈の差 C**：t2 の「鳴く − 吠える」の logit 差を2文で引いたもの。

$$C = \big(\ell_{\text{鳴く}} - \ell_{\text{吠える}}\big)_{\text{猫文 }t_2} - \big(\ell_{\text{鳴く}} - \ell_{\text{吠える}}\big)_{\text{犬文 }t_2}$$

C > 0 なら、モデルは猫文で犬文より「鳴く」を強く推しています。t2 の入力は同じなので、**C ≠ 0 は Attention が文脈を使っている証拠** です。Part 2 は「C = 0 から始まり、1ステップでいくつになるか」を追う物語です。

## 4. 構造の事実（A で、数字を使わずに証明します）

1. **猫文 t0 と犬文 t0 は、順伝播の最後まで同じ**（どちらも `<s>` だけを見る）。ただし正解（猫／犬）が違うので、逆伝播は同じではありません
2. **猫文 t2 と犬文 t2 は、Q, K, V まで同じ**。違いが入り込めるのは Attention（スコアと AV）だけです
3. **t2 の Attention 出力を0にすると、2文の t2 の予測は完全に同じになる**（Attention 以外は行ごとの演算だから）
4. **損失の下限は $2\ln2/6 \approx 0.2310$**。t0 では p(猫) = p(犬) にしかなれません
5. **ミラー対称性**：d0↔d1、猫↔犬、鳴く↔吠える（と V 空間のヘッド内の入れ替え）で猫文は犬文に移り、初期パラメータはこの入れ替えで変わりません。**SGD はこの性質を保つ** ので、更新の前も後も、順伝播も逆伝播も、犬文の数はすべて猫文の数の並べ替えです。これが組み込みの検算になります
6. **QK は猫と犬を区別できない**：両ヘッドとも t1 の名詞を、猫でも犬でも同じスコアで見ます。注意のパターンは2文で同じ（更新前も後も）で、5.5 の「パターン項」は厳密に0です

この重みでは、さらに次のことが成り立ちます（B と C で数字として確かめます）。

- **1回目の順伝播の行列積（Q, K, V、スコア、AV、Wo、W1、W2、Wout）には、小数×小数の掛け算が1回もありません**。相手はいつも 0、±1、±0.5、±2 のどれかです。小数どうしの掛け算は LN2 の分散で使う $1.6790^2$ だけです（割り算は softmax と LN2 の正規化で出ます）
- **OV**：ヘッド0 は t1 の「猫」を「鳴く +2、吠える −2」として運び、ヘッド1 はその逆を運びます。t2 では2つのヘッドが同じ重みで t1 を見るので **ちょうど打ち消し合い**、C は厳密に0、t2 の予測は鳴くと吠えるが厳密に 50:50 から始まります

## 6. ミラー対称性と共有行で手間を半分にする

6行あっても、**手で計算するのは猫文の3行だけ** です。犬文の行は次の3通りで埋めます。

| 犬文の行 | 埋め方 | 根拠 |
|---|---|---|
| t0（順伝播） | 猫文 t0 を **写す** | 問 A1 |
| t2（3.1 の Q, K, V まで） | 猫文 t2 を **写す** | 問 A2 |
| それ以外 | 猫文の同じ位置の行に **ミラー規則** を当てる | 問 A5 |

**ミラー規則**（猫文の行 → 犬文の行。コードで、更新の前後とも全チェックポイントで一致を確認済み）

| 量 | 犬文の行の作り方 |
|---|---|
| 残差ストリームの量（X0, U1, Attn, X1, U2, F, X2） | 列 **d0 と d1 を入れ替える** |
| LN の μ, σ², σ、nll | **そのまま** |
| Q, K, スコア S, Attention 重み A、FFN の Z, R | **そのまま** |
| V, O0, O1, Ocat（値の空間） | **ヘッドの中で入れ替える**（d0↔d1、d2↔d3） |
| logits, p | 列 **猫↔犬、鳴く↔吠える を入れ替える** |

- 記入欄（2.1–5.3）のマスク・「—」を除く 582 マスのうち、手で計算するのは猫文の 291 マスです。犬文の 291 マスのうち 98 マスは記入欄に「＝猫文」と印があり、残り 193 マスも写すかミラー規則で並べ替えるだけです
- **組み込みの検算**：犬文の行のうち数か所（B で指定）は、ミラー規則を使わずに手で計算し、規則どおりになることを確かめます。ずれたら、どちらかに計算ミスがあります
- 逆伝播（D）では t0 も「写す」ではなく **ミラー規則** で埋めます（正解が猫と犬で違うので、dlogits の t0 行からして違います）。ミラー規則は逆伝播でもそのまま使えます

<details><summary><b>このパートで起きること</b>（結果の要約。先に知りたくない人は開かない）</summary>

学習率 1 の SGD を1回（数値は `python3 part2/mini_gpt2.py --only 7.4` などの出力）：

| | 更新前 | 更新後 |
|---|---:|---:|
| 損失 L | 1.3507 | **0.5482** |
| 文脈の差 C | **0**（厳密に） | **3.6937** |
| t2 の正解（鳴く／吠える）の確率（2文とも） | 0.2528（50:50） | **0.7524** |
| t1 の正解（が）の確率 | 0.3503 | 0.7394 |
| t0 の p(猫) = p(犬)（厳密に等しい） | 0.1963 | 0.3470 |
| ヘッド0 の t2 → t1 の注意（2文とも） | 0.5035 | 0.6757 |
| ヘッド1 の t2 → t1 の注意（2文とも） | 0.5035 | 0.4106 |
| C へのヘッドごとの寄与（ヘッド0 ／ ヘッド1） | +4.0279 ／ −4.0279 | +5.3784 ／ −1.6847 |

- 勾配から予言できる下がり幅 −lr‖g‖² = −1.1717 に対し、実際は −0.8025（比 0.685）
- 更新前は2つのヘッドが同じ大きさで逆向きの情報を運び、t2 で打ち消し合っていました。1ステップで **ヘッド0 は t1 をより強く見るようになり、ヘッド1 は弱く見るようになって**、釣り合いが崩れ、C が生まれます。注意のパターンは2文で同じまま（パターン項は更新後も0）で、効いているのは「どれだけ見るか」と「何を運ぶか」です

**どの群の更新が文脈を学ばせたか**（7.5：1つの群だけを更新した場合）

| 更新した群 | C | L |
|---|---:|---:|
| Wq, Wk（QK） | 1.8845 | 1.2065 |
| Wv, Wo（OV） | 2.5282 | 1.2157 |
| Wq, Wk, Wv, Wo（Attention 全部） | 4.4235 | 1.1250 |
| Wout だけ | **0** | **1.0180** |
| W1, W2（FFN） | 0 | 1.1655 |
| E, P（埋め込み） | −0.0834 | 1.1583 |
| 全部 | 3.6937 | 0.5482 |

1つの群だけの更新で損失が一番下がるのは Wout ですが、C は0のまま。**「損失は下がったのに、文脈は何も学んでいない」** 更新がありうることが分かります。

- 損失の下限は $2\ln2/6 \approx 0.2310$。`--train 20` で 0.2362 まで近づきます
