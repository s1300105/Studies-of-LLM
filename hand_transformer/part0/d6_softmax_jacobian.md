# D6 softmax のヤコビアン（40分）

## 目標

- $a = \mathrm{softmax}(s)$ の微分 $\partial a_j/\partial s_i = a_j(\delta_{ij} - a_i)$ を導き、ヤコビアン $J$ を一度は全部書き出します。
- 実用の式 $ds = a \odot (da - r)$、$r = \sum_i a_i\, da_i$ を使えるようにします（$J$ を作らずに済む）。
- 「要素1つの softmax は勾配0」「マスク位置は勾配0」「飽和した softmax は勾配が小さい」を数字で見ます。

D5 では softmax の後ろに交差エントロピーがあったので勾配が $p - y$ にまとまりました。Attention の softmax（Part 1 の 3.3）の後ろには $O = AV$ があるので、そうはまとまりません。そのための一般の式です。

- **目安時間**：40分（(0) 予想 2分 / (1) ケース1 15分 / (2)〜(4) ケース2〜4 10分 / 検算 10分 / 説明 3分）
- **Part 1 で使う所**：6.5（dS = A ⊙ (dA − r)、t0 行は0、マスク位置は0）、6.6（dQ の t0 行が0）、ステップ6 の「見どころ」3（飽和したキー）／ derivations.md 問4・問5

## 問題

$a = \mathrm{softmax}(s)$ の上流の勾配 $da = \partial L/\partial a$ が与えられたとき、$ds = \partial L/\partial s$ を求めます。

**(0) 予想**：$ds$ の成分をすべて足すといくつでしょう？ $da$ の全成分に2を足すと、$ds$ はどうなるでしょう？

**(1) ケース1**：$a = (0.5,\ 0.25,\ 0.25)$、$da = (1,\ -1,\ 0.5)$

- (a) $r = \sum_i a_i\, da_i$ と $ds = a \odot (da - r)$
- (b) ヤコビアン $J = \mathrm{diag}(a) - a^\top a$（3×3、$J[i, j] = \partial a_j/\partial s_i$）を書き出し、$ds = J\,da$ で (a) を検算（$J$ は対称）
- (c) $da + 2 = (3,\ 1,\ 2.5)$ として $ds$ を計算し直す

**(2) ケース2（マスクのある行）**：$a = (0.4,\ 0.6,\ 0)$（3番目は因果マスクで $-\infty$ だった位置）、$da = (0.5,\ -0.5,\ 7)$。$ds$ は？ $da_2 = 7$ はどこへ行きましたか？ 2要素の公式 $ds_0 = a_0 a_1 (da_0 - da_1)$、$ds_1 = -ds_0$ も確かめてください。

**(3) ケース3（要素1つ）**：$a = (1)$、$da = (0.8)$。$ds$ は？

**(4) ケース4（飽和）**：$a = (0.98,\ 0.01,\ 0.01)$、$da = (1,\ -1,\ 0.5)$（ケース1と同じ）。$ds$ と $\max_i |ds_i|$ をケース1と比べてください。

**(説明)** Part 1 の Attention で、t0（`<s>`）のクエリ $Q[t0]$ に勾配が来ない理由を、(3) を使って説明してください。

## 手順のヒント

<details><summary>ヒントを開く</summary>

- $a_j = e^{s_j}/\sum_k e^{s_k}$ を $s_i$ で微分します。$i = j$ なら商の微分で $a_j - a_j^2$、$i \ne j$ なら $-a_i a_j$。まとめて $a_j(\delta_{ij} - a_i)$。
- $ds_i = \sum_j \dfrac{\partial a_j}{\partial s_i}\, da_j = a_i\, da_i - a_i\sum_j a_j\, da_j = a_i\,(da_i - r)$。
- $r$ は「$a$ で重み付けした $da$ の平均」。$ds_i$ は「$da_i$ が平均より大きいか小さいか」に $a_i$ を掛けたものです。
- 2要素では $a_0 + a_1 = 1$ なので $da_0 - r = da_0 - a_0da_0 - a_1da_1 = a_1(da_0 - da_1)$。
- (4) $J$ の対角は $a_i(1 - a_i)$ で、$a_i$ が0か1に近いと小さくなります（最大でも 0.25）。

</details>

## 検算

1. $ds$ の和 = 0、$J$ の各行の和 = 0（$\sum_j a_j = 1$ は定数なので、どの $s_i$ で微分しても0）。
2. **手で数値微分**：$a = (0.5, 0.25, 0.25)$ は $s = (\ln 2,\ 0,\ 0)$ の softmax です（$\ln 2 = 0.6931$）。$L = da\cdot a$ とすると $\partial L/\partial a = da$ なので、$s_0$ を ±0.1 動かした中心差分が $ds_0$ になるはずです。$e^{0.1} = 1.105171$、$e^{-0.1} = 0.904837$ を使います。

<details><summary>検算の値</summary>

| s0 | 分子 2e^(±0.1) | 分母 2e^(±0.1) + 2 | a | L = da·a |
|---|---:|---:|---|---:|
| ln 2（元） | — | — | (0.5, 0.25, 0.25) | 0.375 |
| ln 2 + 0.1 | 2.210342 | 4.210342 | (0.524979, 0.237510, 0.237510) | 0.406224 |
| ln 2 − 0.1 | 1.809675 | 3.809675 | (0.475021, 0.262490, 0.262490) | 0.343776 |

中心差分 $(0.406224 - 0.343776)/0.2 = 0.312240$。解析解 $ds_0 = 0.3125$ との差 $-2.60\times10^{-4}$ は中心差分の誤差です。

</details>

## 答え

<details><summary>答えを開く</summary>

**(1)**

- (a) $r = 0.375$、$da - r = (0.625,\ -1.375,\ 0.125)$、$ds = (0.3125,\ -0.34375,\ 0.03125)$
- (b)

  | J | s0 | s1 | s2 | 行和 |
  |---|---:|---:|---:|---:|
  | s0 | 0.25 | −0.125 | −0.125 | 0 |
  | s1 | −0.125 | 0.1875 | −0.0625 | 0 |
  | s2 | −0.125 | −0.0625 | 0.1875 | 0 |

  $J\,da = (0.3125,\ -0.34375,\ 0.03125)$ で (a) と一致。
- (c) $r = 2.375$ に変わりますが、$ds = (0.3125,\ -0.34375,\ 0.03125)$ は**変わりません**。

**(0) 予想の答え**：和は0。$da$ に定数を足しても $ds$ は変わりません（$a$ の和が常に1なので、$da$ の「全成分に共通の部分」は $L$ に効かない）。

**(2)** $r = -0.1$、$ds = (0.24,\ -0.24,\ 0)$。2要素の公式 $0.4\cdot0.6\cdot(0.5 - (-0.5)) = 0.24$ と一致。$da_2 = 7$ は $a_2 = 0$ を掛けられて消えます。マスク位置のスコアを有限の大きな負の値（たとえば −30）にして数値微分しても、その位置の勾配は0になります。**マスクは逆伝播でも未来へ勾配を流しません**。

**(3)** $r = 0.8$、$ds = 1\cdot(0.8 - 0.8) = 0$。要素1つの softmax は $s$ によらず常に1（定数）なので、勾配は0です。

**(4)** $r = 0.975$、$ds = (0.0245,\ -0.01975,\ -0.00475)$。$\max|ds| = 0.0245$ で、ケース1の 0.34375 よりずっと小さい。$J$ の対角 $a_i(1 - a_i)$ は (0.0196, 0.0099, 0.0099) しかありません。**飽和した softmax（ほぼ one-hot）は勾配をほとんど通しません**。

**(説明)** t0 は因果マスクで k0 しか見られないので、t0 行の softmax は要素1つです。(3) のとおり $A[t0] = (1, 0, 0)$ は $S[t0]$ によらず一定で、$dS[t0] = 0$。$dQ = dS\,K/\sqrt2$ なので $dQ[t0] = 0$ です。順伝播で $Q[t0]$ を計算しなくてよいこと（Part 1 の 3.1）と、逆伝播で勾配が0になること（6.6）は、同じ事実の表と裏です。

</details>
