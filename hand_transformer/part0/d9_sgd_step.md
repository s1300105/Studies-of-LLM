# D9 SGD 1ステップ：1次予測と、曲率・学習率（50分）

## 目標

- 1次のテイラー展開 $\Delta L \approx -\eta\lVert g\rVert^2$ で、**更新する前に**損失の下がり幅を予言します（Part 1 の 7.2）。
- 実際の $\Delta L$ と予測のずれが曲率（2次の項 $\tfrac12\eta^2\, g^\top H g$）から来ることを、2次関数では**厳密に**確かめます。
- 学習率が大きすぎると、いちばん曲がった方向で行き過ぎて振動し、さらに大きいと損失が上がる（発散する）ことを見ます。
- 2つの重みを掛けて使うモデル（2層の最小モデル）では、勾配の向きの曲率が負になることがあり、実際の下がり幅が予測を**上回る**こともあると知ります。

- **目安時間**：50分（A：(0) 予想 2分 / (1) 4分 / (2) 表 12分 / (3)(4) 8分 ／ B：(5)(6) 14分 ／ 検算 6分 / 説明 4分）。任意の (7) +10分
- **Part 1 で使う所**：7.1（θ' = θ − lr·dθ）、7.2（1次予測）、7.4（実際の ΔL と比）／ derivations.md 問9

## 問題

### A 2次関数（曲率が方向によって違う）

$$L(\theta) = \tfrac12\big(\theta_0^2 + 4\,\theta_1^2\big),\qquad \theta = (1,\ 0.5)$$

ヘッセ行列（2階微分の行列）は $H = \mathrm{diag}(1, 4)$ です。θ1 の方向は θ0 の方向の4倍曲がっています。

**(0) 予想**：学習率 $\eta = 0.6$ で1回更新すると、$L$ は下がるでしょうか？

**(1)** $L(\theta)$、$g = \nabla L$、$\lVert g\rVert^2$、$g^\top H g$ を求めてください。

**(2)** $\eta = 0.1,\ 0.25,\ 0.5,\ 0.6$ について次の表を埋めてください。

| η | θ' = θ − ηg | L(θ') | 実際の ΔL | 予測 −η‖g‖² | 実際 / 予測 |
|---|---|---:|---:|---:|---:|
| 0.1 | | | | | |
| 0.25 | | | | | |
| 0.5 | | | | | |
| 0.6 | | | | | |

**(3)** 各方向の倍率 $\theta_i' = (1 - \eta h_i)\,\theta_i$（$h = (1, 4)$）を $\eta = 0.25,\ 0.5,\ 0.6$ で求めてください。$\eta = 0.5$ と $0.6$ で3ステップ続けたとき、$\theta_1$ と $L$ はどうなりますか？ 発散しない $\eta$ の上限はいくつですか？

**(4)** 1ステップでいちばん下がる $\eta^*$ と、そのときの $\Delta L$ を求めてください。

### B 2つの重みの積（2層の最小モデル）

$$L(w) = \tfrac12\,(w_0 w_1 - 1)^2,\qquad w = (0.5,\ 0.5)$$

**(5)** $r = w_0w_1 - 1$、$L$、$g = r\,(w_1,\ w_0)$、$\lVert g\rVert^2$ を求めてください。

**(6)** $\eta = 0.25,\ 0.5,\ 1,\ 2$ について、$w'$、$w_0'w_1'$、$L'$、実際の $\Delta L$、予測 $-\eta\lVert g\rVert^2$、比を求めてください。

**(7)（任意）** $H = \nabla r\,\nabla r^\top + r\begin{pmatrix}0 & 1\\ 1 & 0\end{pmatrix}$ を計算し、$g^\top H g$ の符号と $H$ の固有値を調べてください。

**(説明)** 比（実際 / 予測）が1より小さくなる場合と、1より大きくなる場合があるのはなぜですか？

## 手順のヒント

<details><summary>ヒントを開く</summary>

- 2次関数では $L(\theta - \eta g) = L(\theta) - \eta\lVert g\rVert^2 + \tfrac12\eta^2\, g^\top H g$ が**厳密に**成り立ちます（3次以上の項がない）。
- A は方向ごとに独立です：$g_i = h_i\theta_i$ なので $\theta_i' = \theta_i - \eta h_i\theta_i = (1 - \eta h_i)\theta_i$。
- $|1 - \eta h_i| < 1$ なら縮み、$= 1$ なら同じ大きさで往復、$> 1$ なら膨らみます。
- (4) $-\eta\lVert g\rVert^2 + \tfrac12\eta^2 g^\top Hg$ を $\eta$ の2次関数として最小化します。
- B：$g = (-0.375, -0.375)$ は2成分が等しいので、$w'$ も2成分が等しいまま（$w_0' = 0.5 + 0.375\,\eta$）。
- (7) $\partial^2 L/\partial w_0^2 = w_1^2$、$\partial^2 L/\partial w_0\partial w_1 = w_0w_1 + r$。

</details>

## 検算

1. A では、(2) の各行で「実際の ΔL ＝ $-\eta\lVert g\rVert^2 + \tfrac12\eta^2 g^\top Hg$」が厳密に成り立つことを確かめます。
2. 予測 $-\eta\lVert g\rVert^2$ は必ず負です（勾配の逆向きに動かすので、1次では必ず下がる）。
3. **手で数値微分**：A は $\theta_0$ を ±0.1、B は $w_0$ を ±0.1（$w_1$ は固定）。中心差分を $g_0$ と比べます。どちらも動かす変数について2次式なので、厳密に一致するはずです。

<details><summary>検算の値</summary>

- A：$L(1.1, 0.5) = 1.105$、$L(0.9, 0.5) = 0.905$ → $(1.105 - 0.905)/0.2 = 1$ ＝ $g_0$
- B：$w_0 = 0.6$ で $w_0w_1 = 0.3$、$L = 0.245$。$w_0 = 0.4$ で $w_0w_1 = 0.2$、$L = 0.32$ → $(0.245 - 0.32)/0.2 = -0.375$ ＝ $g_0$
- A の2次までの式は (2) の表の「実際の ΔL」と全行で一致します（答えの表の右端の列）。

</details>

## 答え

<details><summary>答えを開く</summary>

**(1)** $L = 1$、$g = (1,\ 2)$、$\lVert g\rVert^2 = 5$、$g^\top Hg = 17$

**(2)**

| η | θ' | L(θ') | 実際の ΔL | 予測 −η‖g‖² | 実際 / 予測 | 2次まで −η‖g‖² + ½η²gᵀHg |
|---|---|---:|---:|---:|---:|---:|
| 0.1 | (0.9, 0.3) | 0.585 | −0.415 | −0.5 | 0.83 | −0.415 |
| 0.25 | (0.75, 0) | 0.28125 | −0.71875 | −1.25 | 0.575 | −0.71875 |
| 0.5 | (0.5, −0.5) | 0.625 | −0.375 | −2.5 | 0.15 | −0.375 |
| 0.6 | (0.4, −0.7) | 1.06 | **+0.06** | −3 | −0.02 | 0.06 |

**(0) 予想の答え**：下がりません。$L$ は 1 → 1.06 に**上がります**。1次予測は −3（$L' = -2$ という、ありえない値）を予言しています。

**(3)** 倍率 $(1 - \eta h_0,\ 1 - \eta h_1)$：$\eta = 0.25$ で (0.75, 0)、$0.5$ で (0.5, −1)、$0.6$ で (0.4, −1.4)。

- $\eta = 0.25$ は θ1 方向にちょうどぴったり（1回で0に着く）。
- $\eta = 0.5$ で3ステップ：$\theta_1 = 0.5,\ -0.5,\ 0.5,\ -0.5$（同じ大きさで往復）、$L = 1,\ 0.625,\ 0.53125,\ 0.5078125$（θ0 の分だけ下がり、θ1 の分 0.5 は残り続ける）
- $\eta = 0.6$ で3ステップ：$\theta_1 = 0.5,\ -0.7,\ 0.98,\ -1.372$（符号を変えながら膨らむ）、$L = 1,\ 1.06,\ 1.9336,\ 3.766816$（発散）
- 発散しない上限は $\eta < 2/h_{\max} = 0.5$。**いちばん曲がった方向が学習率の上限を決めます**。

**(4)** $\eta^* = \lVert g\rVert^2/g^\top Hg = 0.2941$、$\Delta L = -\lVert g\rVert^4/(2\,g^\top Hg) = -0.7353$。予測どおりに下がり続けることはなく、$\eta$ を大きくするほど得、とはなりません。

**(5)** $r = -0.75$、$L = 0.28125$、$g = (-0.375,\ -0.375)$、$\lVert g\rVert^2 = 0.28125$（この点ではたまたま $L$ と同じ値です）

**(6)**

| η | w' | w0'·w1' | L' | 実際の ΔL | 予測 | 実際 / 予測 |
|---|---|---:|---:|---:|---:|---:|
| 0.25 | (0.59375, 0.59375) | 0.3525 | 0.209603 | −0.071647 | −0.0703125 | **1.0190** |
| 0.5 | (0.6875, 0.6875) | 0.47265625 | 0.139046 | −0.142204 | −0.140625 | **1.0112** |
| 1 | (0.875, 0.875) | 0.765625 | 0.027466 | −0.253784 | −0.28125 | 0.9023 |
| 2 | (1.25, 1.25) | 1.5625 | 0.158203 | −0.123047 | −0.5625 | 0.2188 |

小さい $\eta$ では、実際のほうが予測より**多く**下がっています。$\eta = 2$ では積が 1 を通り越して（1.5625）、下がり幅は予測の2割ほどしかありません。

**(7)** $H$ は w0 行 (0.25, −0.5)、w1 行 (−0.5, 0.25)。$g^\top Hg = -0.0703125 < 0$、固有値は −0.25 と 0.75。$H$ には負の固有値があり（下に凸ではない）、その固有ベクトルは (1, 1) の向きです。勾配 $g = (-0.375, -0.375)$ はちょうどこの直線上にある（$g/|g_0| = (-1, -1)$）ので、勾配の向きに進むと曲面は下に曲がっていきます。

**(説明)** 2次までで書くと

$$\frac{\text{実際}}{\text{予測}} \approx 1 - \frac{\eta}{2}\cdot\frac{g^\top Hg}{\lVert g\rVert^2}$$

です。

- **A** のように下に凸（$g^\top Hg > 0$）なら、比は必ず1より小さく、$\eta$ が大きいほど小さくなり、負（損失が上がる）にもなります。
- **B** のように勾配の向きの曲率が負（$g^\top Hg < 0$）なら、小さい $\eta$ では比が1を超えます。ただし $\eta$ を大きくすると3次以上の項が効いてきて、比は1より小さくなります（積 $w_0w_1$ が目標の 1 に近づくと下がり方が鈍り、$\eta = 2$ では 1 を通り越して 1.5625 になる）。
- Part 1 のモデルも重みどうしの積（$W_qW_k^\top$、$W_1$ と $W_2$、$W_{out}$ と残差ストリーム…）でできているので、B と同じことが起きます。7.4 の「予想1」で、lr によって比が1を超えたり下回ったりするのを確かめてください。

</details>
