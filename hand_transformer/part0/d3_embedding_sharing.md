# D3 埋め込みと重みの共有：勾配は位置ごとの和（40分）

## 目標

- 埋め込みの表引き $X = E[\text{ids}] + P$ の逆伝播が、**使われた行への足し込み（scatter-add）**になることを確かめます。同じトークンが2回出たら2回足します。
- 3つの位置で同じ $W$ を使うと、$dW$ は**位置ごとの外積 $x_t^\top g_t$ の和** $= X^\top dY$ になることを確かめます。重みの共有は、D2 の分岐（同じ値を何か所でも使う）の一種です。
- Part 1 の 7.1 の近道 $X_0' = X_0 - 2\,\text{lr}\,dX_0$ が成り立つ条件を理解します。

- **目安時間**：40分（(0) 予想 3分 / (1) 順伝播 5分 / (2) dW 10分 / (3) dX・dP・dE 7分 / 検算 8分 / (4) 更新 5分 / 説明 2分）
- **Part 1 で使う所**：2.1、6.9（dE, dP）、7.1（X0' の近道）、6.1・6.2・6.4・6.7（dW = 3位置の外積の和）／ derivations.md 問1、問7-3

## 問題

語彙は3個（a = 0, b = 1, c = 2）、次元 d = 2、入力は **ids = (a, b, a)**（位置 t0, t1, t2）です。a が2回出て、c は1度も出ません。

| E | d0 | d1 |
|---|---:|---:|
| a | 1 | 0 |
| b | 0 | 1 |
| c | 0.5 | 0.5 |

| P | d0 | d1 |
|---|---:|---:|
| t0 | 0 | 0.5 |
| t1 | 0.5 | 0 |
| t2 | −0.5 | 0 |

| W | d0 | d1 |
|---|---:|---:|
| d0 | 1 | −0.5 |
| d1 | 0.5 | 1 |

$Y = XW$ に上流から来る勾配 $G = dY$ を与えます。損失を $L = \sum_{t,j} G[t, j]\,Y[t, j]$ とすれば、ちょうど $dY = G$ になります。

| G = dY | d0 | d1 |
|---|---:|---:|
| t0 | 1 | 0 |
| t1 | 0 | −1 |
| t2 | 0.5 | 1 |

**(0) 予想**：$dE$ のどの行が0になりますか？ $dE$ の a 行は、$dP$ のどの行と等しくなりそうですか？

**(1) 順伝播**：$X = E[\text{ids}] + P$、$Y = XW$、$L$ を求めてください。

**(2) 重みの勾配**：位置ごとの外積 $x_{t}^\top g_{t}$（各 2×2）を3つ求め、足して $dW$ にしてください。それが行列積 $X^\top G$ と一致することも確かめてください。

**(3) 入力側の勾配**：$dX = G\,W^\top$、$dP$、$dE$ を求めてください。

**(4) 更新**：lr = 1 で $E' = E - dE$、$P' = P - dP$ と更新し、$X' = E'[\text{ids}] + P'$ を求めてください。Part 1 の近道 $X' = X - 2\,\text{lr}\,dX$ と比べて、どの位置で一致し、どの位置で外れますか？ 正しい式は何ですか？

**(説明)** Part 1 の 6.9 で「dE の使われた行は dP と完全に一致」し、7.1 の近道が使えたのはなぜですか？ もし入力が `<s> 猫 猫` だったら、どうなりますか？

## 手順のヒント

<details><summary>ヒントを開く</summary>

- $X[t] = E[\text{ids}[t]] + P[t]$。$E$ の v 行は、$\text{ids}[t] = v$ となる**すべての** $t$ の $X[t]$ に効きます → $dE[v] = \sum_{t:\ \text{ids}[t] = v} dX[t]$。1度も使われない行は0。
- $P$ の各行は1つの位置でだけ使われるので $dP[t] = dX[t]$（コピー）。
- 外積 $x_t^\top g_t$ は (2×1)(1×2) = 2×2 で、(k, j) 成分は $X[t, k]\cdot G[t, j]$。
- $X^\top G$ の (k, j) 成分は $\sum_t X[t, k]\, G[t, j]$。外積を $t$ について足したものと同じです。
- (4) $X'[t] = E'[\text{ids}[t]] + P'[t] = X[t] - \text{lr}\,\big(dE[\text{ids}[t]] + dP[t]\big)$。

</details>

## 検算

1. **勾配の保存**：$dE$ の全行の和 ＝ $dX$ の全行の和 ＝ $dP$ の全行の和（列ごとに）。足し込み先が変わるだけで、勾配の総量は変わりません。
2. **内積の一致**：$\langle W, dW\rangle = \langle X, dX\rangle = L$（$L$ は $W$ にも $X$ にも1次なので、D1 の内積の一致がさらに $L$ そのものになります）。
3. **手で数値微分**：
   - $E$[a, d1] を ±0.1 動かすと、$X$ の **t0 と t2 の両方**の d1 成分が動きます。$L$ を計算し直して中心差分を $dE$[a, d1] と比べます。
   - $W$[d0, d0] を ±0.1 動かすと、**3位置すべて**の $Y$ の d0 列が動きます。中心差分を $dW$[d0, d0] と比べ、位置ごとの寄与 $X[t, \text{d0}]\cdot G[t, \text{d0}]$ に分けてみます。

<details><summary>検算の値</summary>

- 列和：$dE$、$dX$、$dP$ とも (1.5, 0.75)
- $\langle W, dW\rangle = \langle X, dX\rangle = L = 0.5$
- $E$[a, d1] = 0.1 のとき：$X$ = t0 (1, 0.6)、t1 (0.5, 1)、t2 (0.5, 0.1)、$Y$ = t0 (1.3, 0.1)、t1 (1, 0.75)、t2 (0.55, −0.15)、$L(+h) = 0.675$。$-0.1$ のとき $L(-h) = 0.325$。
  中心差分 $(0.675 - 0.325)/0.2 = 1.75$ ＝ $dE$[a, d1] ＝ $dX$[t0, d1] + $dX$[t2, d1] ＝ 0.5 + 1.25
- $W$[d0, d0] = 1.1 / 0.9 のとき $L(+h) = 0.625$、$L(-h) = 0.375$。中心差分 1.25 ＝ $dW$[d0, d0]。位置ごとの寄与は (1, 0, 0.25)（t0, t1, t2）で、和が 1.25

$L$ は $E$ にも $W$ にも1次なので、中心差分はどの $h$ でも厳密に一致します。

</details>

## 答え

<details><summary>答えを開く</summary>

**(1)**

| | X d0 | X d1 | Y d0 | Y d1 |
|---|---:|---:|---:|---:|
| t0 (a) | 1 | 0.5 | 1.25 | 0 |
| t1 (b) | 0.5 | 1 | 1 | 0.75 |
| t2 (a) | 0.5 | 0 | 0.5 | −0.25 |

$L = 0.5$

**(2)** 位置ごとの外積（行 = d0, d1、列 = d0, d1）

| | t0：$x_{t0}^\top g_{t0}$ | t1：$x_{t1}^\top g_{t1}$ | t2：$x_{t2}^\top g_{t2}$ | 和 = dW |
|---|---|---|---|---|
| d0 行 | (1, 0) | (0, −0.5) | (0.25, 0.5) | (1.25, 0) |
| d1 行 | (0.5, 0) | (0, −1) | (0, 0) | (0.5, −1) |

$X^\top G$ も同じ (d0 行 (1.25, 0)、d1 行 (0.5, −1)) です。

**(3)**

| | dX = dP d0 | dX = dP d1 |
|---|---:|---:|
| t0 | 1 | 0.5 |
| t1 | 0.5 | −1 |
| t2 | 0 | 1.25 |

| dE | d0 | d1 | 内訳 |
|---|---:|---:|---|
| a | 1 | 1.75 | dX[t0] + dX[t2] |
| b | 0.5 | −1 | dX[t1] |
| c | 0 | 0 | 使われない |

**(0) 予想の答え**：c 行が0。a 行は $dP$ のどの行とも等しくなく、$dP$[t0] + $dP$[t2] です（b 行だけが $dP$[t1] と等しい）。

**(4)**

| | E' d0 | E' d1 | | P' d0 | P' d1 |
|---|---:|---:|---|---:|---:|
| a | 0 | −1.75 | t0 | −1 | 0 |
| b | −0.5 | 2 | t1 | 0 | 1 |
| c | 0.5 | 0.5 | t2 | −0.5 | −1.25 |

| | X' = E'[ids] + P' | 近道 X − 2dX | 一致？ |
|---|---|---|---|
| t0 (a) | (−1, −1.75) | (−1, −0.5) | × |
| t1 (b) | (−0.5, 3) | (−0.5, 3) | ○ |
| t2 (a) | (−0.5, −3) | (0.5, −2.5) | × |

正しい式は $X'[t] = X[t] - \text{lr}\,\big(dP[t] + dE[\text{ids}[t]]\big)$。近道 $X - 2\,\text{lr}\,dX$ は $dE[\text{ids}[t]] = dX[t]$、つまり**そのトークンが1回しか出ないとき**だけ正しく、a のように2回出るトークンの位置では、もう一方の位置の勾配も一緒に効いてきます。

**(説明)** Part 1 の入力 `<s> 猫 が` は3トークンが1回ずつ別の位置に出るので、$dE[\text{ids}[t]] = dX_0[t] = dP[t]$ となり、近道が使えました。`<s> 猫 猫` なら $dE[\text{猫}] = dX_0[t1] + dX_0[t2]$ になり、dE の猫行は dP のどの行とも一致せず、近道は t1, t2 で外れます（t0 だけ正しい）。
同じ理由で、**重み行列の勾配はいつも位置についての和**です：$W$ は3位置で共有されているので $dW = \sum_t x_t^\top dy_t$。1つの位置だけ見て $dW$ を作るのはよくある誤りです。

</details>
