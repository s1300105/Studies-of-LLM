# D8 LayerNorm：順伝播・逆伝播・2つの不変性（60分）

## 目標

- LayerNorm の逆伝播 $dx = \big(dy - \overline{dy} - y\,\overline{dy\odot y}\big)/\sigma$ を、$\partial\mu/\partial x$ → $\partial\sigma/\partial x$ → $\partial y/\partial x$ の順に導き、数字で使います（$\overline{\,\cdot\,}$ は4成分の平均）。
- 2つの不変量 $\sum_i dx_i = 0$、$dx\cdot y = 0$ を確かめ、それが「$\mathrm{LN}(x + c) = \mathrm{LN}(x)$」「$\mathrm{LN}(a x) = \mathrm{LN}(x)$（$a > 0$）」の裏返しであることを理解します。
- 入力のスケールが大きいほど勾配が小さくなる（$\div\sigma$）ことを見ます。

- **目安時間**：60分（(0) 予想 3分 / (1)(2) 順伝播 10分 / (3) 途中の微分 15分 / (4) 公式 10分 / (5)(6) 5分 / 検算 14分 / 説明 3分）
- **Part 1 で使う所**：2.2–2.3（LN1）、4.2（LN2）、6.3（LN2 の逆伝播）、6.8（LN1 の逆伝播）／ derivations.md 問8

## 問題

Part 1 と同じ LayerNorm（$\gamma = 1$、$\beta = 0$、$\varepsilon = 0$、分散は母分散 ÷4）を、4次元の1行に使います。

$$x = (4,\ -3,\ 1,\ 0),\qquad \mu = \tfrac14\sum_i x_i,\qquad \sigma^2 = \tfrac14\sum_i (x_i - \mu)^2,\qquad y = (x - \mu)/\sigma$$

上流からの勾配は $dy = (1,\ 0,\ -0.5,\ 0.5)$ とします（$L = dy\cdot y$ とすれば、ちょうど $\partial L/\partial y = dy$）。

**(0) 予想**：$\mathrm{LN}(2x + 3)$ と $\mathrm{LN}(x)$ の関係は？ $\mathrm{LN}(-x)$ は？

**(1)** $\mu$、$\sigma^2$、$\sigma$、$y$ を求め、$\mathrm{mean}(y) = 0$、$\mathrm{mean}(y^2) = 1$ を確かめてください。

**(2)** $x'' = 2x + 3$ について $\mu''$、$\sigma''$、$\mathrm{LN}(x'')$ を求めてください。$\mathrm{LN}(-x)$ も求めてください。

**(3) 途中の微分**（$x_0$ だけ）：

- (a) $\partial\mu/\partial x_0$
- (b) $\partial\sigma/\partial x_0$（$y_0$ で書ける）
- (c) $\partial y_j/\partial x_0$（$j = 0, 1, 2, 3$ の4成分）
- (d) $dx_0 = \sum_j dy_j\,\partial y_j/\partial x_0$

**(4) 公式**：$m_1 = \mathrm{mean}(dy)$、$m_2 = \mathrm{mean}(dy\odot y)$、$dx = (dy - m_1 - y\,m_2)/\sigma$ を計算し、$dx_0$ が (3)(d) と一致することを確かめてください。

**(5)** 入力が $x'' = 2x + 3$ だったとき（$dy$ は同じ）の $dx''$ を求め、$dx$ と比べてください。

**(6)** $dy = (1, 1, 1, 1)$、$dy = y$、$dy = 3 + 2y$ のとき、$dx$ はどうなりますか？（計算する前に予想してから）

**(説明)** $\sum_i dx_i = 0$ と $dx\cdot y = 0$ は、なぜどんな $dy$ でも必ず成り立つのですか？

## 手順のヒント

<details><summary>ヒントを開く</summary>

- (a) $\mu = \frac14\sum x_i$ なので $\partial\mu/\partial x_i = 1/4$。
- (b) $\partial\sigma^2/\partial x_i = \frac24\sum_j (x_j - \mu)(\delta_{ij} - \frac14) = \frac12(x_i - \mu)$（$\sum_j (x_j - \mu) = 0$ を使う）。$\partial\sigma/\partial x_i = \dfrac{\partial\sigma^2/\partial x_i}{2\sigma} = \dfrac{x_i - \mu}{4\sigma} = \dfrac{y_i}{4}$。
- (c) $y_j = (x_j - \mu)/\sigma$ を商の微分で：$\dfrac{\partial y_j}{\partial x_i} = \dfrac{1}{\sigma}\Big(\delta_{ij} - \dfrac14\Big) - \dfrac{x_j - \mu}{\sigma^2}\cdot\dfrac{y_i}{4} = \dfrac{1}{\sigma}\Big(\delta_{ij} - \dfrac14 - \dfrac{y_i y_j}{4}\Big)$。$i = 0$ を代入します。
- (4) $y$ が 1.4 や 0.2 なので、$dy\odot y$ も $y\,m_2$ も暗算に近い計算で済みます。最後に $\div\sigma$ を1回。
- (5) $y'' = y$、$\sigma'' = 2\sigma$。公式に入れると？
- (6) $dy - m_1 - y\,m_2$ は「$dy$ から、$(1,1,1,1)$ 方向と $y$ 方向の成分を取り除いたもの」です（この2つは直交していて、どちらも二乗和が4）。

</details>

## 検算

1. **必ずやる**：$\sum_i dx_i = 0$、$dx\cdot y = 0$。どちらかが0でなければ計算ミスです。
2. **手で数値微分**：$x_0 = 4$ を ±0.1 動かして $\mu$、$\sigma$、$y$、$L = dy\cdot y$ を計算し直し、中心差分を $dx_0$ と比べます。同じ表から $\partial\sigma/\partial x_0$ の中心差分も出して (3)(b) と比べます。（√ を使う15分ほどの計算です。6桁持ってください）

## 答え

<details><summary>答えを開く</summary>

**(1)** $\mu = 0.5$、$x - \mu = (3.5,\ -3.5,\ 0.5,\ -0.5)$、$(x - \mu)^2 = (12.25,\ 12.25,\ 0.25,\ 0.25)$、$\sigma^2 = 6.25$、$\sigma = 2.5$、$y = (1.4,\ -1.4,\ 0.2,\ -0.2)$。$\mathrm{mean}(y) = 0$、$\mathrm{mean}(y^2) = 1$。

**(2)** $x'' = (11,\ -3,\ 5,\ 3)$、$\mu'' = 4$、$\sigma'' = 5$、$\mathrm{LN}(x'') = (1.4,\ -1.4,\ 0.2,\ -0.2)$ ＝ $\mathrm{LN}(x)$。$\mathrm{LN}(-x) = (-1.4,\ 1.4,\ -0.2,\ 0.2) = -\mathrm{LN}(x)$。

**(0) 予想の答え**：$\mathrm{LN}(2x + 3) = \mathrm{LN}(x)$（足した3は $\mu$ に吸収され、掛けた2は $\sigma$ で割られて消える）。負の数を掛けると符号だけが反転します。

**(3)** (a) 0.25、(b) $y_0/4 = 0.35$、(c) $\partial y/\partial x_0 = (0.104,\ 0.096,\ -0.128,\ -0.072)$（4成分の和は0）、(d) $dx_0 = 0.132$。

**(4)** $m_1 = 0.25$、$dy\odot y = (1.4,\ 0,\ -0.1,\ -0.1)$、$m_2 = 0.3$

| | d0 | d1 | d2 | d3 |
|---|---:|---:|---:|---:|
| dy − m1 | 0.75 | −0.25 | −0.75 | 0.25 |
| y·m2 | 0.42 | −0.42 | 0.06 | −0.06 |
| dy − m1 − y·m2 | 0.33 | 0.17 | −0.81 | 0.31 |
| **dx** = (上)/σ | **0.132** | **0.068** | **−0.324** | **0.124** |

$dx_0 = 0.132$ は (3)(d) と一致。

**(5)** $dx'' = (0.066,\ 0.034,\ -0.162,\ 0.062) = dx/2$。出力は同じなのに、入力のスケールが2倍だと勾配は半分になります（$\sigma'' = 2\sigma$ で割るから）。Part 1 の 6.8 で、σ の小さい行ほど LN1 経由の勾配が大きくなるのはこのためです。

**(6)** 3つとも $dx = (0, 0, 0, 0)$。$(1,1,1,1)$ も $y$ も「LN が無視する方向」なので、その方向の勾配は入力に伝わりません。

**(説明)**

- **$\sum_i dx_i = 0$**：$x$ の全成分に同じ $c$ を足しても $y$ は変わらない（$\mu$ が $c$ だけずれるだけ）ので、$L$ も変わりません。$(1,1,1,1)$ 方向に動かしたときの $L$ の変化率 $\sum_i dx_i$ は0です。
- **$dx\cdot y = 0$**：$x \to x + \varepsilon(x - \mu)$ と「平均からのずれ」を $(1 + \varepsilon)$ 倍しても、$y$ は変わりません（$\sigma$ も $(1 + \varepsilon)$ 倍になる）。この方向の変化率 $dx\cdot(x - \mu) = \sigma\,(dx\cdot y)$ は0です。
- まとめると、LN の逆伝播は「$dy$ から $(1,1,1,1)$ 方向と $y$ 方向を取り除き（射影）、$\sigma$ で割る」操作です。Part 1 の U1 は全成分が ±1 なので、この射影が「同じ符号のペアの差 ÷ 2σ」というさらに簡単な形（ステップ6 の「ペアの規則」）になります。

**よくあるミス**：$\sigma^2$ で割る／$y$ の代わりに入力 $x$ を使う／$m_2$ を $\mathrm{mean}(dy)\cdot\mathrm{mean}(y)$ と取り違える（$\mathrm{mean}(y) = 0$ なので、それだと $m_2 = 0$ になってしまう）。

</details>
