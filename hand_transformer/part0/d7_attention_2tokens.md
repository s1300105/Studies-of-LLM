# D7 1ヘッド Attention を2トークンで（60分）

## 目標

- Attention の順伝播（スコア → softmax → 値の加重平均）と逆伝播（$dA \to dS \to dQ, dK$、そして $dV$）を、いちばん小さな大きさで一周します。
- 因果マスクのせいで **t0 のクエリには勾配が来ない**こと、**キーの勾配の和が0**になること、$dV$ が「そのキーを見たクエリ」についての和になることを、自分の数字で確かめます。
- D1（行列積）、D2（分岐）、D6（softmax のヤコビアン）が1つにつながることを体験します。

- **目安時間**：60分（(0) 予想 5分 / (1) 順伝播 15分 / (2) 逆伝播 25分 / 検算 12分 / 説明 3分）。任意の発展 +15分
- **Part 1 で使う所**：3.1–3.4（順伝播）、6.4–6.6（逆伝播）、6.7（dWq = U1ᵀ dQ で t0 行が寄与しない）／ derivations.md 問4・問5・問6

## 問題

2トークン（t0 = 先頭の `<s>` にあたる位置、t1）、$d_k = 2$ の1ヘッドです。$Q, K, V$ は与えます（Part 1 の 3.1 の出力にあたるもの）。

| Q | d0 | d1 |
|---|---:|---:|
| t0 | 0.5 | −1 |
| t1 | 1 | 1 |

| K | d0 | d1 |
|---|---:|---:|
| k0 | 1 | −1 |
| k1 | 0 | 1 |

| V | d0 | d1 |
|---|---:|---:|
| k0 | 1 | 0 |
| k1 | 0 | 2 |

$$S = QK^\top/\sqrt2\ \ (\text{マスク：}S[t0, k1] = -\infty),\qquad A = \mathrm{softmax}(S)\ (\text{行ごと}),\qquad O = AV$$

損失は $L = \sum_{t,j} G[t, j]\, O[t, j]$ とします（したがって $dO = G$）。

| G = dO | d0 | d1 |
|---|---:|---:|
| t0 | 2 | 0 |
| t1 | 1 | −1 |

**(0) 予想**：$dQ$ の t0 行はいくつでしょう？ $dK$ の2行を足すと？ $dV$ の列和は何と等しくなるでしょう？

**(1) 順伝播**：素点 $QK^\top$（マスクされない3マス）、$S$、$A$、$O$、$L$ を求めてください。$Q$ の t0 行は使いますか？

**(2) 逆伝播**：

- (a) $dA = dO\,V^\top$（マスク位置は0）
- (b) 行ごとの $r_t = \sum_j A[t, j]\, dA[t, j]$ と $dS = A \odot (dA - r)$
- (c) $dQ = dS\,K/\sqrt2$
- (d) $dK = dS^\top Q/\sqrt2$（**転置に注意**）
- (e) $dV = A^\top dO$

**(説明)** $Q[t0] = (0.5, -1)$ の値は $L$ に影響しますか？ 影響しないなら、なぜわざわざ値が書いてあるのでしょう？（→ 発展）

**発展（任意・15分）**：マスクを外して（t0 も k1 を見られる）$S$、$A$、$dA$、$dS$、$dQ$ を計算し、$dQ[t0]$ が0でなくなることを確かめてください。

## 手順のヒント

<details><summary>ヒントを開く</summary>

- 素点は厳密な値で出してから、最後に $1/\sqrt2 = 0.70711$ を1回だけ掛けます（Part 1 のルール2）。
- t0 行は要素1つなので $A[t0] = (1, 0)$、$O[t0] = V[k0]$。$S[t0, k0]$ は計算しなくて構いません。
- $A[t1]$ は2要素の softmax：$A[t1, k0] = 1/\big(1 + e^{S[t1,k1] - S[t1,k0]}\big)$。$e^{1/\sqrt2} = 2.028115$ です。
- この $G$ では $L = 3\cdot A[t1, k0]$ になります（$G[t0]\cdot O[t0] = 2$ は一定、$G[t1]\cdot O[t1] = A[t1,k0]\cdot1 + A[t1,k1]\cdot(-2) = 3A[t1,k0] - 2$）。数値微分が楽になります。
- (b) 2要素の行は D6 の公式で：$dS[t1,k0] = A[t1,k0]\,A[t1,k1]\,(dA[t1,k0] - dA[t1,k1])$、$dS[t1,k1] = -dS[t1,k0]$。
- (d) $dK[k_j] = \frac{1}{\sqrt2}\sum_i dS[i, j]\, Q[i]$：キー $j$ を見た**すべてのクエリ**からの和です。$dS[t0] = 0$ なので $Q[t0]$ は掛かりません。
- (e) $dV[k_j] = \sum_i A[i, j]\, dO[i]$：値 $j$ を使ったクエリたちの勾配を、使った重みで足したもの。

</details>

## 検算

1. $dS$ の各行の和 = 0。さらに $r_t = G[t]\cdot O[t]$（行 t の損失への寄与と同じ）。
2. $dQ[t0] = 0$、$dK$ の列和 = 0、$dV$ の列和 = $dO$ の列和。
3. **手で数値微分**：$Q$[t1, d0] = 1 を ±0.1 動かして $L$（$= 3A[t1, k0]$）を計算し直し、中心差分を $dQ$[t1, d0] と比べます。$Q$[t0, d0] を ±0.1 動かすと？（計算しなくても答えが分かるはず）
4. 全キーに同じベクトル $c = (0.1, 0.1)$ を足して $L$ を計算し直します。

<details><summary>検算の値</summary>

- $r = (2,\ -1.0093)$、$G[t]\cdot O[t] = (2,\ -1.0093)$
- $dK$ の列和 (0, 0)。$dV$ の列和 (3, −1) ＝ $dO$ の列和 (3, −1)

| Q[t1, d0] | 素点 t1 行 | S[t1,k1] − S[t1,k0] | e^差 | A[t1, k0] | O[t1] | L |
|---|---|---:|---:|---:|---|---:|
| 1（元） | (0, 1) | 0.7071 | 2.028115 | 0.330238 | (0.3302, 1.3395) | 0.990715 |
| 1.1 | (0.1, 1) | 0.636396 | 1.889658 | 0.346062 | (0.346062, 1.307877) | 1.038185 |
| 0.9 | (−0.1, 1) | 0.777817 | 2.176716 | 0.314790 | (0.314790, 1.370419) | 0.944371 |

中心差分 $(1.038185 - 0.944371)/0.2 = 0.469068$。解析解 $dQ$[t1, d0] = 0.4692（差 $-1.28\times10^{-4}$ は中心差分の誤差）。

- $Q$[t0, d0] を 0.6 / 0.4 にしても $L = 0.990715$ のまま → 中心差分0 ＝ $dQ$[t0, d0]。
- $K + c$ でも $L = 0.9907$ のまま。全キーに同じベクトルを足すと、t1 のスコアが両方とも $q_1\cdot c/\sqrt2$ だけずれるだけで softmax は変わりません。**これが「$dK$ の列和 = 0」の意味**です。

</details>

## 答え

<details><summary>答えを開く</summary>

**(1)** 素点：t0 行 (1.5, —)、t1 行 (0, 1)。$S$：t0 行 (1.0607, −∞)（使わない）、t1 行 (0, 0.7071)。

| | A k0 | A k1 | O d0 | O d1 |
|---|---:|---:|---:|---:|
| t0 | 1 | 0 | 1 | 0 |
| t1 | 0.3302 | 0.6698 | 0.3302 | 1.3395 |

$L = 0.9907$（$= 3\times0.330238$）。$Q$ の t0 行は**使いません**（t0 行の softmax は要素1つなので、$S[t0, k0]$ が何でも $A[t0] = (1, 0)$）。

**(2)**

| | dA k0 | dA k1 | r | dS k0 | dS k1 |
|---|---:|---:|---:|---:|---:|
| t0 | 2 | 0*（マスク） | 2 | 0 | 0 |
| t1 | 1 | −2 | −1.0093 | 0.6635 | −0.6635 |

2要素の公式：$0.3302\times0.6698\times(1 - (-2)) = 0.6635$。

| | dS K（÷√2 前） | dQ = dS K/√2 |
|---|---|---|
| t0 | (0, 0) | (0, 0) |
| t1 | (0.6635, −1.3271) | (0.4692, −0.9384) |

| | dSᵀ Q（÷√2 前） | dK = dSᵀ Q/√2 | dV = Aᵀ dO |
|---|---|---|---|
| k0 | (0.6635, 0.6635) | (0.4692, 0.4692) | (2.3302, −0.3302) |
| k1 | (−0.6635, −0.6635) | (−0.4692, −0.4692) | (0.6698, −0.6698) |

**(0) 予想の答え**：$dQ[t0] = (0, 0)$。$dK$ の2行の和は (0, 0)。$dV$ の列和は $dO$ の列和 (3, −1) と等しい（$A$ の各行の和が1なので、$\sum_j dV[k_j] = \sum_i (\sum_j A[i,j])\, dO[i] = \sum_i dO[i]$）。

ほかに読み取れること：

- $dK$ の2行はどちらも $q_1 = (1, 1)$ に比例しています。キーに勾配を送れるのは、softmax に要素が2つ以上ある t1 のクエリだけだからです。
- $dV[k1] = A[t1, k1]\cdot dO[t1]$ の1項だけ。k1 を見たのは t1 だけです（Part 1 の 6.6 で $dV$ の t2 行が1項だけになるのと同じ）。
- $dA[t0, k0] = 2$ と0ではないのに、$dS[t0] = 1\cdot(2 - 2) = 0$ になります。

**(説明)** 影響しません（数値微分でも0）。マスクがあるので t0 は k0 しか見られず、$A[t0] = (1, 0)$ が $Q[t0]$ によらず固定されるからです。値を書いておいたのは、「値があっても勾配は来ない」ことを確かめるためと、マスクを外した発展で使うためです。Part 1 で Q の t0 行を計算しないのも、6.7 の $dW_q = U_1^\top dQ$ で t0 行が寄与しないのも、同じ理由です。

**発展（マスクなし）**：

| | S | A | dA | dS | dQ |
|---|---|---|---|---|---|
| t0 | (1.0607, −0.7071) | (0.8542, 0.1458) | (2, 0) | (0.2491, −0.2491) | (0.1761, −0.3523) |
| t1 | (0, 0.7071) | (0.3302, 0.6698) | (1, −2) | (0.6635, −0.6635) | (0.4692, −0.9384) |

t0 も k1 を見られるようになると、t0 行の softmax は要素2つになり、$dQ[t0]$ が0でなくなります。t1 行は変わりません。**$dQ[t0] = 0$ は値のせいではなく、マスクのせい**です。マスクを外すと学習の損失は下がっても生成が壊れる様子は、発展課題 S1 で見られます。

</details>
