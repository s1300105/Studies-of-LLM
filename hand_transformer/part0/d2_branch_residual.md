# D2 分岐：同じ値を2か所で使ったら勾配を足す（40分）

## 目標

- 1つの値が2つ以上の経路で L に効くとき、その値の勾配は**各経路から来た勾配の和**になることを、数字で確かめます（多変数の連鎖律）。
- 残差接続 $y = x + f(x)$ では、上流の勾配 $dy$ が**何も掛けられずに**そのまま $x$ に届く（勾配の高速道路）ことを見ます。
- 「足し忘れ」がどんな値になるかを知り、数値微分でそれを見抜けるようにします。

- **目安時間**：40分（(0) ウォームアップ 5分 / A 残差 15分 / B 2本の枝 15分 / 説明 5分）。任意の (B5) +5分
- **Part 1 で使う所**：6.3（dX1 = dX2 + LN2経由）、6.7（dU1 の3項）、6.8（dX0 = dX1 + LN1経由）、6.6（キーと値は複数のクエリに使われる）／ derivations.md 問2

## 問題

**(0) ウォームアップ**：$u = 1.5$、$f = u\cdot u$ とします。2つのコピーに $a = u$、$b = u$ と名前を付けて $f = a\cdot b$ と見なし、$\partial f/\partial a$、$\partial f/\partial b$、$df/du$ を求めてください。$df/du = 2u$ になりますか？

### A 残差接続

$$x = (1,\ -1),\qquad t = (1,\ -0.5),\qquad h = xW,\qquad y = x + h,\qquad L = \tfrac12\lVert y - t\rVert^2$$

| W | d0 | d1 |
|---|---:|---:|
| d0 | 0.5 | 0.5 |
| d1 | 0 | 1 |

（$x = (1, -1)$ は、Part 1 の LN1 の出力 $U_1$ と同じく ±1 だけのベクトルです。）

**(A1)** $h$、$y$、$L$ を求めてください。

**(A2)** $dy$、$dh$、$dW = x^\top dh$ を求めてください。足し算 $y = x + h$ の逆伝播で $dh$ はどうなりますか？

**(A3)** $dx$ を「**残差経由**（$y = x + \cdots$ の $x$）」と「**W 経由**（$h = xW$ の $x$）」に分けて求め、足してください。

**(A4)** $y = x(I + W)$ と書けることを使い、$dx = dy\,(I + W)^\top$ を計算して (A3) と比べてください。

### B 2本の枝（Attention のスコアの形）

同じ $x = (1, -1)$ を、2つの重みで別々に変換してから内積を取ります。

$$q = xW_q,\qquad k = xW_k,\qquad L = s = q\cdot k = q\,k^\top$$

| Wq | d0 | d1 |
|---|---:|---:|
| d0 | 1 | 0 |
| d1 | 0.5 | 1 |

| Wk | d0 | d1 |
|---|---:|---:|
| d0 | 0.5 | 1 |
| d1 | 0 | −0.5 |

**(B1)** $q$、$k$、$s$ を求めてください。

**(B2)** $dq = \partial s/\partial q$、$dk = \partial s/\partial k$ を求めてください。

**(B3)** $dx$ を「q の枝」$dq\,W_q^\top$ と「k の枝」$dk\,W_k^\top$ の和として求めてください。

**(B4)** $M = W_q W_k^\top$ とおくと $s = x M x^\top$ です。$dx = x(M + M^\top)$ を計算して (B3) と比べてください。

**(B5)（任意）** $dW_q = x^\top dq$、$dW_k = x^\top dk$ を求めてください。

**(説明)** (a) Part 1 の U1 は Q, K, V の3か所で使われます。dU1 はどう書けますか？ (b) Part 1 の残差ストリーム $X_0 \to X_1 \to X_2$ で、出力側の勾配 dX2 はどこまで「そのまま」届きますか？

## 手順のヒント

<details><summary>ヒントを開く</summary>

- (0) $f = a\cdot b$ を $a$ で微分すると $b$、$b$ で微分すると $a$。$u$ は両方に入っているので $du = da + db$。
- 足し算 $y = x + h$：$\partial y/\partial x = I$、$\partial y/\partial h = I$ なので、$dh = dy$、残差経由の $dx = dy$（**コピー**）。
- W 経由の $dx$ は D1 と同じ $dh\,W^\top$。
- (B2) $s = q_0k_0 + q_1k_1$ なので $\partial s/\partial q_j = k_j$、$\partial s/\partial k_j = q_j$。
- (B3) それぞれの枝は D1 の $dx = dy\,W^\top$ と同じ形（$dy$ の代わりに $dq$ や $dk$）。
- (B4) $s = x M x^\top$ には $x$ が左と右に2回出てきます。右の $x$ から $xM$、左の $x$ から $xM^\top$ が出て、足すと $x(M + M^\top)$。

</details>

## 検算

1. **手で数値微分（A）**：$x$[d0] を ±0.1 動かして $L$ を計算し直し、中心差分を $dx$[d0] と比べます。$L$ は $x$ の2次式なので、中心差分は厳密に一致するはずです。
2. **同次性（B）**：$s$ は $x$ について2次の同次式（$x$ を $c$ 倍すると $s$ は $c^2$ 倍）なので $x\cdot dx = 2s$ が成り立ちます。
3. **手で数値微分（B）**：$x$[d0] を ±0.1 動かして $s$ を計算し直し、中心差分を $dx$[d0] と比べます。

<details><summary>検算の値</summary>

**A**

| x | h | y | L |
|---|---|---|---:|
| (1.1, −1) | (0.55, −0.45) | (1.65, −1.45) | 0.6625 |
| (0.9, −1) | (0.45, −0.55) | (1.35, −1.55) | 0.6125 |

中心差分 $(0.6625 - 0.6125)/0.2 = 0.25$ = $dx$[d0]。
残差経由を足し忘れると $dx$[d0] = −0.25、W 経由を足し忘れると 0.5 になり、どちらも数値微分の 0.25 と合わないのですぐ分かります。

**B**：$x\cdot dx = -2.5 = 2s$

| x | q | k | s |
|---|---|---|---:|
| (1.1, −1) | (0.6, −1) | (0.55, 1.6) | −1.27 |
| (0.9, −1) | (0.4, −1) | (0.45, 1.4) | −1.22 |

中心差分 $(-1.27 - (-1.22))/0.2 = -0.25$ = $dx$[d0]。

</details>

## 答え

<details><summary>答えを開く</summary>

**(0)** $f = 2.25$、$\partial f/\partial a = b = 1.5$、$\partial f/\partial b = a = 1.5$、$df/du = 1.5 + 1.5 = 3 = 2u$。「$u^2$ の微分が $2u$ になる」のは、$u$ が2か所で使われていて、2本の経路の勾配を足すからだ、と読めます。

**A**

- (A1) $h = (0.5,\ -0.5)$、$y = (1.5,\ -1.5)$、$L = 0.625$
- (A2) $dy = (0.5,\ -1)$、$dh = dy = (0.5,\ -1)$

  | dW = xᵀ dh | d0 | d1 |
  |---|---:|---:|
  | d0 | 0.5 | −1 |
  | d1 | −0.5 | 1 |

- (A3) 残差経由 $= dy = (0.5,\ -1)$、W 経由 $= dh\,W^\top = (-0.25,\ -1)$、合計 $dx = (0.25,\ -2)$
- (A4) $I + W$ は d0 行 (1.5, 0.5)、d1 行 (0, 2)。$dy\,(I + W)^\top = (0.25,\ -2)$ で一致。**残差接続は「重みに単位行列 $I$ を足すこと」**と同じです。$I$ の部分を通る勾配は何も掛けられません。

**B**

- (B1) $q = (0.5,\ -1)$、$k = (0.5,\ 1.5)$、$s = -1.25$
- (B2) $dq = k = (0.5,\ 1.5)$、$dk = q = (0.5,\ -1)$
- (B3) q の枝 $dq\,W_q^\top = (0.5,\ 1.75)$、k の枝 $dk\,W_k^\top = (-0.75,\ 0.5)$、合計 $dx = (-0.25,\ 2.25)$
- (B4) $M = W_qW_k^\top$ は d0 行 (0.5, 0)、d1 行 (1.25, −0.5)。$M + M^\top$ は d0 行 (1, 1.25)、d1 行 (1.25, −1)。$x(M + M^\top) = (-0.25,\ 2.25)$ で一致
- (B5)

  | dWq = xᵀ dq | d0 | d1 |
  |---|---:|---:|
  | d0 | 0.5 | 1.5 |
  | d1 | −0.5 | −1.5 |

  | dWk = xᵀ dk | d0 | d1 |
  |---|---:|---:|
  | d0 | 0.5 | −1 |
  | d1 | −0.5 | 1 |

  （$x = (1, -1)$ なので、どちらも d1 行 = −(d0 行)。Part 1 の 6.7 で dWq の d1 行が −(d0 行) になるのと同じ仕組みです。）

**(説明)**

- (a) $dU_1 = dQ\,W_q^\top + dK\,W_k^\top + dV\,W_v^\top$。3つの枝の和です（Part 1 の 6.7）。どれか1つを落とすのが典型的なミスです。
- (b) $X_2 = X_1 + F$、$X_1 = X_0 + \mathrm{Attn}$ なので、$dX_0 = dX_2 + (\text{LN2経由}) + (\text{LN1経由})$。$dX_2$ は**どの重みにも掛けられずに**埋め込み（dP, dE）まで届きます（Part 1 ステップ6 の「見どころ」1）。層を深くしても勾配が消えにくいのは、この経路のおかげです。

</details>
