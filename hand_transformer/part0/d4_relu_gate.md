# D4 ReLU の門と死んだユニット（35分）

## 目標

- ReLU の逆伝播 $dZ = dR \odot [Z > 0]$ を「門」として理解します。勾配は門の手前（$dR$）までは来ているのに、閉じた門で止まります。
- すべての位置で負になるユニット（**死んだユニット**）には、$W_1$ の列にも $W_2$ の行にも勾配が来ないこと、そのため**自分の力では生き返らない**ことを確かめます。
- ReLU の折れ目（$Z = 0$）をまたぐと数値微分が狂うことを見ます（Part 1 で $|Z|$ が0に近すぎない重みを選んだ理由）。

- **目安時間**：35分（(0) 予想 3分 / (1) 順伝播 6分 / (2) 逆伝播 12分 / 検算 9分 / (3) 更新 3分 / 説明 2分）
- **Part 1 で使う所**：4.3（ReLU と死んだユニット h3）、6.2（dZ、dW1 の h3 列と dW2 の h3 行が厳密に0）、7.1・7.3（h3 は更新後も死んだまま）／ derivations.md 問7-2

## 問題

2位置（t0, t1）、入力2次元、FFN のユニット3個（h0, h1, h2）、出力2次元です。

| X | d0 | d1 |
|---|---:|---:|
| t0 | 1 | 0.5 |
| t1 | −0.5 | 1 |

| W1 | h0 | h1 | h2 |
|---|---:|---:|---:|
| d0 | 1 | −1 | −1 |
| d1 | 1 | 1 | −1 |

| W2 | d0 | d1 |
|---|---:|---:|
| h0 | 1 | 0 |
| h1 | 0.5 | −1 |
| h2 | 1 | −0.5 |

| T | d0 | d1 |
|---|---:|---:|
| t0 | 1 | 0.5 |
| t1 | 1 | −1 |

$$Z = XW_1,\qquad R = \mathrm{ReLU}(Z),\qquad F = RW_2,\qquad L = \tfrac12\sum_{t,j}(F - T)[t, j]^2$$

**(0) 予想**：$Z$ を計算する前に、$W_1$ の h2 列 (−1, −1) を見てください。h2 は発火しそうですか？ 逆伝播で**厳密に0**になる成分はどれでしょう？

**(1) 順伝播**：$Z$、$R$、$F$、$L$ を求めてください。

**(2) 逆伝播**：$dF$、$dW_2 = R^\top dF$、$dR = dF\,W_2^\top$（**6マスすべて**）、$dZ = dR \odot [Z > 0]$、$dW_1 = X^\top dZ$、$dX = dZ\,W_1^\top$ を求めてください。

**(3) 更新**：lr = 1 で $W_1' = W_1 - dW_1$、$W_2' = W_2 - dW_2$ と更新し、同じ $X$ で $Z' = XW_1'$ を求めてください。h2 はどうなりましたか？

**(説明)** 死んだユニットが「自分の力では生き返らない」のはなぜですか？ どんなときなら生き返る可能性がありますか？

## 手順のヒント

<details><summary>ヒントを開く</summary>

- $\mathrm{ReLU}'(z) = 1$（$z > 0$）、$0$（$z < 0$）。$z = 0$ ちょうどのときは定義があいまいです（実装では0にすることが多い）。この問題では0ちょうどが出ないように数を選んであります。
- $Z$ の h2 列は $-(X[t, \text{d0}] + X[t, \text{d1}])$。
- $dR$ は「もし $R$ を直接少し動かせたら」の勾配で、死んだユニットでも0とは限りません。**門は順伝播の $Z$ の符号で決まります**（$dR$ の符号ではありません）。
- $dW_2 = R^\top dF$ の h 行は $\sum_t R[t, h]\, dF[t]$。$R$ の h 列が全部0なら、h 行は自動的に0。
- $dX$ の行和チェックサムには $W_1$ の列和 $\mathbf 1^\top W_1 = (2,\ 0,\ -2)$ を使います。

</details>

## 検算

1. **列和チェックサム**：$dX$ の各行の和 ＝ $dZ[t]\cdot(\mathbf 1^\top W_1)$。
2. **手で数値微分**（3つ）：
   - (a) **死んだユニットの重み** $W_1$[d0, h2] を ±0.1：$Z$ の h2 列はどうなりますか？ $L$ は変わりますか？
   - (b) **生きているユニットの重み** $W_1$[d0, h1] を ±0.1：中心差分を $dW_1$[d0, h1] と比べます。
   - (c) 同じ $W_1$[d0, h1] を **±0.6** 動かすと？

<details><summary>検算の値</summary>

- $dX$ の行和 (1, 0.5) ＝ $dZ[t]\cdot(2, 0, -2)$ の (1, 0.5)

| | 動かした値（+h / −h） | Z の動いた列（+h / −h） | L(+h) | L(−h) | 中心差分 | 解析解 |
|---|---|---|---:|---:|---:|---:|
| (a) W1[d0, h2] | −0.9 / −1.1 | h2：(−1.4, −0.55) / (−1.6, −0.45) | 0.40625 | 0.40625 | 0 | 0 |
| (b) W1[d0, h1] | −0.9 / −1.1 | h1：(−0.4, 1.45) / (−0.6, 1.55) | 0.3765625 | 0.4390625 | −0.3125 | −0.3125 |
| (c) W1[d0, h1] | −0.4 / −1.6 | h1：(0.1, 1.2) / (−1.1, 1.8) | 0.35625 | 0.65 | −0.244792 | −0.3125 |

- (a) h2 は ±0.1 動かしても負のままなので、$L$ は1桁も変わりません。勾配0は「本当に効かない」ことを意味します。
- (b) t0 の h1 は負のまま、t1 だけが動きます（$F$[t1] = (1.225, −1.45) / (1.275, −1.55)）。折れ目をまたがない範囲では $L$ は2次式なので、中心差分は厳密に一致します。
- (c) +h 側で t0 の h1 が $-0.5 \to 0.1$ と**折れ目をまたいで発火**し、中心差分 −0.244792 は解析解 −0.3125 からずれます。数値微分は「折れ目をまたがない小さな h」でしか使えません。Part 1 で ReLU の入力 $Z$ が0に近すぎない重みを選んだのは、このずれ（と $\mathrm{ReLU}'(0)$ のあいまいさ）を避けるためです。

</details>

## 答え

<details><summary>答えを開く</summary>

**(1)**

| | Z h0 | Z h1 | Z h2 | R h0 | R h1 | R h2 | F d0 | F d1 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| t0 | 1.5 | −0.5 | −1.5 | 1.5 | 0 | 0 | 1.5 | 0 |
| t1 | 0.5 | 1.5 | −0.5 | 0.5 | 1.5 | 0 | 1.25 | −1.5 |

$L = 0.40625$

**(2)**

| | dF d0 | dF d1 | dR h0 | dR h1 | dR h2 | 門 [Z>0] | dZ h0 | dZ h1 | dZ h2 |
|---|---:|---:|---:|---:|---:|---|---:|---:|---:|
| t0 | 0.5 | −0.5 | 0.5 | 0.75 | 0.75 | (1, 0, 0) | 0.5 | 0 | 0 |
| t1 | 0.25 | −0.5 | 0.25 | 0.625 | 0.5 | (1, 1, 0) | 0.25 | 0.625 | 0 |

| dW2 = Rᵀ dF | d0 | d1 |
|---|---:|---:|
| h0 | 0.875 | −1 |
| h1 | 0.375 | −0.75 |
| h2 | 0 | 0 |

| dW1 = Xᵀ dZ | h0 | h1 | h2 |
|---|---:|---:|---:|
| d0 | 0.375 | −0.3125 | 0 |
| d1 | 0.5 | 0.625 | 0 |

$dX$ = t0 (0.5, 0.5)、t1 (−0.375, 0.875)

**(0) 予想の答え**：$X$ の各行の和が正（1.5 と 0.5）なので、h2 は2位置とも負＝死んでいます。厳密に0になるのは、$dZ$ の h2 列と (t0, h1)、$dW_1$ の h2 列、$dW_2$ の h2 行です。$dR$ の h2 列 (0.75, 0.5) は0ではなく、**勾配は門の手前までは来ている**のに、門で止められます。$W_2$ の h2 行 (1, −0.5) も0ではないのに、勾配は0です。

**(3)**

| W1' | h0 | h1 | h2 |
|---|---:|---:|---:|
| d0 | 0.625 | −0.6875 | −1 |
| d1 | 0.5 | 0.375 | −1 |

| W2' | d0 | d1 |
|---|---:|---:|
| h0 | 0.125 | 1 |
| h1 | 0.125 | −0.25 |
| h2 | 1 | −0.5 |

$Z'$ = t0 (0.875, −0.5, −1.5)、t1 (0.1875, 0.71875, −0.5)。$W_1$ の h2 列も $W_2$ の h2 行も変わらず、$Z'$ の h2 列は元と同じ (−1.5, −0.5) で、**まだ死んでいます**。

寄り道：このときの損失は $L' = 1.3679$ で、**更新前の 0.40625 より上がっています**。lr = 0.5 なら 0.2798、lr = 0.25 なら 0.0256 と下がります（どの lr でも h2 は死んだまま）。lr = 1 が大きすぎる理由は D9 で見ます。

**(説明)** 勾配が0なので、h2 に入る重み（$W_1$ の h2 列）は更新されません。同じ入力 $X$ に対して $Z$ の h2 列は前と同じ負の値になり、次のステップでも勾配は0——これがずっと続きます。生き返る可能性があるのは、**入力 $X$ のほうが変わったとき**です（下の層や埋め込みが更新されて、ある位置で $Z$ の h2 成分が正になる場合）。Part 1 では h3 が同じように死んでいて、1回の更新後も負のままです（7.3）。GELU のように負の側にも小さな傾きがある活性化関数では、この問題は起きにくくなります。

</details>
