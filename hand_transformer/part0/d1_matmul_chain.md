# D1 行列積の連鎖律と形（45分）

## 目標

- $y = xW$ の逆伝播 $dW = x^\top dy$、$dx = dy\,W^\top$ を、**成分の連鎖律から自分で導き**、数字で使えるようにします。
- 「形（行×列）を合わせる」だけで、転置をどこに付けるかが一通りに決まることを確かめます。
- 勾配の意味＝「その成分を少し動かしたら L がどれだけ変わるか」を、**手で数値微分して**確かめます。前進差分と中心差分の違いも見ます。

- **目安時間**：45分（(0) 予想 3分 / (1) 順伝播 5分 / (2) 成分の連鎖律 12分 / (3)(4) 行列の式と形 10分 / 検算 12分 / 説明 3分）。任意の発展 +10分
- **Part 1 で使う所**：6.1・6.2・6.4・6.7 のすべての $dW$ と $dX$、7.4 の5（数値微分）、ステップ1 の 1-4（行和・列和）／ derivations.md 問1

## 問題

行ベクトル $x$（1×2）、重み $W$（2×2）、目標 $t$（1×2）を使います。

$$x = (1,\ 0.5),\qquad t = (0.5,\ 0)$$

| W | d0 | d1 |
|---|---:|---:|
| d0 | 0.5 | −1 |
| d1 | 1 | 0.5 |

$$y = xW,\qquad L = \tfrac12\lVert y - t\rVert^2 = \tfrac12\sum_j (y_j - t_j)^2$$

**(0) 予想**（計算する前に）：$dW$ の4成分のうち、絶対値が一番大きいのはどれでしょう？ $dW$ の d1 行は d0 行の何倍になるでしょう？
（ヒント：$W[k, j]$ が効くのは $y_j$ だけで、効き方は $x_k$ 倍）

**(1) 順伝播**：$y$ と $L$ を求めてください。

**(2) 成分の連鎖律**：$y$ を成分で書くと

$$y_0 = x_0 W_{00} + x_1 W_{10},\qquad y_1 = x_0 W_{01} + x_1 W_{11}$$

です（添字は0始まり。$W_{kj}$ = W[dk, dj]）。$\partial L/\partial y_j$（2個）、$\partial L/\partial W_{kj}$（4個）、$\partial L/\partial x_k$（2個）を連鎖律で求めてください。

**(3) 行列の式**：(2) の結果が $dW = x^\top dy$（(2×1)(1×2) の外積）、$dx = dy\,W^\top$ と一致することを確かめてください。

**(4) 形の表**：Part 1 の行列積 $Y = XW$ について、空欄を埋めてください（$dW$ は $W$ と、$dX$ は $X$ と同じ形）。

| Part 1 の式 | X の形 | W の形 | dW = ? の掛け算の形 | dX = ? の掛け算の形 |
|---|---|---|---|---|
| logits = X2·Wout（6.1） | 3×4 | 4×5 | | |
| Z = U2·W1（6.2） | 3×4 | 4×8 | | |
| F = R·W2（6.2） | 3×8 | 8×4 | | |
| Attn = Ocat·Wo（6.4） | 3×4 | 4×4 | | |
| Q = U1·Wq（6.7） | 3×4 | 4×4 | | |

**(説明)** 「$dW$ の各行は $dy$ に比例する」のはなぜか、1〜2文で説明してください。

**発展（任意・10分）**：学習率 lr = 1 で $W$ だけを1回更新し（$W' = W - dW$）、$y' = xW'$ を求めてください。$y' - t$ は $y - t$ の何倍ですか？ 損失は下がりましたか？ $y'$ がちょうど $t$ に届く lr はいくつですか？

## 手順のヒント

<details><summary>ヒントを開く</summary>

- $\partial L/\partial y_j = y_j - t_j$（$\tfrac12$ と2乗の2が打ち消し合う）。これが $dy$ です。
- $W_{kj}$ が出てくるのは $y_j$ の式だけで、係数は $x_k$ です。したがって $\partial L/\partial W_{kj} = \dfrac{\partial L}{\partial y_j}\cdot x_k$。
- $x_k$ は $y_0$ と $y_1$ の**両方**に出てきます（係数は $W_{k0}$ と $W_{k1}$）。したがって $\partial L/\partial x_k = \sum_j \dfrac{\partial L}{\partial y_j} W_{kj}$ ＝ **2つの経路の和**です（D2 の分岐と同じ考え方）。
- 行列にまとめると、$dW$ の (k, j) 成分が $x_k\, dy_j$ → $x^\top dy$。$dx_k$ は「$W$ の k 行と $dy$ の内積」→ $dy\,W^\top$。
- 形の覚え方：$dW$ は $W$ と同じ形、$dX$ は $X$ と同じ形。内側の次元が消えるように並べると、掛け方は一通りしかありません。
- 発展：$y' = x(W - x^\top dy) = y - (x x^\top)\,dy = y - \lVert x\rVert^2 dy$ です。

</details>

## 検算

答えを開く前に、自分の値で次を確かめます。

1. **行和チェックサム**（Part 1 ステップ1 の 1-4）：$\sum_j y_j = x\cdot(W\mathbf 1)$。逆向きは列和で $\sum_k dx_k = dy\cdot(\mathbf 1^\top W)$。
2. **内積の一致**：$x\cdot dx = y\cdot dy = \langle W, dW\rangle$（$\langle W, dW\rangle = \sum_{k,j} W_{kj}\, dW_{kj}$）。
   理由：$y\cdot dy = \sum_j\sum_k x_k W_{kj}\, dy_j$ を「$k$ でまとめる」と $x\cdot dx$、「$(k, j)$ ごとに見る」と $\langle W, dW\rangle$ になります（$y$ が $x$ にも $W$ にも1次だから）。
3. **手で数値微分**：$W$[d0, d1] を ±0.1 動かして $L(+h)$, $L(-h)$ を計算し、中心差分 $\big(L(+h) - L(-h)\big)/(2h)$ を $dW$[d0, d1] と比べます。前進差分 $\big(L(+h) - L\big)/h$ も計算してください。同じことを $x$[d1] でもやります。

<details><summary>検算の値</summary>

- $W\mathbf 1 = (-0.5,\ 1.5)$、$\sum y = 0.25 = 1\times(-0.5) + 0.5\times1.5$
- $\mathbf 1^\top W = (1.5,\ -0.5)$、$\sum dx = 1.125 = 0.5\times1.5 + (-0.75)\times(-0.5)$
- $x\cdot dx = y\cdot dy = \langle W, dW\rangle = 1.0625$
- $dW$ の総和 $= -0.375 = (\sum x)(\sum dy)$（外積の総和は、それぞれの和の積）

| 動かす成分 | +h のときの y | −h のときの y | L(+h) | L(−h) | 中心差分 | 前進差分 | 解析解 |
|---|---|---|---:|---:|---:|---:|---:|
| W[d0, d1] = −1 → −0.9 / −1.1 | (1, −0.65) | (1, −0.85) | 0.33625 | 0.48625 | −0.75 | −0.7 | −0.75 |
| x[d1] = 0.5 → 0.6 / 0.4 | (1.1, −0.7) | (0.9, −0.8) | 0.425 | 0.4 | 0.125 | — | 0.125 |

中心差分は解析解と**ぴったり**一致します。$L$ は $W$ についても $x$ についても2次式なので、中心差分の誤差（$h^2$ に比例し、3階微分から来る）がちょうど0になるからです。
前進差分 −0.7 は 0.05 ずれます。これは $\tfrac12 h\cdot x_0^2 = 0.05$（2階微分 $x_0^2$ から来る誤差）で、$h$ に比例します。**手で数値微分するときは中心差分を使う**のが原則です。

</details>

## 答え

<details><summary>答えを開く</summary>

**(1)** $y = (1,\ -0.75)$、$L = 0.40625$

**(2)(3)** $dy = y - t = (0.5,\ -0.75)$

| dW = xᵀ dy | d0 | d1 |
|---|---:|---:|
| d0 | 0.5 | −0.75 |
| d1 | 0.25 | −0.375 |

$dx = dy\,W^\top = (1,\ 0.125)$

- $dx$[d0] $= 0.5\cdot0.5 + (-0.75)\cdot(-1) = 0.25 + 0.75 = 1$
- $dx$[d1] $= 0.5\cdot1 + (-0.75)\cdot0.5 = 0.5 - 0.375 = 0.125$

**(0) 予想の答え**：最大は $dW$[d0, d1] = −0.75。d1 行は d0 行の 0.5 倍（$= x_1/x_0$）です。

**(4)**

| Part 1 の式 | dW = Xᵀ dY | dX = dY Wᵀ |
|---|---|---|
| logits = X2·Wout | (4×3)(3×5) = 4×5 | (3×5)(5×4) = 3×4 |
| Z = U2·W1 | (4×3)(3×8) = 4×8 | (3×8)(8×4) = 3×4 |
| F = R·W2 | (8×3)(3×4) = 8×4 | (3×4)(4×8) = 3×8 |
| Attn = Ocat·Wo | (4×3)(3×4) = 4×4 | (3×4)(4×4) = 3×4 |
| Q = U1·Wq | (4×3)(3×4) = 4×4 | (3×4)(4×4) = 3×4 |

**(説明)** $W$ の k 行は「入力の成分 $x_k$ が、出力の各成分にどれだけ混ざるか」です。どの出力成分にも $x_k$ は同じ $x_k$ 倍で効くので、k 行の勾配は出力の誤差 $dy$ を $x_k$ 倍したもの（$dW[k, :] = x_k\, dy$）になります。だから $dW$ は外積（階数1の行列）です。位置が3つあると、3つの外積の和になります（D3）。

**発展**：

| W' = W − dW | d0 | d1 |
|---|---:|---:|
| d0 | 0 | −0.25 |
| d1 | 0.75 | 0.875 |

$y' = (0.375,\ 0.1875)$。$\lVert x\rVert^2 = 1.25$ で、$y' - y = (-0.625,\ 0.9375) = -\lVert x\rVert^2\, dy$。
$y' - t = (-0.125,\ 0.1875) = -0.25\,(y - t)$（$1 - \text{lr}\lVert x\rVert^2 = -0.25$）。
$L' = 0.025390625$（$= (-0.25)^2 \times L = 0.0625 \times 0.40625$）。損失は下がりましたが、$y$ は $t$ を**通り越して**反対側に出ています（符号が反転）。ちょうど $t$ に届くのは lr $= 1/\lVert x\rVert^2 = 0.8$ のときです。lr が「曲がり具合」$\lVert x\rVert^2$ に比べて大きすぎると行き過ぎる——これは D9 で詳しく見ます。

**よくあるミス**：$dW = dy^\top x$（2×2 になるが転置している）。形が正方行列だと形のチェックでは見つからないので、成分 $dW[k, j] = x_k\, dy_j$ に戻って確かめます。

</details>
