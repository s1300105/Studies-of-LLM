# Part 0 部品ドリル — 本編の前に、部品を1つずつ手で回す

本編（Part 1、[../README.md](../README.md)、20時間）では、1層の Transformer の学習1ステップを通しで手計算します。
Part 0 は、そこで使う**部品（行列積・分岐・埋め込み・ReLU・softmax・Attention・LayerNorm・SGD）を1つずつ取り出し**、2〜4成分の小さな数で「導く → 使う → 自分で確かめる」を一度ずつ済ませておくための、9本の短いドリルです。

> **はじめ方（5分）**
> 1. 用意するもの：関数電卓（exp・ln・√ があるもの）と計算用紙。Part 1 と同じです
> 2. この README の §2（順番と時間）と §3（進め方のルール）を読む
> 3. [d1_matmul_chain.md](d1_matmul_chain.md) から始める。答え合わせはドリルの「答え」を開くか、`hand_transformer/part0/` で `python3 check_drills.py --only D1`（NumPy が必要）

## 1. 目的

Part 1 の逆伝播（ステップ6、8時間）と更新（ステップ7）で使う微分は、次の9種類にまとめられます（ヘッドの分割・連結や 1/√2 倍のような「コピーと定数倍」を除く）。

| 部品 | 式 | ドリル |
|---|---|---|
| 行列積 | $dW = X^\top dY$、$dX = dY\,W^\top$ | D1 |
| 分岐・残差 | 同じ値を2か所で使ったら勾配を足す | D2 |
| 表引き・重み共有 | 使われた行に足し込む、位置ごとの外積の和 | D3 |
| ReLU | $dZ = dR \odot [Z > 0]$ | D4 |
| softmax + 交差エントロピー | $dz = (p - y)/N$ | D5 |
| softmax | $ds = a \odot (da - \textstyle\sum_i a_i da_i)$ | D6 |
| Attention | $dA = dO\,V^\top$、$dQ = dS\,K/\sqrt{d_k}$、$dK = dS^\top Q/\sqrt{d_k}$、$dV = A^\top dO$ | D7 |
| LayerNorm | $dx = (dy - \overline{dy} - y\,\overline{dy\odot y})/\sigma$ | D8 |
| SGD と1次予測 | $\theta' = \theta - \eta g$、$\Delta L \approx -\eta\lVert g\rVert^2$ | D9 |

Part 1 で手が止まる原因はたいてい、(a) 式を導けない、(b) 大きな表の途中で間違え、どこが違うのか分からない、(c) 検算のやり方を知らない、のどれかです。
Part 0 では数が小さいので、この3つを部品ごとに先に片づけられます。

- **勾配を毎回、自分で数値微分して確かめます**。Part 1 では1成分の数値微分に30分かかります（7.4 の5、発展課題 M2）が、ここでは5〜15分です。「勾配＝少し動かしたら L がどれだけ変わるか」を、9回、自分の手で確かめることが一番の狙いです。
- **各ドリルに「(0) 予想」と「(説明)」があります**。式を書けることと、なぜそうなるかを言えることは別の力です。Part 1 の各ステップの「計算する前に予想しよう」で効くのは後者です。時間をかけてでも、説明は文章で書いてください。
- Part 1 の [derivations.md](../workbook/derivations.md)（記号で導くノート）と対になる、**数字で確かめる版**です。derivations.md は Part 1 のステップ6 の最初に解きます（通常 2.5h。Part 0 を終えていれば §4 末尾のとおり 1.0h）。Part 0 を終えていれば、各問に自分で計算した数値例があるので、導いた式をすぐに確かめられます。

## 3. 進め方のルール

Part 1 の [§7 進め方のルール](../README.md#7-進め方のルール) と同じ考え方に、Part 0 用の決まりを足したものです。

1. **(0) 予想 → 問題 → 検算 → 答え の順**に進めます。予想は外れてかまいません。外れた予想と結果のずれが一番の学びになります。
2. **答えを開く前に検算します**（Part 1 §7 の3）。各ドリルの「検算」の節は、答えより**前**に置いてあります。検算の値は、自分で検算を終えてから開いてください。
3. **ヒントは、手が5分止まったら開きます**。目安時間の1.5倍を超えたら答えを見て先へ進み、つまずいた理由をメモします。
4. **記録は有効数字4桁、途中で丸めない**（Part 1 §7 の1）。Part 0 の入力は 0.5 刻みなので、多くの値は割り切れます（0.375、−0.3125 など。そのまま全桁書きます）。**手で数値微分するときだけは6桁**持ってください。$L(+h) - L(-h)$ の引き算で上の桁が消えるからです。
5. **許容差**は Part 1 と同じ $|\text{自分} - \text{解答}| \le 0.002 + 0.002\cdot|\text{解答}|$ です。
6. **ミスを種類ごとに記録します**（転置、符号、分岐での足し忘れ、÷N の忘れ、1/√2 の忘れ、σ と σ² の取り違え）。この記録はそのまま Part 1 の誤差ログ（ステップ1 の 1-5）に引き継ぎます。

**記号**は Part 1 の [§3 記号と形状](../README.md#3-記号と形状) と同じです。

- 行ベクトル規約（各位置のベクトルは行。$y = xW$ の形で掛ける）
- $dX := \partial L/\partial X$（$X$ と同じ形）
- 添字はすべて0始まり：位置 t0, t1, …、次元 d0, d1, …、キー k0, k1、FFN ユニット h0, h1, …、クラス c0, c1, …
- Part 0 では損失を簡単な形にすることがあります。$L = \tfrac12\lVert y - t\rVert^2$ なら $dy = y - t$、$L = \sum G\odot Y$ なら $dY = G$（上流から来た勾配を直接与えるのと同じ）です。

## 5. 修了チェック（10分）

何も見ずに紙に書きます。書けなかった式のドリルだけ、「答え」を読み直してください。

1. $Y = XW$（$X$ は n×k、$W$ は k×m）の $dW$ と $dX$。それぞれの形
2. $y = x + f(x)$ の $dx$
3. $X = E[\text{ids}] + P$ の $dE$ と $dP$。同じトークンが2回出たら？
4. $R = \mathrm{ReLU}(Z)$ の $dZ$
5. N 位置の平均の交差エントロピー $L = \frac1N\sum_t -\log \mathrm{softmax}(z_t)[y_t]$ の $dz$
6. $a = \mathrm{softmax}(s)$ の $ds$（$da$ から）
7. $S = QK^\top/\sqrt{d_k}$（マスク付き）、$A = \mathrm{softmax}(S)$、$O = AV$ の $dQ$、$dK$、$dV$
8. $y = \mathrm{LN}(x)$ の $dx$
9. $\theta' = \theta - \eta g$ のときの $\Delta L$ の1次近似

さらに、1〜9 それぞれについて**検算に使える性質を1つずつ**書いてください。

<details><summary>答え</summary>

| | 式 | 検算に使える性質（例） | ドリル |
|---|---|---|---|
| 1 | $dW = X^\top dY$（k×m）、$dX = dY\,W^\top$（n×k） | 列和チェックサム $\sum_k dX[t,k] = dY[t]\cdot(\mathbf 1^\top W)$。$x\cdot dx = y\cdot dy = \langle W, dW\rangle$ | D1 |
| 2 | $dx = dy + (f \text{ 経由の勾配})$ | 足し忘れると数値微分と合わない | D2 |
| 3 | $dP = dX$、$dE[v] = \sum_{t:\,\text{ids}[t]=v} dX[t]$（2回出たら2回足す） | $dE$ の全行の和 = $dX$ の全行の和。使われない行は0 | D3 |
| 4 | $dZ = dR\odot[Z > 0]$（門は順伝播の Z で決まる） | 死んだユニットの $dW_1$ の列と $dW_2$ の行は厳密に0 | D4 |

| 8 | $dx = (dy - \overline{dy} - y\,\overline{dy\odot y})/\sigma$ | $\sum_i dx_i = 0$、$dx\cdot y = 0$ | D8 |
| 9 | $\Delta L \approx -\eta\lVert g\rVert^2$ | 予測は必ず負。2次関数なら実際 = 予測 + $\tfrac12\eta^2 g^\top Hg$ | D9 |

## 6. 正解スクリプト check_drills.py

ドリルに出てくる数値は、すべて [check_drills.py](check_drills.py) の出力です（NumPy が必要）。

```bash
python3 check_drills.py              # D1〜D9 の答え・検算・数値微分をすべて表示
python3 check_drills.py --only D7    # 1つのドリルだけ
python3 check_drills.py --quiet      # 検査の合否だけ
```

各ドリルについて、スクリプトは次のことをします。

1. 答え（順伝播・逆伝播の値）を、ドリルと同じ名前・同じ順で表示する
2. 不変量（行和0、内積の一致、LN の2つの不変量など）を確かめる
3. **勾配の答えすべて**を、中心差分（h = 10⁻⁶）の数値微分と照合する
4. 手でやる数値微分（h = 0.1 など）の途中の値（L(+h)、L(−h)、中心差分）を表示する

検査は全部で112件で、すべて通れば最後に `ALL CHECKS PASSED` と表示され、終了コード0で終わります。

**もっと時間をかけたい人へ**：スクリプトの入力（各関数の先頭にある `x`、`W` など）を自分で選んだ数に書き換えれば、同じ手順で自分の問題を作って照合できます。勾配の照合（3.）は数によらず成り立ちますが、「h2 は死んでいる」「近道は t1 でだけ正しい」のように、その数のために作った検査は外れることがあります。
