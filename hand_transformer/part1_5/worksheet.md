モデルとパラメータは [README.md の §2](README.md#2-モデルとパラメータ)、ルールは [§3](README.md#3-進め方のルール) です。

**各チェックポイントの進め方**：空欄を埋める → 「検算」で自分の数字を確かめる → 「答え」を開いて照合する。
「ヒント」は、自分で組み立てようとして**5分**止まったときだけ開き、開いたことを [6 想起の記録](#6-想起の記録5分セクション5のあと) に書きます。

記入欄の「0*」は因果マスクで0と決まる値、「−∞」はマスクされたスコア、「—」は計算しなくてよいセル（t0 は自分しか見ないので、Q の t0 行、S と dA の (t0, k0)、r の t0 は結果に効きません）です。
答えの表の「0」は厳密に0、「0.0000」は丸めると0になるだけの値です。数値はすべて `python3 part1_5/retrieval.py` の出力です。

## 0 白紙に地図（5分）

§2 の仕様だけを見て、白紙に次を書きます。

1. 順伝播の式を、入力から損失 L まで上から順に。各式に形を添える（例：`U 2×3`）
2. 1つの値が2か所以上で使われる所（**分岐点**）に ●。逆伝播で各経路の勾配を足す所です
3. 逆伝播でもう一度使う値に ★
4. 因果マスクのおかげで計算しなくてよいもの

<details><summary>答え</summary>

```
X0 = E[ids] + P                         2×3   ● LN と残差の2か所
μ, σ²（行ごと、÷3）, σ                    2×1   ★ σ
U = (X0 − μ) / σ                        2×3   ● Q・K・V の3か所  ★
Q = U Wq,  K = U Wk,  V = U Wv          各2×3 ★（Q は t1 行だけ）
S = Q Kᵀ / √3（マスク：S[t0, k1] = −∞）   2×2
A = softmax(S)（行ごと）                  2×2   ★
O = A V                                 2×3
X1 = X0 + O                             2×3   ★（dWout で使う）
logits = X1 Wout                        2×3
p = softmax(logits)                     2×3   ★
L = ½ Σ_t ( logsumexp(logits[t]) − logits[t, y_t] )
```

- **分岐点は X0 と U の2つ**です。Part 1 には X1 もありましたが（FFN の枝）、この例は FFN が無いので X1 は logits にしか行きません。
- **目に見えない分岐**：重みは2つの位置で共有されている（dW は2位置分の和）。t0 のキーと値は、t0 と t1 の両方のクエリが使う（dK・dV はクエリ方向の和）。
- **マスクで不要になるもの**：A の t0 行は必ず [1, 0] なので、Q の t0 行と S[t0, k0] は計算しなくてよい（逆伝播でも dQ の t0 行は0）。
- このほか、**更新前の**重み Wq・Wk・Wv・Wout も、逆伝播の dX = dY Wᵀ でもう一度使います（★）。
</details>

### A4 スコアと Attention 重み

**S**

| | k0 | k1 |
|---|---:|---:|
| t0 &lt;s&gt; | — | −∞ |
| t1 雨 |   |   |

**A**

| | k0 | k1 |
|---|---:|---:|
| t0 &lt;s&gt; |   | 0* |
| t1 雨 |   |   |


<details><summary>ヒント</summary>

S[t1, j] = Q[t1]·K[j] / √3。Q も K も √(3/2) 倍の形なので、√(3/2)·√(3/2)/√3 = √3/2 = 0.8660 を「0.5刻みどうしの内積」に掛けるだけです。
t1 行は2要素の softmax：A[t1, k0] = 1 / (1 + e^{S[t1,k1] − S[t1,k0]})。
</details>

<details><summary>答え</summary>

**S**

| | k0 | k1 |
|---|---:|---:|
| t0 &lt;s&gt; | 2.1651 | −∞ |
| t1 雨 | −0.8660 | 0 |

**A**

| | k0 | k1 |
|---|---:|---:|
| t0 &lt;s&gt; | 1.0000 | 0 |
| t1 雨 | 0.2961 | 0.7039 |

- Q[t1]/√(3/2) = (0.5, 1, 0) と K/√(3/2) の内積は、k0 と −1、k1 と 0。したがって S[t1] = (−0.8660, 0)、e^{0.8660} = 2.3774、A[t1, k0] = 1/3.3774 = 0.2961。
- **S[t1, k1] は厳密に0**です。理由：$S[t1, j] = U[j]\cdot(W_k\,Q[t1]^\top)/\sqrt3$ と書き直すと、$W_k\,Q[t1]^\top = \sqrt{3/2}\,(0, 0, 1)$。つまり t1 のクエリは、各キー位置の U の **d2 成分だけ**を読んでいます。U[t1, d2] = 0 なので S[t1, k1] = 0、U[t0, d2] = −√(3/2) なので S[t1, k0] = −3/(2√3) = −0.8660。
- S[t0, k0] = 2.1651 は参考値です（t0 は要素1つの softmax なので、値が何でも A[t0] = [1, 0]）。
</details>

## 5 説明し直し（30分）

**問1　どこが0か、2ステップ目も0か**：2 の「予想」で挙げた厳密な0を、「どんな重みでも0（構造）」と「この重み・この入力だから0」に分けてください。2ステップ目（更新後の θ'）の勾配でも0のままなのはどれですか？

<details><summary>答えの要点</summary>

- **構造**：dS・dQ の t0 行（因果マスク → 要素1つの softmax）、dE の 降る 行（入力に無い）。2ステップ目も0のままです。
- **この重み・この入力だから**：dX1・dO・dV・dWv の d2 列（Wout の d2 行が0）、dQ[t1, d1] と dWq の d1 列（キーの d1 成分が等しい）、dK・dWk の d2 列（Q[t1, d2] = 0）、dWq の d2 行（U[t1, d2] = 0）。更新で重みと U が動くので、2ステップ目には0でなくなります。例：dWq の d2 行は (−0.0123, 0.0039, 0.0095)（U'[t1, d2] = −0.1873）、dX1 の d2 列は (−0.0574, −0.0006)（Wout' の d2 行 = (−0.1840, 0.1514, 0.0326)）。（`--explain` の [5]）
- Part 1 の「dWk の d0 行」（U1 の d0 列が3位置とも +1 だったから0）も後者で、2ステップ目には (−0.0002, 0.0020, −0.0020, 0.0027) になります。
</details>

**問2　LN の逆伝播の向き**：B5 の LN経由が、t0 では (1, −2, 1) の、t1 では (1, 1, −2) の定数倍になったのはなぜですか？ d = 4 の Part 1 では何がこれに当たりましたか？ d 次元ではどうなりますか？

<details><summary>答えの要点</summary>

- LN は「全成分に同じ数を足す」（1 の方向）と「平均からのずれを何倍かする」（U の方向）を無視します。だから LN経由は、どんな dU に対しても「各行の和 = 0」「U と直交」になります（dU からこの2方向を取り除いて σ で割る射影）。
- 3次元から2方向を除くと残りは1方向。t0 は 1 = (1, 1, 1) と U ∝ (1, 0, −1) の両方に直交する (1, −2, 1)、t1 は (1, 1, 1) と (−1, 1, 0) に直交する (1, 1, −2) です。
- d 次元では d − 2 次元が残ります。Part 1（d = 4）は2次元で、U1 = ±1 のときは「同じ符号の2成分の差 ÷ 2σ」（ペアの規則）になりました。
</details>

**問3　合流点**：この例で勾配が足し算で合流する所はどこで、それぞれ何と何が足されますか？ Part 1 の3つの合流点（X1、U1、X0）と比べて、なぜ1つ少ないのですか？ 目に見えない合流も挙げてください。

<details><summary>答えの要点</summary>

- **U**：dU = dQ Wqᵀ + dK Wkᵀ + dV Wvᵀ。t1 行は Q の枝 (−0.0512, 0, 0.1791) ＋ K の枝 (0, 0, 0.0512) ＋ V の枝 (−0.0226, 0.0226, 0.1318) = (−0.0737, 0.0226, 0.3621)。t0 行には Q の枝がありません。（4桁どうしで足すと末尾が1ずれることがあります）
- **X0**：dX0 = dX1（残差、何も掛けずに）＋ LN経由。t1 行は (0.1676, 0.1035, 0) ＋ (−0.1055, −0.1055, 0.2110) = (0.0621, −0.0020, 0.2110)。
- Part 1 の X1 の合流は「残差 ＋ FFN の枝（LN2 経由）」でした。この例は FFN が無いので X1 は logits にしか使われず、合流しません。
- **目に見えない合流**：t0 のキー・値は t0 と t1 の両方のクエリに使われるので、dV[t0] = 1·dO[t0] + 0.2961·dO[t1] = (−0.0277, −0.1355, 0)。重みは2位置で共有されるので dW = Σ_t（外積）。
</details>

**問4　1次予測の比**：予測 ΔL = −0.7077、実際 −0.6070 で、比は 0.858 でした（Part 1 は 0.877）。`python3 part1_5/retrieval.py --explain` の [1] で lr を変えたときの比を見て、Part 1（lr = 0.5 で比 1.080）と何が違うのか説明してください。

<details><summary>答えの要点</summary>

- この例では、勾配方向に沿った損失 L(θ − ηg) の曲率が、最初から**正**です（d²L/dη² は η = 0 で 0.1221、η = 1 で 0.4258）。上に曲がった曲線では、まっすぐな1次予測より実際の下がり方が常に小さいので、比は lr = 0.1 でも 0.9914 と1を切り、lr を上げるほど下がります（0.5 で 0.9498、1 で 0.8577、2 で 0.6151）。2次の項まで入れた予測は −0.6467 で、実際により近くなります。
- Part 1 では η = 0 の曲率が**負**（−0.8270）で、小さな lr では実際のほうが大きく下がりました（lr = 0.5 で 1.080）。lr = 1 で比が1を切ったのは、損失が0の下に行けず（予測 L' = −0.0752 はありえない値で、比は L/‖g‖² = 0.949 を超えられない）、曲線が底で平らになるからです。2次の項を入れると、かえって外れます（−1.8836、実際 −1.2893）。
- 同じ「0.86〜0.88」でも、理由は別です。1次予測は「今の傾き」の情報だけなので、どれだけ当たるかは曲面の形しだいです。
</details>

**問5　÷2 を忘れたら**：dlogits の ÷2 を忘れると、更新後の損失は 0.2303 になり、正しい勾配の 0.4939 より**低く**なります（`--explain` の [2]）。なぜですか？ 「損失がちゃんと下がったから勾配は正しい」と言えないのはなぜですか？

<details><summary>答えの要点</summary>

- ÷2 を忘れると、逆伝播はすべて線形なので**全部の勾配がちょうど2倍**になります。向きは正しいまま、lr = 2 で進んだのと同じです。この例では勾配方向に沿って η = 4 付近まで損失が下がり続ける（η = 4 で 0.1355。η = 6 では 0.1876 に戻る）ので、2倍の歩幅のほうが低くなります。
- 和が0、直交、などの検算は大きさを2倍にしても成り立つので、このミスを見つけられません。見つけられるのは数値微分（`--gradcheck`）だけです。
- Part 1 でも ÷3 を忘れると L' = 0.0002 になり、正しい 0.1056 より低くなりました（`python3 extras/bug_signatures.py`）。**損失が下がることは、勾配が正しいことの証明になりません。**
</details>

**問6　Attention は要ったか**：更新で t1 の注意は k1 から k0（`<s>`）へ移りました。では、t1 で 降る を当てられるようになったのは Attention のおかげですか？ `--explain` の [4]（logits = 直接経路 X0·Wout ＋ Attention 経路 O·Wout）を見て答えてください。

<details><summary>答えの要点</summary>

- FFN も最終 LN も無いので、logits = X0·Wout + O·Wout と厳密に2つに分かれます。更新後の t1 は、直接経路 (−0.2375, 0.3230, 1.4786) ＋ Attention 経路 (−0.0909, −0.1077, 0.2063)。降る の logit の大部分は直接経路で、直接経路だけでも argmax は 降る です（t0 も直接経路 (0.0373, 0.4402, −1.1105) だけで argmax は 雨）。
- つまり「自分のトークン（と位置）の埋め込みを Wout で読む」だけで当たっています。このタスクは Part 1 と同じく直前の1語で答えが決まるので、**注意が動くこと＝意味のある働き、とは限りません**。t0 の Attention にいたっては、自分の V を足すだけで何も混ぜていません。
- Attention でしか解けないタスクは Part 2 です。t2 の入力がどちらの文も「が」なので、t1（猫 / 犬）を振り返らなければ 鳴く か 吠える かを決められません。
</details>
