## 1. 何のために、何を確かめるか

- **間をあけて思い出す**：直後に読み返すより、間をあけて自分で思い出すほうが長く残ります。思い出すのに苦労すること自体が効き目です。
- **新しい例でやる**：Part 1 の数字を覚えていても使えません。思い出す対象は数ではなく**手順と理由**（どの式で、どこが0になり、何で検算するか）です。
- **白紙からやる**：式は与えません。モデルの言葉での仕様（§2）とパラメータだけから、式・形・分岐点を自分で書き起こします。思い出せなかった所が、Part 2 の前に復習する所です（worksheet の「6 想起の記録」に残します）。

この例で、Part 1 の部品のうち FFN（ReLU）と、ヘッドの分割・連結・出力射影 Wo 以外のすべてをもう一度使います。

| 部品 | この例で出る所 | Part 1 | Part 0 |
|---|---|---|---|
| 埋め込み＋位置埋め込み、dE と dP | A1、B6 | 2.1、6.9 | D3 |
| LayerNorm の順・逆と2つの不変量（d = 3） | A2、B5 | 2.2–2.3、6.8 | D8 |
| Attention の順・逆（因果マスク、t0 のクエリ） | A3–A5、B2–B3 | 3.1–3.4、6.5–6.6 | D6、D7 |
| softmax + 交差エントロピー（平均の ÷N） | A6、B1 | 5.1–5.3、6.1 | D5 |
| 行列積の逆伝播、位置ごとの外積の和 | B1、B4 | 6.1、6.7 | D1 |
| 分岐での合流（U の3本、X0 の残差） | B4、B5 | 6.7、6.8 | D2 |
| SGD、1次予測と実際 | C1–C4 | 7.1–7.4 | D9 |

**d = 3 にした理由**：Part 1 は U1 = ±1 になるように重みを選んであり、LN の逆伝播も「ペアの規則」で楽ができました。d = 3 ではその手が使えず、LN の出力は ±√(3/2) = ±1.2247 と 0 になります。
LN の逆伝播の2つの不変量（各行の和 = 0、LN の出力と直交）を、別の形でもう一度確かめるためです。

## 2. モデルとパラメータ

**わざと式は書いていません。** 次の仕様から、worksheet の「0」で式と形を自分で書き起こしてください。

- 語彙は3つ：`<s>` = 0、`雨` = 1、`降る` = 2。入力 `<s> 雨` → 正解 `雨 降る`（2つの位置の両方で次のトークンを予測）
- d_model = 3、系列長 T = 2、**1ヘッド（d_k = 3）**、**FFN なし**、**出力射影 Wo なし**（ヘッドの出力をそのまま残差に足す）
- 入力 = トークン埋め込み E（3×3）の行 ＋ 学習型の位置埋め込み P（2×3）の行
- LayerNorm は Attention の**前**（Pre-LN）。γ = 1、β = 0、ε = 0、分散は母分散（÷3）。最終 LN はなし
- Attention：スコアは √d_k で割る、因果マスクあり。残差は LN の**前**の値に足す
- 出力層 Wout（3×3、埋め込みと共有しない）→ softmax → 2位置の交差エントロピーの**平均**
- 素の SGD、**lr = 1**、パラメータはすべて学習する（E 9 + P 6 + Wq 9 + Wk 9 + Wv 9 + Wout 9 = 51個）
- 記号は Part 1 と同じ：行ベクトル規約（$Y = XW$）、$dX := \partial L/\partial X$、添字は0始まり（位置 t0, t1、次元 d0〜d2、キー k0, k1）

**E（トークン埋め込み、行 = トークン）**

| | d0 | d1 | d2 |
|---|---:|---:|---:|
| &lt;s&gt; | 1 | 0.5 | 0 |
| 雨 | −0.5 | 1 | 0.5 |
| 降る | 0 | −1 | 1 |

**P（位置埋め込み、行 = 位置）**

| | d0 | d1 | d2 |
|---|---:|---:|---:|
| t0 | 0.5 | 0 | −0.5 |
| t1 | −0.5 | 1 | 0 |

**Wq**

| | d0 | d1 | d2 |
|---|---:|---:|---:|
| d0 | −0.5 | 0 | 0 |
| d1 | 0 | 1 | 0 |
| d2 | 1 | 0 | −1 |

**Wk**

| | d0 | d1 | d2 |
|---|---:|---:|---:|
| d0 | −1 | 0.5 | 1 |
| d1 | 0 | 0 | 0.5 |
| d2 | 0 | 1 | 0 |

**Wv**

| | d0 | d1 | d2 |
|---|---:|---:|---:|
| d0 | −0.5 | 0.5 | 0 |
| d1 | 0.5 | −0.5 | −0.5 |
| d2 | 0.5 | 1 | −1 |

**Wout（出力層、列 = トークン）**

| | &lt;s&gt; | 雨 | 降る |
|---|---:|---:|---:|
| d0 | 0 | 0 | −0.5 |
| d1 | 0 | 0.5 | 0 |
| d2 | 0 | 0 | 0 |

正本は [retrieval.py](retrieval.py) の `PARAMS0` です。

## 3. 進め方のルール

1. **見てよいのは、この README の §2 と電卓だけ**です。Part 0・Part 1 の資料、自分のノート、`retrieval.py` のソースは見ません。
2. **式を思い出せないときは、まず自分で組み立てます**：形を合わせる（dW は W と同じ形）、2×2 の小さな例で成分を書く、「足すと0になるはず」の不変量から逆算する。それでも**5分**止まったら worksheet のヒントを開き、開いたことを「6 想起の記録」に書きます。
3. **記録は有効数字4桁**、内積の途中では丸めません（Part 1 の §7 と同じ）。1回目の順伝播は「√(3/2) × 0.5刻みの数」の形のまま持つと、掛け算がほとんど要りません。
4. **許容差**は |自分 − 解答| ≤ 0.002 + 0.002·|解答|。外れたら**5分**だけ探し、見つからなければ答えの値で上書きして先へ進みます。ミスの種類（転置、符号、÷2 忘れ、1/√3 忘れ、σ と σ² の取り違え、分岐での足し忘れ）を記録します。
5. **答えはチェックポイントごとに**開きます。開く前に、worksheet の「検算」で自分の数字を確かめます。

## 5. 正解スクリプト retrieval.py

worksheet の数値はすべて [retrieval.py](retrieval.py) の出力です（NumPy が必要）。`hand_transformer/` で実行します。

```bash
python3 part1_5/retrieval.py               # 全チェックポイント（A1〜C4）
python3 part1_5/retrieval.py --only B5     # 1つだけ（LN の逆伝播と合流）
python3 part1_5/retrieval.py --section B   # 逆伝播だけ
python3 part1_5/retrieval.py --check       # 不変量と数値微分の検査30件。すべて通れば ALL CHECKS PASSED
python3 part1_5/retrieval.py --gradcheck   # 51個の勾配と中心差分（h = 10⁻⁶）の最大誤差
python3 part1_5/retrieval.py --explain     # 説明し直しで使う数値（学習率ごとの比、÷2 忘れ、群ごとの更新、logits の分解）
python3 part1_5/retrieval.py --blank       # 記入用の空欄表（Markdown）
```

数値微分との差は、どの群でも 1.3×10⁻¹⁰ 未満です（`--gradcheck`）。
